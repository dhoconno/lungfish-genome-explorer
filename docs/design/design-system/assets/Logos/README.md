# Logos

`app-icon.png` is the Lungfish Genome Explorer app icon at 512 px. It shows a Creamsicle fish and wave line inside a Creamsicle ring on a light disc. Use it on `cream` or `deep-ink` only, at 40px or larger, with clear space equal to a quarter of its width. Never recolor, stretch, rotate, shadow or tile it. The brand wordmark and monogram are not yet in this system.
