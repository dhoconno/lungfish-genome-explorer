# TitleBlock

The page opener for docs and brand pages, made of a Space Grotesk title with the Creamsicle bar beneath, a sentence-case subtitle, and the section heading style that follows.

Hand-written from `docs/site/theme-house.scss` (`.quarto-title-block`, `h2`) and `docs/user-manual/css/extra.css`.

- Title is `display` in `deep-ink`. The bar is `accent-bar-width` by `accent-bar-height` in `creamsicle`, flush left at the title's foot.
- The subtitle is one `subtitle` line in `deep-ink`, sentence case. Never add an eyebrow above or below the title.
- Section headings are `heading-2` in sentence case with a 1px `rule` above.
- Every H1 gets the bar. Never put the bar under H2 or H3.
