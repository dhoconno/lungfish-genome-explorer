# Callout

A Peach-washed panel with a Creamsicle left edge that sets one important note or the download card apart on a docs page.

Hand-written from `docs/site/theme-house.scss` (`.callout`, `.download-card`).

- Fill `peach` at 28%, border `peach` at 60%, left edge `callout-edge` in `creamsicle`, radius `radius-8`, no shadow.
- Text stays `deep-ink`. Links are `deep-ink` with a `creamsicle` underline inside a callout.
- The download card puts the 72px app icon at `radius-16` left of the text.
- Use one callout per screen at most. Never color a note blue or green, the palette has no blue.
