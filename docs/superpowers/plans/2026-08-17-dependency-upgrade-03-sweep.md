# Dependency Sweep Tooling and 2026.2 Sweep Implementation Plan (Plan C)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Fable orchestrates and reviews every task, and personally owns every "verify" decision in Tasks C5 to C12; see the master index for model routing.

**Goal:** Ship `scripts/deps/check-upstream.py`, `bump.py`, and `verify.sh`, then use them to move LGE to dependency set 2026.2 with tiered verification and release notes.

**Architecture:** Three stdlib-only Python/bash tools operate on the manifest from Plan A: `check-upstream.py` gathers candidates (bioconda repodata via micromamba, GitHub releases/tags, S3 HEAD probes, NCBI listings) into `candidates.json`/Markdown; `bump.py` rewrites the manifest for a chosen subset with full build strings and checksums and regenerates derived files; `verify.sh` provisions an isolated storage root through `lungfish-cli tools update` and runs the Plan B tiers. The sweep itself is a sequence of bump + verify + fix cycles per risk group, ending with GUI walkthroughs, CI dispatch, and release notes.

**Tech Stack:** Python 3.12 stdlib (`urllib`, `json`, `subprocess`), bash, micromamba, `gh` optional, XCTest via Plan B.

**Spec:** `docs/superpowers/specs/2026-08-17-dependency-upgrade-mechanism-design.md` (sections 4.6, 5, 6)

## Global Constraints

- Scripts must run offline where possible: `check-upstream.py` needs network; `bump.py` needs network only for checksums (`--no-checksums` skips); `verify.sh` needs network for provisioning once (cache by manifest hash under `LUNGFISH_STORAGE_ROOT`).
- Only `osx-arm64` and `noarch` builds are eligible; a candidate without an eligible build is reported as "no arm64 build" and never chosen.
- Every bump preserves the manifest's `packTools`/`tools` ordering and untouched entries byte-for-byte (stable JSON writer with the repo's existing formatting: 2-space indent, one tool per line for `tools`; write with the same style as the current file, verified by a test that round-trips the current manifest without diff).
- Held tools in the 2026.2 sweep: seqkit, cutadapt (build only), trim-galore, pigz, sra-tools, ucsc-bedgraphtobigwig, pysam (build only), openpyxl, bwa-mem2, blast, lofreq, ivar, megahit, skesa, flye, hifiasm, mafft, kraken2, bracken, ribodetector, gatk4, whatshap, viralrecon, EsViritu DB v3.2.4, deacon panhuman-1/ribokmers, apple/containerization, Xcode 26.4.1.
- Fable owns verification verdicts; subagents may run commands and report but do not decide that a regression is acceptable.

#!/bin/bash
# verify.sh - provision an isolated storage root from the current manifest and run regression tiers.
# Usage: scripts/deps/verify.sh --tier 1|2|3|all [--root DIR] [--keep] [--dry-run] [--filter REGEX]
set -euo pipefail
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"; ROOT="$(cd "$SCRIPT_DIR/../.." && pwd)"; cd "$ROOT"
TIER="1"; STORAGE_ROOT="${LUNGFISH_VERIFY_ROOT:-$HOME/.lungfish-verify}"; KEEP=0; DRY=0; FILTER=""
while [ $# -gt 0 ]; do case "$1" in
  --tier) TIER="$2"; shift 2;; --root) STORAGE_ROOT="$2"; shift 2;; --keep) KEEP=1; shift;; --dry-run) DRY=1; shift;; --filter) FILTER="$2"; shift 2;;
  -h|--help) sed -n '2,4p' "$0"; exit 0;; *) echo "unknown arg $1" >&2; exit 64;; esac; done
MANIFEST="Sources/LungfishWorkflow/Resources/ManagedTools/third-party-tools-lock.json"
SET="$(python3 -c 'import json,sys;print(json.load(open(sys.argv[1]))["dependencySet"])' "$MANIFEST")"
HASH="$(shasum -a 256 "$MANIFEST" | cut -d' ' -f1)"
export LUNGFISH_STORAGE_ROOT="$STORAGE_ROOT"; export LUNGFISH_REQUIRE_TOOLS=1
echo "verify: set=$SET manifest=$HASH root=$STORAGE_ROOT tier=$TIER"
[ "$DRY" -eq 1 ] && exit 0
mkdir -p "$STORAGE_ROOT"
swift build --product lungfish-cli >/dev/null
CLI=".build/debug/lungfish-cli"
# Provision (idempotent; reconciler skips work when receipt matches).
"$CLI" tools update --apply --yes --required-only
for pack in read-mapping assembly phylogenetics multiple-sequence-alignment metagenomics full-length-mhc-genotyping variant-calling; do
  "$CLI" conda install --pack "$pack" --yes
done
"$CLI" db download Viral --yes || true          # already installed → no-op
"$CLI" tools update --plan >/dev/null || { echo "verify: plan not empty after provisioning" >&2; "$CLI" tools update --plan; exit 65; }
run_tier1() { bash scripts/full-suite-gate.sh --require-tools --filter "${FILTER:-Conformance|FASTQToolIntegrationTests|RecipeIntegrationTests|NativeToolRunnerTests|MAFFTAlignmentPipelineTests|ClassificationPipelineTests|ReadsToVariantsEndToEndTests|BAMPrimerTrimSubcommandTests|IVarConverterViralReconParityTests|Dependency}"; }
run_tier2() { local out=".build/goldens-$SET"; rm -rf "$out"; bash scripts/deps/regenerate-goldens.sh --set "$SET" --out "$out"; python3 scripts/deps/diff_goldens.py --recipes scripts/deps/goldens.json --candidate "$out" --set "$SET"; }
run_tier3() { bash scripts/deps/run-pipelines.sh --which all --out ".build/pipelines-$SET"; }
case "$TIER" in 1) run_tier1;; 2) run_tier2;; 3) run_tier3;; all) run_tier1 && run_tier2 && run_tier3;; *) echo "bad tier" >&2; exit 64;; esac
[ "$KEEP" -eq 0 ] && echo "verify: keeping $STORAGE_ROOT for reuse (pass --root to change)"
