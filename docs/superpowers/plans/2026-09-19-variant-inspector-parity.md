# Variant Inspector Table Parity Implementation Plan

**Goal:** Variant Detail presents the selected table row's available fixed and dynamic fields, including runtime-recovered iVar measurements, without changing scientific files.

**Diagnosis (Astra):** VariantSectionViewModel.select resets infoFields to [] and computeGenotypeSummary replaces them using SQLite only, ignoring SearchResult.infoDict. Legacy iVar recovered values therefore disappear. The view omits track/settings/sample/source/derived coding fields, limits dynamic fields to prefix(20), and Copy Info omits them. Selection notification currently carries only SearchResult, while coding feature/consequence/AA and caller settings are resolved by drawer methods.
