# Known MHC Allele Graphical Detail Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the slow evidence-heavy detail for known full-length MHC genotype rows and cells with a fast allele-centric Overview/GenBank/FASTA view backed by a compact, reproducible visualization artifact generated by fresh analyses.

**Architecture:** The full-length workflow will extract the deduplicated union of exact known references and every candidate's already-classified closest reference from the complete reference database into one versioned JSON artifact plus canonical multi-record GenBank and FASTA companions. LungfishIO will validate and index the JSON once when the result bundle loads. LungfishGenotypeUI will render an AppKit overview directly from the indexed record and switch to its precomputed GenBank or FASTA text without reading BAM, SQLite, or reference files. Candidate detail remains unchanged in this tranche; its closest-reference records are included now for the next graphical overlay tranche.

**Tech Stack:** Swift 6, Swift Package Manager, AppKit, LungfishIO reference bundles and GenBank writer, LungfishWorkflow full-length ONT MHC pipeline, XCTest.

---

## Scope guardrails

- Implement only the MHC reference visualization artifact, known-allele detail UI, its pipeline publication/provenance, and preservation across existing result-manifest revisions.
- Reuse the bundle loader's existing safe relative-path resolution, checksum/size verification, stable read, and manifest-last publication mechanisms.
- Add only schema, identity, sequence checksum, required-role, and in-bounds-feature validation needed for correct rendering.
- Do not introduce a generalized viewer framework, generalized cache subsystem, new filesystem/security abstraction, exhaustive adversarial test matrix, or adjacent LGE UI changes before the user evaluates the detail pane.
- Preserve the existing candidate detail view in this tranche.

- [ ] **Step 3: Implement the minimal public model**

Define these `Codable`, `Equatable`, `Sendable` values:

```swift
public struct ONTMHCReferenceVisualizationArtifacts: Codable, Equatable, Sendable {
    public let schemaVersion: Int
    public let recordsJSON: ONTMHCArtifactReference
    public let genBank: ONTMHCArtifactReference
    public let fasta: ONTMHCArtifactReference
}

public enum ONTMHCReferenceVisualizationRole: String, Codable, Equatable, Sendable {
    case exactKnownCall = "exact_known_call"
    case closestNovelReference = "closest_novel_reference"
    case closestExtensionReference = "closest_extension_reference"
}

public struct ONTMHCReferenceVisualizationRoleAssignment: Codable, Equatable, Sendable {
    public let role: ONTMHCReferenceVisualizationRole
    public let candidateStableClusterIDs: [String]
}

public struct ONTMHCReferenceVisualizationFeature: Codable, Equatable, Sendable {
    public let type: String
    public let start: Int
    public let end: Int
    public let strand: String
    public let sourceOrdinal: Int
    public let rawGenBankLocation: String?
    public let qualifiers: [String: [String]]
    public var interval: Range<Int> { start..<end }
}

public struct ONTMHCReferenceVisualizationRecord: Codable, Equatable, Sendable {
    public let rawReferenceID: String
    public let sourceOrdinal: Int
    public let alleleName: String
    public let locus: String?
    public let sequence: String
    public let sequenceSHA256: String
    public let recordFields: [String: [String]]
    public let features: [ONTMHCReferenceVisualizationFeature]
    public let annotatedTranslation: String?
    public let genBankText: String
    public let fastaText: String
    public let roles: [ONTMHCReferenceVisualizationRoleAssignment]
}

public struct ONTMHCReferenceVisualizationArtifact: Codable, Equatable, Sendable {
    public let schemaVersion: Int
    public let records: [ONTMHCReferenceVisualizationRecord]
    public let recordsByRawReferenceID: [String: ONTMHCReferenceVisualizationRecord]
    public func validated() throws -> Self
}
```

`recordsByRawReferenceID` is a derived stored index initialized once during construction or decoding and is omitted from encoded JSON. Validation is intentionally limited to schema version 1, nonempty unique raw IDs, nonempty roles, SHA-256 equality, and `0 <= start < end <= sequence.count`.

- [ ] **Step 4: Implement the builder**

Provide a narrow workflow API:

```swift
struct MHCReferenceVisualizationArtifactBuilder {
    struct Inputs {
        let referenceBundleURL: URL
        let exactKnownRawReferenceIDs: Set<String>
        let candidates: ONTMHCCandidateAllelesDocument?
    }

    struct Output {
        let document: ONTMHCReferenceVisualizationArtifact
        let genBankText: String
        let fastaText: String
    }

    func build(_ inputs: Inputs) throws -> Output
}
```

Construct the requested reference set as the deduplicated union of exact raw IDs and every candidate's persisted raw `selectedEvidence.referenceName`, categorizing candidate references from `.novel` and `.extension`. Treat `closestReferenceName` as the resolved allele label used for provisional naming, not as the reference-bundle sequence key. Resolve each selected-evidence raw identity against all records in the supplied reference bundle. Do not recompute nearest neighbors and do not filter them through exact genotype calls.

For each reference, fetch its entire sequence, ordered annotations, flattened GenBank fields, allele label, locus, and annotated translation. Convert annotations to 0-based half-open intervals. Format canonical GenBank and FASTA strings once, store them on the record, and concatenate them in source-ordinal order with raw-reference-ID as the stable tie-breaker for the companion files.
