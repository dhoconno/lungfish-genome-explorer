# MHC Unmatched Closest Match Workbook Design

## Summary

Full-length ONT MHC genotyping already reports Savont clusters that do not qualify as exact genotype calls in an `Unmatched Clusters` workbook sheet. That sheet is a long per-cluster list, which makes it hard to see whether the same unmatched sequence is shared across samples in a run.

Add two workbook sheets generated by the existing full-length ONT MHC workflow:

- `Unmatched Closest Matches`: one detail row per unmatched Savont cluster with closest reference match metadata.
- `Unmatched Shared Pivot`: one matrix row per closest-match identifier and one column per sample, with read counts as intersect values.

## Matching Semantics

Closest matching is based on the minimap2 alignment evidence already produced while classifying full-length clusters against the reference library. The matcher must preserve SNP-containing alignments instead of only considering zero-SNP genotype calls.

For each unmatched cluster:

1. Parse all mapped alignments to reference sequences.
2. Count SNP mismatches from CIGAR `X` operations.
3. Count indel bases from CIGAR `I` and `D` operations.
4. Select the closest reference by sorting on:
   - fewer SNP mismatches;
   - fewer indel bases;
   - more aligned bases;
   - higher score;
   - reference name, using localized standard sort.

If the best alignment has zero SNP mismatches and at least one indel base, classify the cluster as an `extension` of the closest reference. If the best alignment has one or more SNP mismatches, classify it as `snp-different` and use the SNP mismatch count as `nucleotides_different`.

Unaligned unmatched clusters should remain in the raw `Unmatched Clusters` sheet and appear in the closest-match detail sheet with blank closest reference metadata. They should not add a pivot identifier unless a closest reference can be determined.

## Workbook Contract

`Unmatched Closest Matches` columns:

- `sample`
- `cluster`
- `cluster_reads`
- `closest_reference`
- `match_class`
- `closest_match_id`
- `nucleotides_different`
- `snp_differences`
- `indel_bases`
- `aligned_bases`
- `score`
- `sequence`

`Unmatched Shared Pivot` rows:

- Header: `closest_match_id`, `closest_reference`, `match_class`, `nucleotides_different`, followed by one column per sample.
- Each data row groups unmatched clusters by `closest_match_id`.
- Each sample cell is the sum of Savont cluster read counts for unmatched clusters in that group and sample.

Identifiers:

- Extension: `<reference>_extension`
- SNP-different: `<reference>_<n>SNP`

The workbook keeps existing sheets unchanged, including `Unmatched Clusters` for raw sequence review and `Full Sequencing Results 1` for genotype-style output.

## Provenance

This is part of the existing `lungfish-cli fastq full-length-ont-mhc-genotype` workflow. The generated workbook already belongs to the provenance-tracked output bundle. No new external tool is introduced. The new sheets are deterministic derived report content from retained inputs and existing minimap2/Savont workflow evidence.
