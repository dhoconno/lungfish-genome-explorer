## Item 1 (BUG, P0): minimap2 reference fails to load — validator rejects the app's own symlinks

### Verified root cause
- `MappingViewerBundlePreparer.linkOrCopyItem` (Sources/LungfishApp/Services/MappingViewerBundlePreparer.swift:93-110) creates **absolute symlinks** for **every** manifest-referenced top-level dir (`genome/`, `annotations/`, `variants/`, `metadata/`…) of the viewer bundle, pointing into the external source `.lungfishref`. The manifest records the source in `originBundlePath` (preparer :39, :112-115; project-relative preferred, filesystem-relative fallback).
- Commit e5a01250 (2026-07-05) introduced `BundleManifest.validatedBundleMemberURL` (Sources/LungfishCore/Bundles/BundleManifest+Validation.swift:122-149). Lines 140-146 resolve symlinks and re-check descendancy, rejecting these legitimate symlinks with `BundleValidationError.invalidPath` → wrapped as `ReferenceBundleError.validationFailed`.
- Failure fires in `ReferenceBundle.init(url:)` (ReferenceBundle.swift:128,133) — **before any fetch** — plus fetchSequence/fetchSequenceSync/referenceFASTAPath. UI call sites use `try?`, so degradation is silent.
- Contradictory contracts shipped: `MappingViewerBundlePreparerTests` asserts `genome` IS a symlink; `BundleManifestTests.testValidatedBundleMemberURLRejectsSymlinkEscapes` + `ReferenceBundleTests.testOpenRejectsGenomeSymlinkEscapingBundle` assert symlink escapes throw. Both stay green under the chosen fix.

### Chosen fix: origin-scoped, top-level-symlink-only allowance (NOT a blanket opt-out)
FASTQBundle's `allowExistingSymlinkEscape: Bool` precedent is a blanket disable — rejected. Instead:

1. `BundleManifest.validatedBundleMemberURL` gains `allowedEscapeRoots: [URL] = []` (default = today's behavior, all existing call sites unchanged).
2. The string check (`isSafeBundleMemberPath`) and the **lexical `isDescendant` on the unresolved candidate stay untouched**.
3. The post-resolution re-check, when it fails, permits the escape ONLY IF **both**:
   - **(a) traversal-through-owned-member**: the first path component of `relativePath` is itself a symlink located directly inside the (resolved) bundle root — i.e. the bundle owns the escape point at top level. A leaf-file symlink (e.g. `genome/sequence.fa` → outside, with `genome/` a real dir) does NOT qualify — the existing negative tests keep throwing.
   - **(b) origin containment**: the fully resolved candidate is a descendant of one of the resolved `allowedEscapeRoots`.
4. `ReferenceBundle` derives `allowedEscapeRoots` from `manifest.originBundlePath`: resolve the recorded path (mirror the preparer's project-relative/filesystem-relative encoding), require the target to exist and to contain a readable bundle manifest, and pass its resolved URL. No `originBundlePath`, unresolvable origin, or origin without a manifest ⇒ empty roots ⇒ current strict behavior.
5. Route all reference-bundle member resolution through one shared helper so init, both fetch paths, `referenceFASTAPath`, and the direct `BundleManifest.validatedBundleMemberURL` callers that operate on reference bundles (SequenceExtractionPipeline, BAMVariantCallingDialogState/Preflight, ReferenceBundleMergeService, builders) get consistent policy. Priority: the `ReferenceBundle` paths are required for the bug; the direct callers are required to avoid the same bug resurfacing in consensus export / variant calling on mapping bundles.

### Security-gate outcome (2026-08-09): REJECT-as-first-drafted → hardened rule below is what gets implemented
The pentest proved `originBundlePath` is an **unvalidated attacker-controlled string** in the manifest, so treating it as a trust anchor was exploitable (set it to `/etc`/`$HOME`/`../../..`, symlink a top-level member in, "contains a manifest" authenticates nothing → full out-of-bundle disclosure). The relaxation MUST additionally, ALL required:

1. **Validate `originBundlePath` itself** before use: reject absolute paths and any `..`/`.`/empty component; do NOT use FASTQBundle.resolveBundle's permissive legacy branch. For `@/` form validate the inner path with the member-path string check.
2. **Constrain the resolved origin root**: (i) must resolve INSIDE the same `.lungfish` project root as the viewer bundle (`findProjectRoot(from: bundleURL)`; reject if none or if origin escapes it); (ii) must have extension `.lungfishref`; (iii) its OWN `manifest.validate()` must pass AND its `identifier` must equal the viewer manifest's `identifier` (identity auth, not mere manifest presence); (iv) must NOT be an ancestor of the viewer bundle and NOT equal `$HOME`, `/`, `/etc`, `/Users`, or any volume root.
3. **No transitive origins**: depth = 1 — when a bundle is used as an escape root, its own `originBundlePath` is ignored (no recursion).
4. **File-identity containment, not string prefix**: for the escape-root descendancy check, resolve symlinks on BOTH sides and compare by `(st_dev, st_ino)` walking the candidate's parent chain (or `.fileResourceIdentifierKey`) — closes APFS case-insensitivity and NFC/NFD soundness holes. KEEP the existing trailing-slash `isDescendant` for the unchanged lexical check on the unresolved candidate.
5. Condition (a) (first component is a bundle-owned top-level symlink) stays as defense-in-depth but is known to authenticate only the first hop; security rests on the origin-root constraints (1-2).

TOCTOU (symlink swapped between origin validation and member read) is accepted residual risk for the single-user desktop threat model; route eventual reads through `NoFollowFileSystem` (ProjectTempDirectory.swift:191) as a cheap follow-up (not blocking this change).

### Regression tests (behavioral, real fetch path)
- Positive: build a real source bundle + viewer bundle whose `genome/` (and one non-genome dir) symlink to it with `originBundlePath` set; `ReferenceBundle(url:)` opens and `fetchSequenceSync` returns correct bases. Strengthen per bio gate: assert bases at a non-zero offset AND near the contig end (catches off-by-one in origin-scoped resolution), and for a multi-contig bundle assert the SECOND contig resolves — a silently offset reference is worse than the current all-mismatch failure.
- Negative (all throw `invalidPath` / yield empty escape-roots): `../outside.fa`; absolute `/etc/passwd`; leaf-file symlink to outside (existing tests); top-level symlink with NO `originBundlePath`; top-level symlink with origin declared but target outside the origin; `originBundlePath` pointing at a non-bundle directory.
- Security negatives from the gate (all must throw / not escape): absolute `originBundlePath` (`/etc`) with a top-level symlink into it; `originBundlePath` = `../../../../etc`; origin = plain dir that merely contains a manifest but is not `.lungfishref` or whose `identifier` differs; chained origins (A declares B — assert no escape past A); origin = `$HOME` / viewer bundle's own parent / an ancestor of the viewer bundle; nested escape (owned top-level symlink whose target dir contains a deeper symlink escaping the origin).
- Both-sides-resolved regressions: legitimate origin under `/tmp` (candidate canonicalizes to `/private/tmp`) still opens; case-variant origin vs candidate on APFS decided by file identity not string casing; NFC-vs-NFD equivalent component names decided consistently.
