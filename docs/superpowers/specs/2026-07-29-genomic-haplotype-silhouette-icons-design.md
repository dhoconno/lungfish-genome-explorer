# Genomic Haplotype Silhouette Icon Concepts

## Goal

Create a comparison sheet of ten possible silhouettes for a genomic haplotype icon in Lungfish Genome Explorer.

## Visual Direction

- Match the compact, monochrome visual language of macOS SF Symbols.
- Use solid black silhouettes on a plain white background.
- Favor paired genomic tracks and locus patterns over a generic DNA helix.
- Use rounded geometry, balanced negative space, and a consistent apparent weight.
- Keep every concept recognizable at approximately 16–32 pixels.
- Include no lettering, labels inside the icons, gradients, shadows, color, or decorative detail.

## Concepts

1. Paired segmented tracks
2. Offset allele blocks
3. Paired tracks with one variant notch
4. Recombinant crossover tracks
5. Braided paired strands
6. Split chromosome bar
7. Mirrored locus ladders
8. Linked variant beads
9. Stacked genomic ribbons
10. H-shaped haplotype monogram

## Deliverable

Produce one clean, evenly spaced 5-by-2 comparison sheet. Number the concepts outside the icon artwork for selection, while keeping each icon itself free of text. The sheet is for visual exploration; no application code or scientific data is created or transformed.

## Acceptance Criteria

- Exactly ten visibly distinct concepts are shown.
- Every icon reads as a single monochrome silhouette.
- The set feels internally consistent and suitable for a native macOS genomics application.
- The concepts remain visually separable when viewed at small size.
