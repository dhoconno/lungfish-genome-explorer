## Punch list from your morning feedback — all addressed

1. **Resizable viewport panels.** The list-top split defaults to 0.72 (list dominant) with smaller pane minimums (180pt list / 120pt detail) so the divider drags freely. The cohort summary contents are slimmer, so the bottom pane doesn't need 180pt of vertical room.

2. **MCM haplotype-calling logic.** The pipeline already encodes the notebook's subset-match algorithm; the user-visible regression was that the Outline rendered *every observed locus* (~17 for the real bundle) rather than the seven the MCM definition set actually analyses. The Outline now defaults to the seven canonical loci (MHC-A, B, DRB, DQA, DQB, DPA, DPB) and the Inspector grew a "Show observed-only loci" toggle to bring the ancillary loci back when the analyst needs them.

3. **64-token Rhesus palette.** `HaplotypeColorToken.canonicalPalette` is now 64 entries (M0–M7 untouched; X1–X56 generated by an 8-hue × 7-tint sweep in HSB, with WCAG-luminance-driven font colour and cycled glyphs). `assigned(forName:)` hashes unknown names across the full 1..63 range so Rhesus runs no longer collapse to seven colours.

4. **Free-text override + whitelist hints.** The override picker became a free-text TextField with suggestion chips drawn from the active definition set. Off-whitelist values surface a `lungfishDanger` warning triangle so reviewers can audit custom entries.

5. **Progressive-disclosure notes.** The Outline's right-most column collapsed from full-text notes to a single `⚠` alert glyph in `lungfishDanger`, with the full notes text as a tooltip and accessibility label. The header row's column shrank to 18pt accordingly.

6. **Cohort Summary redesign.** Panel B (bottom in list-top layout) dropped the redundant "Cohort summary > Samples" / "Read budget median" / "Block coherence" sections. It now leads with **Low-coverage samples** (more than 1 SD below the cohort mean reads) and **Below-threshold samples** (under 5K reads), each with a hover tooltip listing the affected sample IDs.

7. **Per-locus dropout EQ + 1% default.** Default global locus-fraction lowered from 5% → 1% (your "too many genotypes" feedback). The dropout section in the Audit lens grew a "Per-locus EQ" disclosure: one slider per analysed locus with a reset button, music-EQ style. Per-locus overrides persist in the sidecar (`Settings.locusFractionOverrides`).

8. **Dynamic haplotype recalculation.** `GenotypeHaplotypeAnalyzer.analyze(..., dropoutFilter:)` strips below-threshold genotypes from each sample × locus group before the subset-match runs. The Inspector caches a `liveHaplotypeAnalysis` that drives Outline / Cards / Matrix / Cohort Summary / Review lens evidence — so an analyst who drops a locus threshold from 5% → 0.5% sees `ERR: TMG` cells flip back to called haplotypes in real time. The pipeline-persisted analysis on disk stays authoritative; only the in-memory view changes.

## Known regression to investigate

Computer-Use driving of the running app surfaced an apparent sidebar routing regression: clicking the `barcode08-mhc-haplotypingv1.lungfishgenotype` row in the project sidebar highlights it visually but does **not** trigger `displayGenotypeResultBundleFromSidebar`. The viewport stays on whatever was previously selected (or stays empty on fresh launch). Tested with the v0.5.0-alpha2 binary at `.build/debug/Lungfish`.

I could not reproduce this via the unit/integration tests (all `SidebarViewControllerSelectionTests` pass; programmatic loading of the bundle works in `GenotypeResultViewportTests`). My hypothesis:

- A previous session's persisted selection (a reference sequence row) survives across launches.
- Clicking the bundle row marks it as a secondary selection rather than the focused row, so `selectionDidChange` doesn't refire the routing.
- Workaround: click a different sidebar row, then click the bundle.

When you have a moment, try opening the bundle via File → Open or via a fresh project window — that may bypass the persisted-selection state. If it loads cleanly that way, the bug is in the sidebar's selection-restoration path, not the genotype display.
