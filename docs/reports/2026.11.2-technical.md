## The 2026.11.1 publish stall

RELPROMPT found that the signed-app smoke took 3.83 s in that publish, so the wait sat in `build-notarized-dmg.sh` between the end of signing at 20:54:53 and the first appcast file at 01:52:21, and the builder took 18,003 s in all (`SCR/lanes/RELPROMPT/RELPROMPT.md` F1, `RELPROMPT-2.md` Item 1). RELPROMPT-2 read every step of that span and found none that runs the app, an embedded binary or a GUI launch. The system log shows a click on a Documents privacy prompt at 01:52:08.85 that ended twelve pending Documents-folder requests within 90 ms, and the publish ran on 0.6 s later. The log names no requester: a `find` over `/Users` (pid 64769) was one of them and the installed Lungfish Preview was running, so the step that held the wait is not proven (`RELPROMPT-2.md` Which step, F7). So the fix bounds every step of the span that reads the release folder or the network, with words that name the step and, for a local step, the prompt and how to answer it (`scripts/release/bounded_process.py`, `RELPROMPT-2.md` Item 3).
