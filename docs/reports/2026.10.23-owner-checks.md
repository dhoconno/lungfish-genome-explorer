# Lungfish 2026.10.23 owner check list

This is the owner check list of Preview 2026.10.23, which holds the checks that must pass before this build can become a Stable release.

## Checks still to run

This list holds only the rows that gate a Stable promotion of this candidate. They are the re-walk rows of vote V16 and the check list rows of vote V17 of Phase 2.14. By the owner's direction O35 the experts replace the owner on the rows of vote V17 by consensus, so each row names who makes the check. The manager makes most rows by computer use, and the owner makes the acceptance of the Pathoplexus terms in row 35. Every permission that the walk needs, such as computer use, the Finder grant or a privacy prompt, is the owner's own click. By the owner's direction O37 the panel observes and rules on what the walk shows, so the manager saves a screenshot of each row's words and of its Operations row for the panel. By the owner's direction, screenshot recaptures and manual rewrites wait until every phase has ended, so this release lists no screens to recapture and changes no manual chapter.
