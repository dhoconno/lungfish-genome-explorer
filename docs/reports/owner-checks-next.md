# Lungfish owner check list for the next release

This list holds the checks that need a person's eyes, ears, hands or accounts. It is written new by lane TWINS of the trust session, and the next release step renames the file to its version. The rows that a test can click are the XCUI twins of `Tests/LungfishXCUITests/WalkTwinsXCUITests.swift` and `SidebarRescanSelectionXCUITests.swift`, which the `ui-twins` profile of `config/test-catalog.json` runs on the package (`app_smoke_gate.py --profile ui-twins`) and which never bind a release. `SCR` is `/Users/dho/lungfish-phase-records/phase-3-2`, where the sheets and reviews of the Script column are. Severity follows `docs/contracts/SCOPE-AND-DELIVERY.md`. Owner rows block no release, and an open S1 or S2 finding blocks the next stable release. Work on a copy of a project.
