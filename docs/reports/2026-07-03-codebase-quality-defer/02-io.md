# LungfishIO — Deferred Items (Phase 2)

Module: `Sources/LungfishIO/**` (139 files, ~66K LOC).
Protocol: audit -> apply (behavior-preserving only) -> build + scoped tests ->
independent adversarial review -> revert-on-uncertainty -> commit.

IO is heavily correctness-sensitive (format parsing, coordinate math, bgzip
random access). The bar for "apply" is provably behavior-preserving:
dedup, dead-code removal, clarity renames of locals, access-control tightening.
Anything touching parsing/coordinate/format logic, a `Codable` schema, or a
failure path is DEFERRED here with a precise rationale, not applied.

Binding invariants preserved (never refactored away):
- bgzip `readUncompressedRange` infinite-loop fix: break when
  `nextOffset <= currentUncompressedOffset` OR `findBlock` returns nil, in BOTH
  the async and sync readers.
- Never save alignment as SAM (always sorted + indexed BAM).

## 2026-07-04 expert-review corrections

Two access/API shrink decisions were reclassified as too risky for a long-lived public module and
were surgically restored with regression coverage:
- `MultipleSequenceAlignmentBundle.ColumnStat` remains `public`, including its stored
  properties. It is plausibly part of the bundle API even if current in-repo use writes it to
  SQLite.
- `FormatRegistryError` remains `public`. It had no in-repo references, but removing a public
  error type is an API break, not a behavior-preserving cleanup.
