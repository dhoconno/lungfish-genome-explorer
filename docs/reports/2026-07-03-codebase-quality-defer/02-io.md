# LungfishIO — Deferred Items (Phase 2)

Module: `Sources/LungfishIO/**` (139 files, ~66K LOC).
Protocol: audit -> apply (behavior-preserving only) -> build + scoped tests ->
independent adversarial review -> revert-on-uncertainty -> commit.

IO is heavily correctness-sensitive (format parsing, coordinate math, bgzip
random access). The bar for "apply" is provably behavior-preserving:
dedup, dead-code removal, clarity renames of locals, access-control tightening.
Anything touching parsing/coordinate/format logic, a `Codable` schema, or a
failure path is DEFERRED here with a precise rationale, not applied.

Binding invariants preserved (never refactored away):
- bgzip `readUncompressedRange` infinite-loop fix: break when
  `nextOffset <= currentUncompressedOffset` OR `findBlock` returns nil, in BOTH
  the async and sync readers.
- Never save alignment as SAM (always sorted + indexed BAM).

## Deferred items

### Batch 1 — `NaoMgsDatabase.swift` (split + defer-reorder applied; rest deferred)

Applied: 4-way extension split + two `defer { sqlite3_finalize(stmt) }` reorderings
(behavior-identical, `finalize(nil)` no-op). Deferred (audit confirmed these are NOT
provably behavior-preserving):

- Duplicated 25-column `INSERT INTO virus_hits` VALUES list (createStreaming ~443 vs
  bulkInsertHits ~1469). Extractable to a shared constant only if byte-identical, but
  the two sites bind differently and one is `async static`; touches the insert path.
- Near-duplicated schema DDL across `createSchema`, `init(at:)` migration, and
  `openReadWrite`. Sites differ (`IF NOT EXISTS` vs `ALTER TABLE`, ordering interacts
  with migration detection). High blast radius.
- Repeated `String(cString: sqlite3_errmsg(db))` + throw (dozens of sites) — every one is
  an error/throw path (out of scope).
- `mergeStageSummaries` staged finalize-cascade — each guard finalizes a different growing
  subset; a helper would change error-path resource lifetime.
- `computeCoveredBasePairs` interval-merge, `normalizeImportedSampleName` regex,
  percent-identity/MAPQ/quality math, hash/dedup — parsing/coordinate/numeric logic.
- `NaoMgsTaxonSummaryRow` Codable + `topAccessions` JSON decode — schema/decode path.
- `populateSampleHitCounts` partial-failure control flow (`continue`/early-return fallback).
