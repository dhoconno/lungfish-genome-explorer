# Lungfish 2026.10.28 owner check list

This is the owner check list of Preview 2026.10.28. It starts from the six rows of Stable 2026.10.27 that were not run before that Stable, and adds the walk steps that the reviews of session 1 wrote for each changed screen. It holds at most 20 rows still to run. Each row is one task that no automated test covers, and a row that a test comes to cover is deleted. A failed row is a finding with a severity, and an open S1 or S2 finding blocks the Stable release that ends Phase 3.1. Every permission that the walk needs, such as computer use, the Finder grant or a privacy prompt, is the owner's own click.

The walk is planned for 2026-10-29 with the owner at the Mac Studio (O84), on the packaged Preview 2026.10.28. `SCR` is `/Users/dho/lungfish-phase-records/phase-3-1`. The steps of each new row are in the review that the Script column names, under `SCR/reviews`. The steps of the six carried rows are in `/Users/dho/lungfish-phase-records/phase-3-0/walk/REWALK.md`, and the log of that walk is `rewalk-log.md` beside it. The rows that passed for 2026.10.27 stay in `docs/reports/2026.10.27-owner-checks.md` and are not repeated. When this list was committed no row had been walked.

A row that names an old result needs a NAO-MGS result imported by Stable 2026.10.27 or earlier, with the results file it came from. Work on a copy of a project, never on the only copy of a result.
