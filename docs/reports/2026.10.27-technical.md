## The promotion

Stable 2026.10.27 promotes Preview 2026.10.26, which was published on 2026-10-27 from `7d7f8f63b` as build 11593. The promotion adds no product change, so the app holds the code of that Preview and only the release notes and these reports are new. It is the first Stable release since 2026.9.78 of 2026-10-02, and it includes the 26 Previews 2026.10.1 to 2026.10.26. The release notes reconcile the notes of those Previews. Where a later Preview changed or undid an earlier item, they give only where it ended, grouped by task. Preview 2026.10.26 replaced Preview 2026.10.25 as the build to promote, because the owner checks of 2026-10-27 found a wrong number in 2026.10.25 (DEMUX-STATS-BEHIND, S1) that 2026.10.26 fixes.

The owner check list of this release, `docs/reports/2026.10.27-owner-checks.md`, starts from the list of Preview 2026.10.26 and takes each result from the re-walks of 2026-10-27. Those walks ran on candidate `9478bd939` (build 11575), on the published build 11584 for the Illumina kit check and the rows run after that publish, and on the packaged Preview 2026.10.26 (build 11593) for DEMUX-STATS-BEHIND.

## Known limits that still hold

Each limit below is in the notes or the technical record of the Preview it names and still holds at 2026.10.26. A limit that a later Preview closed is left out. The full words are in that Preview's notes or record.

| Area | Limit | Preview |
|---|---|---|
| Quality scores | Binning cannot be undone once the original files are gone. The app's in-place ingest of a downloaded file and its single-file import offer no None choice (BIN-NONE-ROUTES, S3). | 2026.10.23, 2026.10.25 |
| Quality scores | Every BBTools step stores a called Q0 or Q1 as Q2. Merge stores scores above Q50 as Q50 in pairs it cannot merge, and BBMap writes alignment base qualities above Q50 as Q50 (BBTOOLS-QIN, S3). | 2026.10.25 |
| Quality scores | Only imports refuse Phred+64, and a Phred+64 file trimmed to no score below Q6 passes the refusal and is stored 31 too high, which BIO accepted. | 2026.10.25 |
| Demultiplexing | IDT for Illumina UD Indexes stops with words until its built-in sequences are checked, and a custom list that gives one sequence two names stops. | 2026.10.25 |
| Counts | NVD `unique_reads` still counts with `-F 0x404` (`MetagenomicsImportService.swift:2177`), which is S1 if an NVD BAM holds secondary records. | 2026.10.25 |
| Time limits | kraken2 stops at 2 hours, Bracken at 1 hour, the scrub's human-read filter at 2 hours, a recipe's deduplication at 1 hour, and the mappers, MAFFT and assembly at up to 24 hours. Which fixed limits to lift needs a decision (TTL F1, S2). | 2026.10.25 |
| Extract and BLAST | They compare read names and lengths, not bases or scores. A result made before 2026.10.25 records no file sizes, and a result classified from FASTA reads is refused as changed reads (READ-IDENTITY, S3). A result made in another project reads the open project's reads of the same name and place, and after a new import under the same name BLAST needs the result reopened. | 2026.10.25 |
| Extract and BLAST | A zero-read Extract ends Failed in the Operations Panel. A TaxTriage row with no reference still lets BLAST Verify answer after the click (TTFUZZY F1, S3). A Kraken2 batch opens with every sample picked, so Extract asks for one sample. | 2026.10.23, 2026.10.25 |
| Operations Panel | Cancel stops a run at once with no question. | 2026.10.25 |
| Mapping | A pool that mixes interleaved pairs with R1 and R2 files, or compressed with uncompressed bundles, is refused. | 2026.10.23, 2026.10.25 |
| Mapping numbers | A renamed mapping, some older ones and every filtered track have no saved numbers and are measured when opened. The Per-Chromosome list counts alignments (MAPPED-READS F1, S3), and a bundle whose statistics lack flagstat read lines keeps alignment counts. | 2026.10.25 |
| Older bundles | Nanopore bundles imported earlier are measured again when opened, and project search keeps their old numbers until they are imported again. An older demultiplexed, trimmed or filtered read set is counted the first time it is opened in each launch and the result is never written back. Selecting another item stops the count, which starts again when you come back. | 2026.10.25, 2026.10.26 |
| Read statistics | The metadata section writes its file with no error shown, so an edit to a read set on a read-only volume is lost with no words (review backlog, S3, already in Stable 2026.9.78). | 2026.10.26 |
| Images | Single-base zoom leaves out base letters. Above 1,000 bases per point an image leaves out the Depth track and says so, and several alignment tracks get one Depth track each. Reads draw only at about 2 bases per point or less, at most 75 rows, and every read track and sample of the result is drawn. A reference wider than the fetch cap shows a plain line. | 2026.10.22, 2026.10.23, 2026.10.25 |
| Annotations | A region extracted to a new bundle keeps no annotations, and its record does not say so. One missing annotation database of several shows no words (DRAWER finding 2, S3). Show Drawer shows nothing while no mapped contig row is selected (DRAWER-ROUTE, S3). The viewport clear does not close an open annotation drawer, so beside a loose sequence document it can stay next to the measuring spinner, and it holds annotations, never a read-set number (review backlog, S3, not walked). | 2026.10.22, 2026.10.25, 2026.10.26 |
| GFF3 | A list item that holds a comma is written as two items, a qualifier outside the five list keys joins with encoded commas, and a feature named by another attribute still gets a Name. | 2026.10.25 |
| Pairs | A file that holds pairs and single reads is recorded as single reads with roles, and a taxa extraction's per-file record is retired with the plain file (PAIRING, S3). Long reads in a file or derived bundle with no recorded platform can still be read as pairs when an id repeats. | 2026.10.22, 2026.10.25 |
| Projects | A project renamed in Finder while open, with a new folder made at its old path, opens a second time for editing (PROJECT-LOCK, S3). A mapping opened outside a project asks where to save a consensus bundle, and `lungfish-cli assemble --reference-bundle` refuses an output bundle that exists. | 2026.10.25 |
| Classifiers | A stopped EsViritu run keeps up to about 15 GB of working files until Remove Partial Output…, and a long one has no time limit. After a Kraken2 batch shows its first sample, the sidebar and Provenance tab stay on the earlier item. A TaxTriage row whose sample has no accession is left out of Extract even when its BAM holds reads. A result imported by an earlier version stays in Imports until imported again. Copies and exports write EsViritu Identity as a fraction. | 2026.10.17, 2026.10.22, 2026.10.23 |
| Downloads and archives | Downloads need an open project. An archive whose link has an absolute target is refused even when the target lies inside it. A cancelled CZ-ID import can leave a half-written bundle. | 2026.10.22 |
| Assembly | MEGAHIT 1.2.9 can end a run on Apple silicon with exit -11 or -6. After a cancelled Reassemble, a failure in the same output folder names a line of the cancelled run's `spades.log`, such as `Mode: ONLY assembling (without read error correction)`, while `assembly.log` holds the real error (`ManagedAssemblyPipeline.swift` `failureDetail`, S3 REASSEMBLE-STALE-SPADES-LOG). | 2026.10.22, 2026.10.26 |
| Variants and annotations | Variant files imported earlier answer the High Impact filters slower with no chip counts. A coding feature of several segments imported earlier is read from its first base, and a reverse-strand feature cut at its sequence end does not record the cut length. | 2026.10.22 |
| Records and exports | A signing key does not sign every record, and a run with no key leaves a signed record unsigned. Records an earlier `lungfish-cli` wrote keep mode 0600. A viewer export keeps a full copy of its inputs in `.lungfish-export-inputs`. A bundle that took several adopted mappings or GATK calls before 2026.10.22 keeps only the last run record. | 2026.10.22 |
| Projects and copies | Cancelling a copy between projects on two disks, or on a disk that is not APFS, can leave a staging folder in the target project's `.tmp`. Cancelling a very large item with a record can take several seconds. | 2026.10.22 |
| Imports | A VSP2 or wastewater import keeps a different read count than before 2026.10.23, so compare counts within one release. A large short-read import needs free disk of about five times its read files, and the Trim Galore choice clumps with no disk check. Two imports of one large sample can store a different read order. A failed step of a legacy recipe reads as an unknown recipe error. | 2026.10.23, 2026.10.24 |
| Linux plans | Lungfish does not ship the tool image, and the Docker route needs a script from the source. A plan with no `--platform` is planned as short reads, and Ultima reads read as Unknown. `run-local.sh` retries nothing. Job disk and memory rest on small samples, the automatic release of a held job has not been seen on a pool, and the default requirements name an attribute of the pool we tested. The adopted bundle keeps the plan's platform. | 2026.10.24 |
