- KI-1, the restored contig, narrows in the notes. The narrowing came with VS-MAP-RACE, which 2026.11.17's build already carried. `held(from:)` (`ViewerViewController+ViewMemory.swift:50-51`) keeps no selection only when a visit ends on its start selection, so a click on row 1 of a result that opened with no row selected is a pick (ux-text's `UX-WR1B-17R.md`).
- KI-2, the changed-data line, closes for both kinds (manager, 2026-11-24 17:36 CST). VS-REF-LINE puts a reference's line in flow between the gene tab bar and the canvas, and VS-LINE-HIDDEN hosts a mapping result's line in the viewport's detail area, so it shows with no contig on show. At full height the annotation drawer can run past the canvas by the line's height (S4, `VS-REF-LINE.md:131-132`).
- KI-4, no Reset View, closes.
- The Inspector half of 2026.11.17's "Not yet" item closes. Primer analyses and primer orders, PDFs, Quick Look previews, a FASTA file opened by itself and status pages still keep no view (`ViewStateDeclaredGaps.swift:18`, ceiling 6).
- A file opened outside any project keeps no view (VS-LOOSE-READ).

These stay open beside the notes' lines.

- Not kept yet, as in 2026.11.17. These open at their defaults, and none changes a result. Mapping (haploid mode, the shown track and a drawn region).
