# Lungfish 2026.10.25 owner check list

This list gates the Stable release of Phase 3.0. It began as the check list of Preview 2026.10.24 and holds at most 20 rows still to run. Each row is one task that no automated test covers, and a row that a test comes to cover is deleted. A failed row is a finding with a severity, and an open S1 or S2 finding blocks the Stable release. Every permission that the walk needs, such as computer use, the Finder grant or a privacy prompt, is the owner's own click.

The packaged walk of 2026-10-26 ran the first list. A row that passed on it moved to the last section, a row whose screen a later fix changed was rewritten from the review's re-walk rows, and rows that test one screen were merged.
