## The release

Preview 2026.11.8 is the Preview of the trust session of 2026-11-12 and 2026-11-13 (`docs/plans/2026-10-02-architecture-program.md`, section The trust session). It carries the result fixes that the session's sweeps, probes and reviews found in Stable 2026.11.7, the table that tells a person a result came from a faulty version, and the words of a run that was stopped for memory. No stable release is built in the session.

The version. `scripts/release/release.py` does not name the next version. `release_version()` in `scripts/release/release_version.py` returns the highest `YYYY.M.PATCH` among the committed notes files, and `_validate_release_notes` requires that file to hold `Channel`, `Previous versioned release`, `Stable baseline` and `Dependency set` lines and the heading Dependency versions. The patch counter runs across channels (Preview 2026.11.6, then Stable 2026.11.7), so the file `2026.11.8.md` makes the version 2026.11.8. The month part moves only when a release is made in a later month. The Stable baseline line reads v2026.11.7, the newest Stable tag.
