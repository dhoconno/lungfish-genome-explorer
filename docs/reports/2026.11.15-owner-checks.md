# Lungfish 2026.11.15 owner check list

This is the owner check list of Preview 2026.11.15. It holds six checks of the cell map view that need your hands or ears, and no automated test covers them. The walk ran F1 and F5 and the default view of F2, so four rows stay for you under Checks still to run, and F2 there is only its switch to UMAP. It is written new for this Preview and carries no older list. Each row is one task of about two minutes (F3 and F4 about three), and a row that a test comes to cover is deleted. The rows block no release. A failed row is a finding with a severity, and an open S1 or S2 finding blocks the next stable release. Severity follows `docs/contracts/SCOPE-AND-DELIVERY.md`. S1 is a false number, a silently wrong result, silent data loss or a crash. S2 is a common task that fails or a failure that shows no words. S3 is a rare task that fails or words that mislead. S4 is appearance.

Work on the copies in the walk folder `~/LGE-GUI-Walk/2026-11-20-5-5`, never on the only copy of a result. `PREP-A.md` in that folder holds the numbers each row compares with. The Result column holds the answers of the walk and of your run, filled in after them.
