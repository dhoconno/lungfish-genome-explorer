From `v2026.11.18` (`01ee336aa`) to the code head `cf50eefef`, `main` has 394 commits. Most are the docs-refresh landing (`538803a2d`, `docs/user-manual` and `docs/plans`). ## What landed

- **TaxTriage, all organisms** (`d5a95ec57`, with `ee04ea4bc` for the help golden and a size row). `TaxTriageConfig.allOrganismsTopHitsCount` is 1,000,000, which `get_top_hits.py -t` caps each rank at, so every species of the Kraken2 report is chosen. The wizard's All organisms toggle is on by default and sends it; the stepper runs 1 to 1,000. `topHitsDisplayValue` reads All in the Inspector and provenance rows and the CLI summary.
- **TaxTriage, Unique Reads at MAPQ 5** (`d5a95ec57`). `build-db taxtriage` counted Unique Reads with `samtools view -c -F 0xD04` and no MAPQ floor, while `# Reads Aligned` counts reads of MAPQ 5 or more (TaxTriage `minmapq = 5`). The count of a row whose BAM count exceeded its Reads stays NULL (3.2 TTREADS, BIO ruling F1), so MAPQ 0 multi-mappers turned most rows into a dash. The count now passes `-q 5` (`TaxTriageConfig.defaultMinMappingQuality`). On SRR12486983 (cornea, top hits 10) the NULL rows went from 112 of 130 to 10 (6 with no accession), and from 54 of 63 to 4 on SRR12486989. HSV-1 (NC_001806.2) reads 1,220,072 unique of 1,480,825 aligned, where the floorless count was 1,616,920. Test: `BuildDbTaxTriageOrganismReadsTests.testTaxTriageUniqueReadsApplyTaxTriageMappingQualityFloor`. A database built by an older version keeps its counts until it is built again.
- **RNA-seq reference sets** (`75925afbc`, `93bb89a6c`, `393384f85`, `8ea8a6f44`, `7494ff0f6`, `64ec2cf7f`). `lungfish-cli rnaseq install-reference --default <id>` checks salmon, gffread, memory and disk, downloads the genome and GTF, checks each sha256, builds the set through `ReferenceSetOwner` and the k 31 genome-decoy salmon index through `SalmonIndexCache`. Plugin Manager > Databases gets RNA-seq Reference Sets with `human/gencode-50` and `mouse/gencode-M39` (new pinned default). The count pane's empty state links there. The label renames are Count Reads per Gene, Export Counts and Analysis Scripts, Existing Bulk RNA-seq Counts and Existing Single-cell Counts. Scope and the BIO, UX and ARCH rulings: `docs/reports/2026-11-26-rnaseq-novice-path/`. Evidence: the human install took 63 minutes on galah, peaked at 19.8 GB of memory and keeps 17.4 GB; 1 M pairs of SRR896663 counted in 35 s with 85.3% mapped (`EVIDENCE.md`). The mouse files were downloaded and their sha256 pinned, but its set and index were not built.
- **GTF-WORDS-SHEET-LOSES-SAVE-PANEL** (S2, `6c7b00cef`, `6f691bb3c`, `86900e767`). The old-GTF words sheet shows only after the save panel returns a file.
- **PROVSIGN-KEYCHAIN-KEY-UNUSED** (S2, `bdd202f5a` red, `1fcadf11f`). The Settings status words follow what the writers do: signed only from `LUNGFISH_PROVENANCE_SIGNING_KEY` or `LUNGFISH_PROVENANCE_SIGNING_KEY_FILE`, and the Provider and saved key are not used. Wiring the saved key is S3 PROVSIGN-SAVED-KEY-WIRING (`SCR reports/PROVSIGN-KEYCHAIN-KEY-UNUSED.md`).
- **PACK-REMOVE-ALL-ENV-NAME** (S2, `89c9ac200`, `f32d9f294` red, `cf50eefef`). Remove All reads `PluginPack.installEnvironmentNames`, so GATK Core (`gatk-core`), Variant Phasing (`phasing`) and Single-Cell (`sc-embed`) are removed.
- **Release tooling** (`eecce4d50` to `e5dbef25a`). A patch mode for `package stable` and `publish stable`. No change to a Preview's path.
