## The release

Preview 2026.10.28 closes session 1 of Phase 3.1, the view-switch and alert quality net, database identity for the classifiers and the start of the ViewportHost migration. It builds on Stable 2026.10.27 (build 11609 from `2aab8bf5d`, `origin/main` at `05e50d234`) and holds 151 commits of the program branch `phase-3-1`. Eight cherry-pick landings (LAND-1 to LAND-8) reach the program head `533416a10`, which is the base of this record. Two more landings follow that head. LAND-9 is the release loop and test isolation, described under The release loop, and LAND-10 holds the MSA pane flag fix, the column-layout keys that two test classes left and the three files of these notes. The owner's answer O85 allowed one Preview at the end of session 1, and the walk of this Preview is on the owner check list.

The candidate gates run after this record is committed, so it gives no result of them. The gate logs of the candidate are named in its release record.
