# Lungfish 2026.10.5

Channel: Preview

Previous versioned release: v2026.10.4

Stable baseline: v2026.9.78

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release gives tree building a home in the Tools menu and rebuilds the Build Tree with IQ-TREE dialog. Trees now come with support values, a recorded seed, and a root on the outgroup you choose, and the Inspector shows how each tree was made. Two fixes reach the whole app. Menu items now turn on and off as they should, and tool runs in the Debug build no longer hang.

## Build Tree in the Tools menu

**Tools > Alignment & Phylogenetics > Build Tree with IQ-TREE…** builds a tree from the alignment open in the viewport, or from one alignment selected in the sidebar. The submenu that held MAFFT, once called Multiple Sequence Alignment, is now Alignment & Phylogenetics. With no alignment open or selected, the item is greyed out and its tooltip says "Open or select an alignment to build a tree." The right-click item in the alignment viewport opens the same dialog, and VoiceOver offers Build Tree with IQ-TREE… as an action on the alignment and its row names.

## A rebuilt Build Tree dialog

The dialog now groups its settings under Inputs, Model, Branch Support, Rooting, Output, Run and a collapsed Advanced group, and every field is named for VoiceOver by its visible label.

- **Build from** chooses the whole alignment or the selected rows and columns, with the counts in each choice. IQ-TREE needs at least 3 sequences, and support needs at least 4.
- **Model** is a pop-up. Find best model (ModelFinder) is the default, followed by four fixed DNA or protein models and Custom… for any other IQ-TREE model.
- **Sequence type** offers Detect automatically, DNA, Codon or Protein to suit the alignment. Codon adds a **Genetic code** choice of Standard or Vertebrate mitochondrial, for coding genes from human or macaque mitochondrial genomes.
- **Outgroup** lists the sequences in scope as tick boxes. The tree is saved rooted on them, which sets where the root sits without changing which sequences group together.
- A line at the foot of the dialog says what still blocks **Build Tree**, such as a seed that is not a whole number.

## Defaults that change your results

Five defaults change what a tree run gives you, so a tree built now can differ from one built with an earlier release.

| What | Before | Now |
|---|---|---|
| Branch support | Off unless ticked | Ultrafast bootstrap (UFBoot) and SH-aLRT both on at 1000 replicates, IQ-TREE's recommended pair. UFBoot 95 or higher and SH-aLRT 80 or higher indicate a well-supported clade |
| Threads | IQ-TREE chose a count | 1. One thread gives the same tree on every run. More threads can be faster on large alignments, but IQ-TREE then gives slightly different branch lengths each run |
| Seed | Blank meant no record of the seed | A blank Seed field draws a seed, and the seed is always recorded in the command and the Inspector, so any run can be repeated |
| Tip names | Names as IQ-TREE rewrote them, with spaces and some punctuation changed | The alignment's own row names, even names with spaces or brackets |
| Rooting | Always unrooted, rooted afterwards by hand | Rooted on the outgroup when you tick one |

On the five primate mitochondrial genomes in the Genes and Sequences demo project, rooted on the two macaques, the run with Seed 1 and one thread gives human and chimpanzee together with support 99/100, gorilla next at 100/100, and the model TPM2u+F+I chosen by BIC.

## Reading support and the Inference section

When both tests run, each node shows the pair as IQ-TREE writes it, SH-aLRT first and UFBoot second, such as 99/100. The Nodes drawer has one column per test in place of a single Support column, and Support Type reads SH-aLRT/UFBoot instead of unknown. Colouring branches by Support now shades by UFBoot, blue for 95 or higher, orange below, and grey for no value, with a legend on the summary line. A tree built without an outgroup says "Unrooted (drawn root is arbitrary)" so the left edge of the drawing is not mistaken for a root.

A tree built in LGE now carries an Inference section in the Inspector. It lists the IQ-TREE version, the model you asked for, the best-fit model and the score that chose it, the sequence type, both support tests and their replicate counts, the outgroup, the seed, the threads, the scope of the alignment used, and the log-likelihood, with links to IQ-TREE's own report and log.

## Tree node commands in the menu bar

**Selection > Tree Node** holds the ten node commands of the tree viewport's right-click menu, such as Root on Selected Branch, Extract Subtree as New Bundle… and Copy Subtree as Newick. They work while the tree or its Nodes drawer has focus and a node is selected, so the tree can be worked from the keyboard. VoiceOver reads each node with its branch length and support, and offers the same commands as actions.

## Command line changes

`lungfish-cli tree infer iqtree` gains `--outgroup`, `--alrt`, `--safe` and `--keep-identical` as documented flags, and accepts `CODON1` to `CODON25` for `--sequence-type`. `--seed` takes 1 to 2147483647, and a run without `--seed` records the seed IQ-TREE drew as `effectiveSeed`. `--threads` is passed to IQ-TREE, and leaving it out runs with `-T AUTO`, which does not reproduce a tree exactly. `--bootstrap` must be 1000 or more. `MF`, `TESTONLY` and other model strings ending in `ONLY` are rejected because they build no tree. Flags in `--extra-args` that have their own option, such as `-T`, `-m`, `-B` or `-o`, are rejected with a message naming that option. `--extra-iqtree-options` is now a hidden alias of `--extra-args`.

## Menu items turn on and off correctly

Many items in the app's menus that depend on what is open or selected were never greyed out, because a check the app relied on was never called. That check now runs, so items that cannot act on the current selection are greyed out, and some show a tooltip explaining what they need.

## Debug tool runs no longer hang

When the Debug build was set to share Lungfish Preview's tool folder, a tool run could hang for minutes before starting because the app tried to change the permissions of the shared micromamba program and macOS waited on a consent prompt. The app now leaves the program alone when it can already run, so MAFFT, IQ-TREE and the other managed tools start straight away.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.10.4. The phylogenetics pack still provides IQ-TREE 3.1.3.
