# Lungfish 2026.9.57

Channel: Preview

Previous versioned release: v2026.9.56

Stable baseline: v2026.9.54

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release keeps unfinished analyses out of the sidebar, keeps your folder paths and account name out of the records LGE writes into a project, and fixes the problems found by clicking through every feature the manual describes.

## Unfinished analyses stay out of the sidebar

- **An analysis result appears in the sidebar only when its run finishes.** Opening a result while its run was still writing it could break the viewport, most visibly with TaxTriage. A run that finishes with warnings counts as finished. Failed and cancelled runs stay hidden. This covers TaxTriage, Kraken2, EsViritu, mapping, assembly, pbAA, Savont, Viral Recon, 12S matching and amplicon genotyping, whether the run starts in the window or from `lungfish-cli`.
- **Interrupted runs are listed in the Operations Panel.** If LGE or the Mac stops during a run, the next time the project opens the Operations Panel shows an Interrupted row with the run's size on disk. Remove Partial Output deletes it after you confirm. Reveal in Finder, Copy CLI Command and View Log are also available. LGE never deletes partial output on its own.
- Universal search no longer finds files inside an unfinished analysis.
- Results written by earlier builds are unaffected.

## Privacy

- **Project records no longer contain your private folder paths.** Provenance, run history, operation logs, alignment statistics, variant databases, BAM `@PG` lines, VCF headers and bundle manifests now write paths relative to the project (`@/...`), to the run workspace, to the managed tool and storage roots, or as `<external>/<file name>` for files outside the project.
- **Provenance no longer records your account name.**
- Run Again, `workflow run --repeat-from` and provenance export still work, including after a project is moved. Exported scripts mark any external file you need to supply. Projects written by earlier builds load unchanged.

## Fixes

- Completed FASTQ operations record their output, so the Operations Panel's Results button and Reveal Output Files work. A failed operation's log ends with its error, and the details title is no longer clipped.
- Removing a failed analysis run also removes its result folder.
- The mapping result's Track column shows track names, the Alignment Summary counts each alignment's reads once, primer-trimmed and duplicate-marked tracks are described as derived, and the mapping viewer has Variant Tracks toggles.
- The Provenance Source picker lists a mapping result's variant tracks, so their provenance can be opened from the Inspector.
- Ticking Hide high-gap sites in the Consensus section no longer clears the selected contig or disables Extract Consensus.
- Clicking a variant table column header sorts without opening the column menu. The menu opens on a right-click.
- The Analyses list shows readable settings instead of a raw parameter string.
- Call Variants defaults to the duplicate-marked track after Mark Duplicates.
- Demultiplex Barcodes starts on a barcode kit that matches the reads' platform.
- Save as Primer Scheme names the record, not an internal row id, and Primer3 order groups are named after the record accession.
- CZ ID imports record the sample name. Viral Recon's genome-wide coverage table has its own title.
- The Workflow Library no longer goes blank after scrolling or hangs after a workflow is switched on.
- A fresh install opens on the Welcome window's Required Setup card instead of an Update Tools sheet.
- Plugin Manager cards show the installed build's pack description. Help > Demo Projects attaches to the front window. The mapping dialog keeps its flag labels on one line.

## Documentation

- The MHC genotyping chapters use a de-identified cohort (Animal_01 to Animal_30).
- The manual describes when results appear and how to handle interrupted runs.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.56.
