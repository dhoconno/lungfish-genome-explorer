# Lungfish 0.5.0-alpha16

Previous release: v0.5.0-alpha15

## Nightly Alpha Release

This automated nightly alpha release integrates Codex and Claude agent worktrees
into `main`, publishes a notarized Apple Silicon DMG, and updates the Sparkle
alpha appcast for testers.

## Summary

This nightly build changes how release-note summaries are produced for the alpha pipeline. Narrative release notes are now authored by the Codex automation before the local release script runs, so the human-readable summary comes from the interactive automation layer rather than from a standalone script dependency.

The local nightly release script remains deterministic and model-free. If a release note has already been prepared for the next alpha, the script now preserves that file instead of overwriting it, which keeps the Codex-authored summary intact through version bumping, build, signing, and publication.

Highlights: Codex-authored nightly summaries, preserved prewritten release notes, deterministic local release script.
