## Multiple sequence alignment viewport

The alignment viewer now lets you return to consensus comparison after choosing a sequence as the reference. Changing the comparison target affects the display without changing the alignment or its exported sequences.

Vertical scrolling works across the whole sequence row, including names and coordinates. The active comparison row, showing either the consensus or the selected reference, stays pinned above the sequences while scrolling. The scrolling sequence list no longer leaves empty rows where the comparison header used to be.

## Project lock recovery

A dialog replaces the technical lock warning in the window header. When a project's lock cannot be resolved automatically, choose Open Read-Only, Cancel, or Recover and Open where recovery is available. Recovery requires confirmation for unrecognized or damaged locks, retains the original lock and a recovery record, and refuses locks belonging to a verified active local process.

New locks record a stable Mac identifier so network and VPN hostname changes do not obscure local ownership. Confirmed stale locks from the same user and Mac can be recovered when opening for editing. A competing writer's lock is preserved.

Cancelling or superseding a project-open request dismisses its lock dialog. Recovery rechecks the captured lock before changing it, and filesystem recovery checks the project folder identity again after the dialog.
