# Lungfish 2026.9.48

Channel: Preview

Previous versioned release: v2026.9.47

Stable baseline: v2026.9.28

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release makes the Operations Center easier to follow, preserves sequence formats during processing, and fixes tools that were reading the original reads instead of a derived bundle's transformed or selected reads.

## Follow operations and inspect their results

- Progress shows the operation's state, including completion, failure, cancellation, and completion with warnings. Percentages and remaining-time estimates appear when supported by meaningful progress evidence; work without a reliable estimate shows its current activity and elapsed time.
- The latest captured log message remains visible in each operation row. A **Log** button opens a resizable drawer, and **Results** selects an available result in the main viewer.
- Operation, Progress, and Time use consistent system typography and alignment. Status symbols provide color cues alongside readable status text.
- The drawer shows the recorded command above the log without a Details checkbox. Log text uses a smaller monospaced default and can be enlarged or reduced.
- Live logs follow new output. Selecting text or scrolling back pauses the log view, not the operation. **Reviewing log history** and **Resume live log** make that distinction explicit, with a count of new entries waiting to be shown.
- Native primer workflows now forward tool output during execution while retaining their diagnostic files. Timestamps older than 24 hours include the date.

## Preserve FASTA and FASTQ through processing

- Orient Reads and other compatible processing operations preserve the input sequence format: FASTA remains FASTA, and FASTQ retains its quality information whenever the tool supports it.
- Shared format handling restores FASTA after tools that temporarily require synthetic FASTQ. Demultiplexed FASTA results also remain FASTA.
- Mixed FASTA/FASTQ batches retain the format of each input. Operations that intentionally produce a different kind of sequence, such as translation, keep their documented output format.
- Conversion and import provenance retain the executed commands, checksums, and required intermediate files.

## Use the actual reads in derived bundles

- Multiple sequence alignment uses a derived bundle's oriented, trimmed, or selected reads rather than silently returning to the original input.
- Derived-input handling is also corrected for genotyping, Savont clustering, and the sequence count shown before alignment.

## Detect changed alignment evidence

- The viewer now queues another integrity check when an alignment evidence file changes during an existing checksum check. This prevents a timing race that could leave replaced evidence and cached reads appearing current.

## Remove experimental workflow interfaces

- The experimental Workflow Builder and the Kraken2 workflow-template prototype introduced in 2026.9.47 have been removed from the app and CLI. Their documentation has been retired. Existing scientific result bundles remain available.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap pins are unchanged from v2026.9.47.
