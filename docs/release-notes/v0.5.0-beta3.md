# Lungfish 0.5.0-beta3

Previous release: v0.5.0-beta2

## Highlights

- Fixed the TaxTriage batch result viewport so rows without BAM alignment data no longer open an empty miniBAM detail pane on initial selection.
- Preserved miniBAM detail behavior for TaxTriage rows that do include BAM paths and accession mappings.
- Added smoke coverage for collapsed no-BAM TaxTriage rows and visible BAM-backed TaxTriage rows.

## Notes

- This release is a focused follow-up to v0.5.0-beta2 for the TaxTriage display regression.
