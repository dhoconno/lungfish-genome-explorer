# Lungfish 0.5.0-beta29

Previous release: v0.5.0-beta28

This beta restores reliable mapping-result publication and integrated BAM
viewing for projects stored on ExFAT volumes. It also carries forward the
portable Kraken-index recovery added after the original beta28 release.

## Publish mapping viewers reliably on external drives

Read mapping could finish successfully, write a valid sorted and indexed BAM,
and then report `File exists` while Lungfish prepared the lightweight reference
bundle used by the integrated viewer. The failure occurred after minimap2, not
inside the mapper. ExFAT exposes AppleDouble companion files for extended
metadata, and the recursive clone operation could collide with those visible
sidecars while copying a reference bundle.

Lungfish now keeps the fast clone path where it works and retries only this
specific collision with a data-and-stat copy that does not reproduce extended
attributes. The retry first removes only its incomplete candidate tree and
continues to reject unrelated copy failures.

## Complete viewer publication on filesystems without Darwin rename extensions

ExFAT also rejects the Darwin `RENAME_EXCL` operation used to publish a newly
prepared viewer directory. First-time mapping-viewer publication now uses
Lungfish's existing portable exclusive-rename implementation, which reserves
the destination before the same-volume rename and preserves the established
identity checks. Native atomic swap remains unchanged for replacement and
rollback, so this compatibility fix does not weaken existing-bundle safety.

Published mapping results contain materialized genome, annotation, alignment,
index, metadata, and provenance payloads rather than symlinks into the source
reference. Stored paths and imported BAM provenance are rehydrated to the final
viewer location, allowing the mapping analysis to open directly in Lungfish.

## Keep Kraken indexes readable on ExFAT

The beta28 recovery for Kraken2 index databases is included in this version.
Legacy self-contained indexes can be opened read-only without changing their
bytes, nonempty WAL content remains protected, and newly built indexes are
finalized in portable DELETE journal mode without WAL or shared-memory
sidecars. Query failures fail closed instead of returning partial read-ID sets.

## Verification and release confidence

Regression coverage exercises AppleDouble collisions, fallback failure
propagation, portable exclusive publication, native replacement behavior,
symlink rejection, rollback, provenance rehydration, and checksum validation.
The complete publication pipeline passed on the affected AJL-T7 ExFAT volume.
A fresh barcode33 minimap2 workflow launched from Lungfish processed 603,516
reads, aligned 1,051 of them, published its viewer bundle, and displayed all
three reference contigs in the integrated BAM viewer; both the analysis BAM and
imported viewer BAM passed
`samtools quickcheck`, and every canonical provenance file descriptor matched
the published file's SHA-256 and size.

The app, embedded command-line tool, Help Book, and managed-tool metadata now
report `0.5.0-beta29`. This is a signed and notarized Apple Silicon beta DMG,
published through the Sparkle beta feed with the legacy alpha bridge so older
installations can discover the update.
