# Lungfish 2026.10.7

Channel: Preview

Previous versioned release: v2026.10.6

Stable baseline: v2026.9.78

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes two problems reported with the classifiers. The NCBI Taxonomy database can be downloaded again, and Viral Recon no longer stops before it starts in projects that hold an older copy of the SARS-CoV-2 reference.

## NCBI Taxonomy downloads

Downloading NCBI Taxonomy from the database manager failed every time with "Prepared database payload is invalid: missing or empty hash.k2d". LGE checked the downloaded taxonomy as if it were a Kraken2 database, which it is not. It now checks for the taxonomy name and hierarchy tables the download actually contains, so the download completes and Kraken2 results can resolve taxon names again.

## Viral Recon in projects with an older reference

In some projects, Run in the Viral Recon dialog stopped with "Could not prepare Viral Recon" followed by "StageError error 1", for one sample or several. The project's Downloads folder held a reference named MN908947.3 that an earlier release had downloaded as the equivalent RefSeq record, NC_045512.2. Every bundled primer scheme is written against MN908947.3, so no primer could be matched to it.

LGE now reads the sequence name inside that reference before using it. If it is not MN908947.3, LGE moves it to the Trash and downloads MN908947.3 again when the run starts. If a primer scheme and a reference still disagree, the message now names both sequences and says what to do, in place of the error number.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.10.6.
