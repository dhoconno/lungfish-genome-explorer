## MiSeq genotype Excel export on ExFAT

MiSeq genotyping could finish read mapping and genotype analysis, render its
Excel workbook, then fail while checking the renderer's `stdout.json` on an
ExFAT project volume. ExFAT can assign a new synthetic file identity when an
initially empty log receives its first data. The exporter now checks the
current identity of the held writer and the reopened file before accepting
that change. A replaced file still fails the check.

Workbook receipts, captured scientific inputs, replay scripts, checksums, and
failure cleanup remain identity-bound. Genotype calculations and report
contents are unchanged. An analysis that already failed at this check remains
incomplete and should be rerun with this build.
