# Lungfish 2026.9.73

Channel: Preview

Previous versioned release: v2026.9.72

Stable baseline: v2026.9.72

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release makes every command reachable from the keyboard and from VoiceOver, and makes provenance exports usable outside the machine that recorded them.

## Keyboard and accessibility

- **A new Selection menu** between Sequence and Tools holds the commands for the selected sidebar item and the selected table row, so they no longer need a right-click. Show in Inspector is Command-Option-S.
- **Sidebar shortcuts now work from the menu bar** while the sidebar has focus: New Folder… (Command-Shift-N), Duplicate (Command-D), Move to Trash (Command-Delete) and Select Siblings (Command-Shift-A). They do nothing while a text field has focus.
- **Every table's right-click commands are also VoiceOver actions** on its rows, each listed once and named as in the menu: the annotation and variant drawer, chromosome list, FASTA collections, reference records, taxonomy tables, EsViritu, NVD, NAO-MGS, TaxTriage, 12S, BLAST results, phylogenetic trees, the genotype matrix, primer results, sidebar items and Inspector rows. A row's action always acts on that row.
- **Pull-down buttons publish their menu items as actions**, for example the variant drawer's Profiles and Export buttons and the 12S Export button.
- **Return opens the selected row** in the chromosome list, FASTA collections and the variant table. View > Provenance Inspector is Command-Option-V. Operations > Selected Operation has Copy CLI Command (Command-Option-C), View Log (Command-Option-L) and Reveal Output Files (Command-Option-O).
- Track headers in the sequence viewer are keyboard-focusable disclosure triangles, and View > Show or Hide Annotations for Selected Track toggles the focused track.
- View > Expand All and Collapse All now work in the EsViritu, NVD and BLAST outlines as well as the taxonomy table.
- Long Inspector lists (MSA pairwise identities, primer binding rows, primer order oligos) are sortable tables, and the selected-variants list shows the first 100 variants with a count of the rest.
- Filter chips and swatches state their selection in words as well as colour, and the AI Assistant copy button meets contrast guidelines.
- **Shortcut changes:** View > AI Assistant moved to Command-Option-A. View > Document Inspector and the genotype Edit Comment… command lost their shortcuts, because macOS reserves Command-Option-D (Dock) and Command-Option-M (Minimize All). The genotype review marks are menu items under Tools > Genotype Review > Selected Cell with their existing Command-Option-P, X and R shortcuts.

## Provenance

- **Methods Section exports read as methods text.** Each tool appears once, in pipeline order, with its version, package and key parameters in plain language, and the lineage now starts at the reads (FASTQ import, mapping, then variant calling).
- **Snakemake, Nextflow, shell and Python exports run elsewhere.** Paths are relative to the project, tools come from conda environment files built from the recorded package pins, internal staging steps are folded away, and `snakemake -n` plans the demo project's workflow without errors.
- The Inspector's Provenance tab shows paths and commands relative to the project, labels intermediate files that were not kept, names index formats such as BAM index, and shows "development build" instead of "dev (0)". Copying a command still copies it exactly as recorded.
- LoFreq's version is recorded correctly, and a failed version check is recorded as unknown.

## Viewer

- The status bar's "Visible:" range updates as soon as you navigate. It used to show the previous range until the next redraw.
- Re-selecting the same mapping result or resizing the window keeps Focus mode, the selected contig and the region.

## Documentation

- The keyboard-shortcuts appendix lists the Selection menu and every new shortcut, and the classification chapters use the current command names.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.72.
