# Lungfish 0.5.0-alpha25

Previous published release: v0.5.0-alpha24

## Release Notes

This alpha refreshes AI-assisted macaque MHC haplotyping after a full OpenAI API
smoke run on the barcode05 ONT genotype bundle. The AI haplotyper now uses
compact, chunk-scoped knowledge-pack retrieval instead of sending the entire
FASTA and definition context with every prompt. Evidence chunks keep the
observed genotype calls and citations, while the prompt receives only the
allele, haplotype, and assay context needed for that chunk.

The CLI now supports debug-only AI haplotyping runs with chunk windows, so
later chunks can be tested without publishing a bundle revision. Provider
progress events, transient retry handling, clearer network/quota errors, and
resolved provenance options were added to make long AI runs inspectable and
reproducible.

The app's AI haplotyping path now mirrors the successful CLI settings: compact
knowledge packs, smaller observation chunks, larger structured-output budgets,
temperature 1.0, and additional provider retries. The replayable command preview
and provenance records include these resolved options.

Validation is stricter around current-call conflicts and safer around ambiguous
retain-current behavior. Conflicting current calls are preserved as reviewable
conflicts instead of being silently replaced, and the validation report records
normalization warnings that analysts can inspect before accepting AI output.

## Notes

- This release remains a prerelease build for testers.
- AI haplotyping calls must still be manually reviewed before downstream use.
- Existing deterministic and manual haplotyping workflows remain available.
