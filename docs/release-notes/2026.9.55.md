# Lungfish 2026.9.55

Channel: Preview

Previous versioned release: v2026.9.54

Stable baseline: v2026.9.54

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes MiSeq MHC genotyping on Macs without a system Java.

## Fixes

- **MiSeq amplicon MHC genotyping failed at the pair-merge step with "Unable to locate a Java Runtime".** When a cohort's Illumina inputs hold unmerged read pairs, LGE merges overlapping pairs with bbmerge before mapping. That step ran bbmerge without the Java that LGE installs with BBTools, so it only worked on a Mac that also had its own Java installed. It now uses the managed Java, like every other BBTools step. Rerun any genotyping cohort that failed this way. Nothing else changes, and results from successful runs are unaffected.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.54.
