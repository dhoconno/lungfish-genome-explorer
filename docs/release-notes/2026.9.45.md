# Lungfish 2026.9.45

Channel: Preview

Previous versioned release: v2026.9.44

Stable baseline: v2026.9.28

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes two ways that storing paired reads in one file could lose or scramble reads, and makes the Demo Projects window work with VoiceOver and the keyboard.

## Paired reads kept together

- **Pairs whose two reads share an identical name were separated when Optimize storage was on.** Many SRA downloads name both reads of a pair the same way. Storage optimization reorders reads to save space, and for these files it moved the two reads of a pair apart, so later tools no longer saw them as pairs. LGE now tells the reordering step when a file holds pairs, so both reads always stay together. If you imported such a file with Optimize storage on in an earlier release, import it again.
- **A file with an odd number of reads lost its last read** during storage optimization or quality score rounding. Every read is now kept, and LGE checks that the read count is unchanged before it deletes the original file.
- A file that mixes merged reads with pairs is now optimized as pairs plus single reads, instead of being treated as all pairs.
- The paired-end merge step, deduplication, primer removal, and error correction now state whether their input holds pairs, instead of guessing from read names.
- The Trim Galore storage option splits a file of paired reads into its two halves and trims them as pairs. It refuses a file that mixes merged reads with pairs and explains how to proceed, where before it broke the pairs.

## Demo Projects window

- **Every button and link in Help > Demo Projects… now works with VoiceOver and the keyboard.** Each one names its project, for example "Download and open Genes and Sequences", and the chapter links and Reveal in Finder can be reached with Tab when keyboard navigation is on.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap pins are unchanged from v2026.9.44.
