# Lungfish 2026.9.25

Channel: Preview

Previous versioned release: v2026.9.24

Stable baseline: v2026.9.4

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## PrimalScheme with a single reference sequence

PrimalScheme now accepts a native `.lungfishref` reference bundle containing one sequence as a one-row alignment. Selecting a reference in the project no longer excludes it from primer design. The workflow retains the source bundle, the normalized input, and their reproducibility records in the saved analysis.

## Clearer PrimalScheme names

Tool selections, invocation menus, and workflow messages now use the name PrimalScheme. The custom fork attribution remains in acknowledgements and technical provenance, including the exact runtime version and source repository.

## Export sequences with repeated chromosome names

Exporting selected sequences into a new bundle now handles repeated chromosome names. Repeated identifiers receive unique suffixes so the reference index can represent every selected sequence, and the export provenance records the original names and their exported counterparts.

## Dependency versions

Dependency set 2026.2 (2026-08-18) and all managed tool, optional pack, pipeline, database and bootstrap pins are unchanged from v2026.9.24.
