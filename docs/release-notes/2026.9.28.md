# Lungfish 2026.9.28

Channel: Stable

Previous versioned release: v2026.9.27

Stable baseline: v2026.9.4

Dependency set: 2026.2

Lungfish 2026.9.28 consolidates the user-facing improvements delivered through
Preview 2026.9.27. The 2026.2 managed dependency set remains the release set;
the SwiftPM and release-toolchain migration does not change dependency pins.

## Reliable projects and workflows

Viral Recon now completes on Apple Silicon, publishes an analysis bundle, and
shows primer-trimmed alignments, coverage, variants, and reports together. Its
wizard has focused defaults, validates advanced parameters early, handles paths
with spaces, records provenance, and recovers transient failures. MiSeq
genotyping restores paired-read and DR-locus handling and reports its inputs
clearly.

Project windows retain ownership across background loads and tool results.
Read-only and unavailable projects explain their state, cancellation and
recovery preserve earlier payloads where possible, and project locks have an
explicit recovery flow. Native bundles and supported imports/exports retain
their final payloads and reproducibility records. Workflow Library runs can be
reopened when their saved inputs and runtime remain valid.

## Sequences and alignments

The alignment viewer supports selected-row alignment, extraction, reference
comparison, readable names, stable scrolling, and export to bundles, files, or
the clipboard with captured provenance. FASTA and compressed-reference paths
used by primer workflows are normalized and retained with their source records.
Dead alignment controls were removed, and alignment display remains usable
after resizing and comparison changes.

## MHC genotyping and Excel reports

Full-length ONT matching is completeness-aware, and reference bundles can
resolve curated allele and locus names from sequence annotations. MiSeq review
includes clearer setup guidance, readable haplotype assignments, evidence
associations, matrix controls, audited overrides, deterministic haplotype
ordering, and explicit review state.

Genotype Excel reports capture the visible Lungfish projection, effective
H1/H2 calls, filters, comments, annotations, colors, stable identities, and
provenance. All worksheets remain editable for analyst review, while Lungfish
remains the scientific editing authority and reports are one-way exports.

## PCR primer design

The optional PCR Primer Design pack adds Primer3 and PrimalScheme workflows
with durable analysis bundles, primer and amplicon inspection, MSA match
summaries, coverage-panel selection, selected-primer exports, and IDT order
workbooks. Designs can use native references, aligned FASTA, one-row inputs,
and compressed single-sequence references; transformations and runtime details
remain in provenance. Primer3 remains 2.6.1 and PrimalScheme3-LGE remains
3.3.0+lge.2; coverage execution uses the explicit lge.3 contract.

## Release and storage behavior

The supported SwiftPM build and test path uses the Swift Build engine and
resolves products from that same engine. Release tooling uses Xcode 27 / Swift
6.4 with macOS SDK 27 and keeps macOS 26 as the minimum deployment target.

Compatible Preview and Debug installations can share managed dependencies when
their manifests and verified receipt match. Stable uses isolated managed-storage
and configuration roots and does not inherit Preview or legacy preferences.
Dependency verification and CI use isolated roots, and local release retention
is explicit, receipt-aware, evidence-preserving, and guarded against active or
unverified payloads.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database,
and bootstrap pins are unchanged from v2026.9.26. The optional pack remains
Primer3 2.6.1 and **PrimalScheme3-LGE 3.3.0+lge.2 (custom fork)** in separate
managed conda environments; coverage execution uses the explicit lge.3
contract. Other managed dependency pins remain unchanged.

## Known setup limitation

A first CLI-only setup in an empty managed-storage root can report a micromamba
bootstrap checksum mismatch because app packaging re-signs that executable.
The required environments can still finish installing. Rerun the same
`tools update --apply --yes --required-only` command and require successful
completion with no pending changes before using that root. This release does
not change or relax the pinned source checksum. The newly provisioned Stable
root on the release machine passed that follow-up check; clean one-pass setup
is not claimed.

## Operating system validation

Builds use macOS SDK 27 and retain macOS 26.0 as the minimum deployment target.
Local release and migration tests run on macOS 26.6.2. Runtime testing on
macOS 27 is deferred until a test machine is available; SDK compatibility does
not establish macOS 27 runtime validation.
