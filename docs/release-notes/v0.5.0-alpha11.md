# Lungfish 0.5.0-alpha11

## Highlights

This release is an internal architecture pass that generalizes the kernel plus
feature-module structure across the whole app. There are no intended user-facing
behavior changes; it is a structural refactor validated by the full test suite.

### Kernel and feature modules
- Renamed the shared UI kernel from `LungfishAppKit` to `LungfishKit`, since the
  preferred language of the project is Swift and the kernel is not specific to one
  UI framework.
- Promoted the shared UI and infrastructure into the kernel so feature modules can
  reuse it: the operation center and its operation model, the metagenomics drawer
  sizing and layout helpers, the classifier sample picker, the BAM mini-viewer, the
  brand color palette, the reference-sequence picker, and several smaller views.
- Extracted eight feature surfaces out of the monolithic app target into standalone
  modules, each with its own test target: Alignment, Assembly, NVD, NAO-MGS,
  TaxTriage, EsViritu, Genotype, and Phylogenetics. These join the existing 12S
  module from the prior cycle.
- The app target shrank by roughly 36,000 lines as those surfaces moved into modules.
  A change confined to one feature module now recompiles and tests only that module
  rather than the whole app.

### What stayed in the app
- The composition roots that wire the features together stay in the app target by
  design: the main split controller, the viewer, the inspector, and the sidebar.
  Extracting those is a separate effort, not part of this pass.

## Notes
No user-facing behavior changes are expected. The full test suite passes, every
module builds standalone, and the brand color values are unchanged.
