# Lungfish 2026.9.37

Channel: Preview

Previous versioned release: v2026.9.36

Stable baseline: v2026.9.28

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## MiSeq workflow choices

MiSeq analysis choices now present the two supported modes directly:
**Deterministic haplotyping** and **Genotyping only**. The unavailable AI preset
choice has been removed. Single-sample and cohort operations explicitly run
with `--genotype-only` stop after genotype generation, preventing bundled
defaults from activating haplotyping.

## MHC reference selection

The MHC reference picker now hides archived source FASTA files and displays the
readable bundle name for available references, making it easier to choose the
intended current reference without exposing stale source artifacts.

## MCM reference preparation

The maintainer utility `scripts/reference/prepare_mcm_workbook_reference.py`
supports readable allele identities and audited reconciliation between the
curated workbook and FASTA haplotype memberships while preserving the supplied
sequences and original source inputs.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database,
and bootstrap pins are unchanged from v2026.9.36.
