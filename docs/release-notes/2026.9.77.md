# Lungfish 2026.9.77

Channel: Preview

Previous versioned release: v2026.9.76

Stable baseline: v2026.9.72

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release makes read sorting by base work, lets the table drawer be resized from the keyboard, and labels mapping runs correctly in the Operations panel.

## Alignments

- **Sort by Base at Position now sorts.** Choosing it used to change nothing, because no position was ever set. Right-click a column in the read stack and choose Sort Reads by Base Here to sort the reads by their base in that column. The Inspector's picker follows the choice. Choosing Base at Position in the Inspector alone sorts at the centre of the view. VoiceOver's show-menu action on the read stack opens the same menu for the centre column.
- The manual now says the rarer base sorts on top, which is what the sort does. It said the opposite.

## Table drawer

- **The drawer under the viewer resizes from the keyboard.** Its divider takes keyboard focus, and the Up and Down Arrow keys make the drawer taller or shorter. VoiceOver can do the same and reads the height.
- View > Show Drawer (Control-Command-B) opens and closes the drawer. View > Make Drawer Taller and Make Drawer Shorter resize it.
- The drawer opens 300 points tall. A saved height under 200 points, which could show the Variants filters with no rows, is replaced by that default.

## Operations

- Mapping runs are labelled Mapping in the Operations panel and in a copied operation report. They were labelled Download.

## Under the hood

- Contributor and agent guides now describe how the modules fit together, where each kind of feature belongs, and the steps for adding an operation or a new analysis view. New checks before each push keep these guides, the module map and the feature list in step with the code. No scientific output changes.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.76.
