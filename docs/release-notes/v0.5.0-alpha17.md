# Lungfish 0.5.0-alpha17

Previous release: v0.5.0-alpha16

## Nightly Alpha Release

This automated nightly alpha release integrates Codex and Claude agent worktrees
into `main`, publishes a notarized Apple Silicon DMG, and updates the Sparkle
alpha appcast for testers.

## Summary

There are no new commits on `main` since `v0.5.0-alpha16`, so this nightly alpha
does not introduce additional product changes for testers to evaluate. This
release primarily rolls the version forward for the next signed alpha build and
keeps the standard packaging, notarization, and Sparkle publication flow current.

Highlights: no new code changes since the previous alpha, fresh signed build,
continued nightly release validation.

## Included Commits

- No code changes beyond the nightly release version bump.
