# Lungfish 2026.9.78

Channel: Stable

Previous versioned release: v2026.9.77

Stable baseline: v2026.9.72

Dependency set: 2026.2

This release makes every command reachable from the keyboard and from VoiceOver, makes provenance exports usable outside the machine that recorded them, opens exported workflow files as text, makes read sorting by base work, and fixes problems found while filming the learner videos. It collects Preview releases 2026.9.73 to 2026.9.77.

## Keyboard and accessibility

- **A new Selection menu** between Sequence and Tools holds the commands for the selected sidebar item and the selected table row, so they no longer need a right-click. Show in Inspector is Command-Option-S.
- **Sidebar shortcuts work from the menu bar** while the sidebar has focus: New Folder… (Command-Shift-N), Duplicate (Command-D), Move to Trash (Command-Delete) and Select Siblings (Command-Shift-A).
- **Every table's right-click commands are also VoiceOver actions** on its rows, and pull-down buttons such as the variant drawer's Profiles and Export publish their menu items as actions.
- **Return opens the selected row** in the chromosome list, FASTA collections and the variant table. View > Provenance Inspector is Command-Option-V. Operations > Selected Operation has Copy CLI Command (Command-Option-C), View Log (Command-Option-L) and Reveal Output Files (Command-Option-O).
- **Shortcut changes.** View > AI Assistant moved to Command-Option-A. View > Document Inspector and the genotype Edit Comment… command lost their shortcuts, because macOS reserves Command-Option-D and Command-Option-M. The genotype review marks are under Tools > Genotype Review > Selected Cell with their existing shortcuts.

Track headers in the sequence viewer are keyboard-focusable, View > Expand All and Collapse All work in the EsViritu, NVD and BLAST outlines, long Inspector lists are sortable tables, and filter chips state their selection in words as well as colour.

## Provenance

- **Methods Section exports read as methods text.** Each tool appears once, in pipeline order, with its version, package and key parameters in plain language, and the lineage starts at the reads.
- **Snakemake, Nextflow, shell and Python exports run elsewhere.** Paths are relative to the project, tools come from conda environment files built from the recorded package pins, and internal staging steps are folded away.
- The Provenance tab shows paths and commands relative to the project, labels intermediate files that were not kept, and names index formats. Copying a command still copies it exactly as recorded.
- **A Viral Recon result shows its provenance**, read from the record the run wrote beside its raw pipeline results.
- **Provenance exports start in the current project** instead of the last folder used.
- LoFreq's version is recorded correctly, and a failed version check is recorded as unknown.

## Viewer and alignments

- **Workflow and script files that macOS cannot preview open as read-only text**, including a provenance export's `main.nf`, `nextflow.config`, `Snakefile` and environment `.yaml` files. Text previews are capped at 2 MB, and binary files are never shown as text.
- **Sort by Base at Position now sorts.** Right-click a column in the read stack and choose Sort Reads by Base Here. The Inspector's picker follows the choice, and choosing Base at Position in the Inspector alone sorts at the centre of the view. The rarer base sorts on top.
- **The table drawer resizes from the keyboard.** Its divider takes focus and the Up and Down Arrow keys resize it. View > Show Drawer (Control-Command-B), Make Drawer Taller and Make Drawer Shorter join the View menu. The drawer opens 300 points tall, and a saved height under 200 points is replaced by that default.
- The status bar's Visible range updates as soon as you navigate, and re-selecting a mapping result or resizing the window keeps Focus mode, the contig and the region.

## Projects, import and operations

- **A new project's sidebar is empty until something is added.** LGE no longer creates an empty Primer Schemes folder. It appears when the first primer scheme is saved, and older projects hide an empty one.
- **A project that opens read only because it has no project store says why** in an Opened Read Only alert, with how to recover.
- The SRA and ENA import sheet shows the size the archive reports instead of "Zero KB".
- The Inspector names quality binning the way the import sheet does, for example "Illumina (7-level)".
- Mapping runs are labelled Mapping in the Operations panel. They were labelled Download.

## Documentation

- The keyboard-shortcuts appendix lists the Selection menu, the drawer commands and every new shortcut. The provenance chapter says exported workflows can be read in the viewer, and the Shared Projects and Troubleshooting appendices describe the read-only alert.
- Contributor and agent guides describe how the modules fit together and the steps for adding an operation or an analysis view. No scientific output changes.
