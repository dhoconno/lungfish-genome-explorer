# Lungfish 0.5.0-beta7

Previous release: v0.5.0-beta6

## Highlights

This beta makes large FASTQ imports more reliable on laptops and other Macs
that would otherwise go to sleep while work is in progress. Lungfish now holds
a scoped macOS user-initiated activity while a FASTQ import is running. This
prevents automatic idle system sleep without keeping the display awake, and it
is released immediately when the import completes, fails, or is cancelled.

This beta also fixes full-length ONT MHC genotyping and other BBTools-backed
FASTQ work on Macs without a separately installed Java runtime. Lungfish now
supplies the Java runtime managed inside its BBTools environment to every
BBTools execution path, including file-output and pipeline workflows.

## Notes

This remains a beta prerelease. A user-selected sleep action, closing a laptop
lid, or a low-battery or thermal emergency can still interrupt work; the new
activity only prevents automatic idle sleep while the import is active.

The release is packaged as a signed and notarized Apple Silicon DMG and
published to the Sparkle beta feed for testers.
