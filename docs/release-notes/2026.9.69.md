# Lungfish 2026.9.69

Channel: Stable

Previous versioned release: v2026.9.68

Stable baseline: v2026.9.65

Dependency set: 2026.2

This release makes primer designs save again inside a project, fixes problems found while retaking the user manual's screenshots, and ships the last of the retaken screenshots with the manual. It collects Preview releases 2026.9.66 to 2026.9.68.

## Primer design

- **Primer designs are saved again.** Since 2026.9.57, every Primer3, PrimalScheme, Olivar, and varVAMP design run inside a project finished its work and then failed with "Invalid primer analysis provenance: output inventory does not match". Designs saved before 2026.9.57 still open.
- **Off-target screening works in a project whose folder name has a space.** varVAMP qPCR and Olivar designs screened against a reference bundle failed with a BLAST database error in a project such as Primer Design.
- Expanding Discriminating Sites in an alignment's Inspector no longer widens the Inspector past its column and clips its text and controls. Its Exclusions choice is now a pair of radio buttons.

## Reads, mapping, and variants

- **Bundles imported from an ONT run folder can be mapped and assembled.** They recorded Oxford Nanopore only where mapping and assembly do not read it, so minimap2 would not run on reads without nanopore-style headers. Re-import a run folder imported with an earlier build, or set its Read Type once in the Inspector.
- **A primer trim started from a mapping result shows the trimmed track.** The viewport now stays on the reference bundle, and Bundle > Alignment Tracks in the Inspector lists the new track. Creating a deduplicated bundle had the same problem.
- **Variant tracks called with bcftools no longer read Incomplete in the Provenance Inspector.**
- The SRA Runs pane's Accession hint gives run accessions as examples.

## Operations and workflows

- **A failed FASTQ operation's row shows the tool's own error on one line.** The full text stays in the row's tooltip and log.
- **A workflow opened from Tools > Workflows starts with its own settings.** Its Result Name is the workflow's name, and its Project Reference is the reference selected in the sidebar.
- The Import Annotation Track alert is wide enough for its Reference, Track Name, and Track ID fields.
- BLAST Verify on an NVD contig says why it cannot run when the result has no contig FASTA.
- The action bar under an imported CZ-ID result names the import again, and the genotype Export to Excel save panel shows its title, Export Genotype View.

## Documentation

- The user manual's remaining screenshots were retaken on this release series, and captions and steps now match the current app, including where to drag to select a stretch of an alignment and how the 12S Project Reference menu lists a bundle you built.

## Included preview releases

Includes Preview 2026.9.66, 2026.9.67 and 2026.9.68. This release reconciles those previews' notes and the changes since Stable 2026.9.65. Stable promotion adds no further product changes.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from Stable v2026.9.65.
