# Lungfish 2026.9.21

Channel: Preview

Previous versioned release: v2026.9.20

Stable baseline: v2026.9.4

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## Genotype Excel reports

Genotype Excel exports now carry only analyst-authored sample, row and cell comments. Generated evidence and status commentary no longer appears as worksheet comments.

The All and Filtered matrices preserve the captured sample order and the ordered native identity, reference-metadata and read-total columns visible in Lungfish. Default layouts now start with **Genotype** or **Allele** plus **Total Reads**; Total Reads continues to reflect the full result even when samples are hidden. Historical MHC results retain their allele identity through the legacy metadata fallback.

The existing workbook layout remains intact: **Genotype Matrix - All**, **Genotype Matrix - Filtered** and **Export Metadata**, plus **Haplotype Calls** when the analysis has call content. The scientific source of truth, captured display state and durable export provenance remain preserved.

## Primer review

Individual oligo controls now reflect effective filtered visibility. An oligo excluded by another filter is shown unchecked and disabled, with a hover explanation; manual per-oligo controls are grouped under **Advanced**.

Scheme analyses with saved alignment data calculate MSA match summaries automatically. Scheme details, Results, primer hover text and Binding inspection report the match percentage and matching/comparable row counts, with comparison details available on hover. Gapped, unresolved or unknown sites are excluded from the denominator. The MSA percentage filter remains opt-in, and Primer3 results do not show scheme MSA status.

Overview and result views repeat less metadata and guidance. Explanatory details remain available through contextual help and hover text.

## Dependency versions

Dependency set 2026.2 (2026-08-18) and all managed tool, optional pack, pipeline, database and bootstrap pins are unchanged from v2026.9.20. The PCR Primer Design pack remains pinned to Primer3 2.6.1 and PrimalScheme3-LGE 3.3.0+lge.2.
