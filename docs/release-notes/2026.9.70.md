# Lungfish 2026.9.70

Channel: Preview

Previous versioned release: v2026.9.69

Stable baseline: v2026.9.69

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes four problems found while retaking the user manual's screenshots.

## Fixes

- **BLAST Verify on an NVD contig judges hits by the contig's adjusted taxon.** A SARS-CoV-2 contig whose BLAST hits were all SARS-CoV-2 was reported as contradicting its assignment, because the request did not carry the taxon IDs NVD had accepted for it.
- **BLAST Verify on a TaxTriage or EsViritu row judges hits by the row's taxonomy.** A TaxTriage row counted an NCBI hit to its own tax ID as contradicting when the two used different names for the organism, such as Simplexvirus humanalpha1 and Human alphaherpesvirus 1. An EsViritu detection now also accepts hits named by its species.
- **A TaxTriage run can no longer hang at FASTQC.** On some samples the quality-control step that draws FastQC plots never finished, and the run waited on it forever. LGE now skips that step. Its plots only fed a report LGE does not show.
- **Variant columns added in recent releases stay where they belong after you change the column layout.** With a layout saved before Variant Track, Caller Settings, and Gene / Protein existed, those columns sat at the bottom of the gear button's column list, and the next change moved them to the far right of the Variants table. Checking a hidden column again now shows it straight away instead of after switching tabs.

## Demo projects and documentation

- **The Pathogen Detection demo project includes contig FASTA files for its NVD results**, simulated from the SARS-CoV-2 reference, so BLAST Verify works on its NVD contigs. Download it again from Help > Demo Projects… to get them.
- The Welcome window's third card is described as Third-Party Tools, as the app shows it.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.69.
