# Lungfish 2026.9.53

Channel: Preview

Previous versioned release: v2026.9.52

Stable baseline: v2026.9.52

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release pairs a rewritten user manual with the fixes found while writing it. Several fixes change scientific results. If you used an affected operation on paired reads, rerun it.

## Fixes that change results

- **Paired-read trimming kept mates together only in the window.** `lungfish-cli fastq trim` (and the window's single trim operations that call it) ran fastp in single-end mode on interleaved pairs. A read trimmed to nothing left its mate behind, and every later pair was misaligned. The window and the command line now share one paired implementation, so both keep pairs together and report the same counts. Retrim any interleaved paired data trimmed with an earlier build.
- **The command-line length filter orphaned mates.** `fastq length-filter` now keeps pairs together (`--pairing`), like the window.
- **Assemblers received paired bundles as unpaired reads.** SPAdes and MEGAHIT now get interleaved pairs with `--12` and SKESA with `--use_paired_ends`, and the summary and provenance record the pairing. `lungfish-cli assemble` gains `--read-layout`.
- **Viral Recon ran interleaved bundles single-end.** Interleaved pairs are now split into `fastq_1` and `fastq_2` inside the run. `lungfish-cli workflow run nf-core/viralrecon --input <bundle>` builds the same samplesheet as the wizard.
- **Nanopore native barcoding kits assigned almost no real reads.** LGE built the barcode flank in the wrong orientation. On a real SQK-NBD114-96 run the built-in kit now assigns 78 percent of reads to the correct barcode. Reads matched at one end only now go to unassigned instead of disappearing from the totals.
- **Mean Q and Q20/Q30 changed after Refresh QC Summary.** One error-probability definition of mean quality is used everywhere, and Q20/Q30 are counted from the bases.
- **varVAMP qPCR mode used tiled amplicon sizes.** qPCR designs now default to varVAMP's own 70 to 200 bp. The Primer3 hydrolysis-probe preset now uses qPCR primer rules and places the probe at least 5 °C above the primers.
- **The varVAMP qPCR "selected" assay was the worst-ranked one.** The best-ranked assay is now selected and exported.

## Data safety

- **Mark Duplicates keeps your original alignments** in the app and on the command line. Marked copies are added beside the originals, which stay on disk renamed "[unmarked]". `lungfish-cli markdup` writes `<name>.markdup.bam` unless you pass `--in-place`. A new `lungfish-cli bundle mark-duplicates` matches the app.
- **Rerunning Demultiplex Barcodes keeps earlier results** (`demux-2`, `demux-3`). The command line refuses to overwrite without `--replace`.
- **Importing a second VCF with the same file name no longer replaces the first track.** Each import gets its own track (`calls`, `calls-2`), and replacing a track now needs an explicit choice (`--replace` on the command line).
- **Importing a VCF attaches it to the displayed reference bundle**, and Tools > Call Variants is available again when a reference bundle or mapping result is selected.
- **Variant tracks no longer store your folder paths in their VCF headers** for LGE's own callers.
- Several commands failed when a project lived under a symbolic link such as `/tmp`. Paths are now compared by their physical location throughout.

## Primer design

- **Design specific assays, not only conserved ones.** A new Discriminating Sites section in the alignment Inspector (and `lungfish-cli msa discriminating-sites`) finds columns where every target sequence differs from every sequence you must not detect, highlights them, and lists candidate windows.
- **Primer3 can keep your primers or probe** and design the rest, and can place a primer 3′ end on a chosen position.
- Primer3 now explains which rule rejected each primer and probe, not only the pair.
- Off-target screening builds its BLAST database from sequences you choose in the project. No terminal step is needed.
- Order export is available on the command line (`primers analysis export-order`). Designs open when they finish, coverage notes are visible without hovering, Primer3 oligo names come from the accession, and Olivar's ΔG setting is labelled as the primer binding energy it is.
- A new Primer Design demo project uses rhesus macaque MHC class I alleles.

## Other fixes

- `lungfish-cli map --project` produces the same result layout as the window, with a new Output Track name field and `--track-name`. The mapping result's second BAM is now a clone that takes no extra space.
- Nextflow and Snakemake exports of a provenance record now pass `nextflow lint`, a Nextflow stub run and `snakemake -n`.
- Trees can be rooted on a branch (Root on Branch to Here), extraction names use 1-based positions, and the alignment Inspector shows a pairwise identity table.
- `lungfish-cli debug container` checks the Docker daemon that Viral Recon and TaxTriage actually use, as does the TaxTriage dialog.
- Genotype review shortcuts work (Tools > Genotype Review), menu shortcut conflicts are resolved, and zoom items are disabled when nothing can zoom.
- Genotype exports write a homozygous haplotype the same way in every format, and run totals count fragments.
- The Taxonomy Collections drawer honours its checkboxes and starts one extraction per click.
- Workflow runs launch only the managed Nextflow or Snakemake, never another copy found on PATH.
- Many command-line help and error messages were corrected, and help text now names the program `lungfish-cli` throughout.

## Documentation and demo projects

The user manual was reviewed end to end by a group of textbook authors and revised as both a course and a reference. It has a new Getting LGE section, a reading order that builds from part to part, a single glossary meaning for each overloaded term, a new Primer Design part with a settings appendix, and a troubleshooting defect list checked against this release. New demo projects under Help > Demo Projects: Primer Design, and Human Mapping and Variants (with results). Existing demos gain a GIAB family trio, a mixed human and macaque 12S read set (simulated, labelled as such), a real barcoded nanopore run, and published MCM haplotype definitions.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.52.
