# Lungfish 0.5.0-alpha4

This alpha focuses on making MHC genotyping and haplotyping review practical
inside Lungfish. It adds a dedicated review interface for `.lungfishgenotype`
bundles, assay-scoped haplotype definitions, provenance-backed analyst edits,
and Sparkle-ready release packaging for the new workflow.

Changes since v0.5.0-alpha3:

## MHC Genotype Review

- Added the genotype result viewport for ONT `.lungfishgenotype` bundles with
  visual Outline and Matrix modes tailored to MHC review.
- Removed the older Cards mode so haplotypes use the visual Outline view and
  genotype/haplotype definition evidence uses Matrix mode.
- Added review-focused quick filters, metadata-aware search, saved smart
  cohorts, call evidence panels, audit timeline views, and sample detail
  navigation.
- Made the review panes resizable and corrected layout issues that could leave
  the main viewport empty or hidden behind filters and detail panes.

## Haplotype Calls And Definitions

- Added built-in deterministic MHC haplotype definitions for Mauritian
  cynomolgus macaques and rhesus macaques, with separate rhesus DPA/DPB/DQA/DQB
  calls and combined MCM DP/DQ calls.
- Added an editable project haplotype definition store so existing sets can be
  inspected, changed, deleted with provenance, and extended with new sets.
- Scoped haplotype definitions by assay/amplicon set and species. Workflow
  Operations now exposes only definitions applicable to the selected assay.
- Improved homozygote and dropout handling so clear whole-MHC homozygotes are
  displayed as the same haplotype in both slots and low-level alleles do not
  suppress complete supported haplotype calls.
- Added manual haplotype assignment controls that write analyst actions into
  the annotation sidecar audit trail.

## Workflow Operations And CLI

- Added `--haplotype-assay` to `lungfish fastq ont-barcode-genotype` and
  preserved legacy `--haplotype-definition` behavior when the definition is
  unambiguous.
- Fixed Workflow Operations to invoke the CLI from the active worktree build so
  development builds do not fail with `env: lungfish-cli: No such file or
  directory`.
- Included project/user haplotype definitions in workflow execution, not just
  built-in definitions.
- Reworked Matrix mode so column headers can sort and filter diagnostic allele
  evidence used to define haplotypes.

## Provenance And Export

- Added reproducibility provenance for haplotype-definition edits, manual
  haplotype assignments, annotation sidecar changes, Excel exports, LabKey
  exports, and ONT haplotype assignment.
- The ONT genotyping workflow now snapshots the exact haplotype definition JSON
  used for calls and records its checksum in canonical provenance before
  producing outputs.
- Generic genotype workbooks derive haplotype rows from the actual analysis, so
  MCM reports show combined `MHC-DP` and `MHC-DQ` rows while rhesus reports keep
  class II sub-loci separate.
- Added genotype export commands for plain workbook, pivot workbook, LabKey,
  sample listing, cohort listing, and annotation patch application.

## Stability And Performance

- Reduced multi-second lag when opening retained-demux-sized genotype bundles by
  deferring expensive inferred haplotype preview recomputation until needed.
- Fixed provenance inspector overdraw and layout problems with long workflow,
  path, and sidecar values.
- Added focused coverage for genotype sidecars, smart cohorts, dropout
  thresholds, haplotype definition matrices, metadata search, export
  provenance, and ONT report generation.

## Known Alpha Notes

- Rhesus class II haplotyping remains conservative: runs with many observed
  diagnostic genotype labels may still be marked for review rather than called.
- Existing `.lungfishgenotype` bundles created before this release may not have
  a haplotype-definition snapshot in their provenance until regenerated or
  edited through the new interface.
- Missing provenance remains a release-blocking defect for new scientific
  outputs; older project data may still need backfill when opened.
