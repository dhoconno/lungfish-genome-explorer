# Lungfish 0.5.0-alpha10

## Highlights

This release is primarily an internal architecture and developer-experience pass,
plus several fixes that improve the `.lungfishmhcref` reference-bundle workflow and
12S amplicon matching from the prior cycle.

### Build and codebase reorganization
- Split the largest source files (each formerly 5,000-10,000 lines) into focused
  files so incremental builds recompile less per edit: `AppDelegate`,
  `AnnotationTableDrawerView`, `SequenceViewerView`, `MainSplitViewController`,
  `InspectorViewController`, `VariantDatabase`, `FASTQDerivativeService`, and
  `SidebarViewController`.
- Introduced `LungfishKit`, a shared UI-kernel module below the app, and
  extracted `LungfishTwelveSUI` as the first feature module with its own test
  target. Untangled the shared CLI runner, BLAST results drawer, and file-panel
  factory into the kernel so feature surfaces can be modularized incrementally.
- Removed dead code (the unused 12S rolling-hash exact-match index).
- Added local fast-iteration tooling: a surface-scoped test runner, a background
  full-suite gate, and an optional pre-push hook (the full suite runs locally on
  Apple Silicon rather than on slower hosted CI).

### Reference bundles and 12S (from the prior cycle, included here)
- 12S amplicon matching counts reads whose exact reference core sits inside
  retained primer/flanking sequence, and collapses nested-substring and
  same-species reference duplication to a canonical species.
- `.lungfishmhcref` MHC reference bundles can be built from the CLI, imported via
  the Haplotype Definitions manager and drag-and-drop, render as a single bundle
  in the sidebar, and show their metadata in the inspector. The notarized build
  now registers the lungfish bundle document types with macOS.
- Bundle deletion tolerates AppleDouble companion files on non-native volumes.

## Notes
No user-facing behavior changes are expected from the reorganization; it is a
structural refactor validated by the full test suite.
