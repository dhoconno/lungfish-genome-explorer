# Lungfish 2026.9.5

Channel: Preview

Previous versioned release: v2026.9.4

Stable baseline: v2026.9.4

Dependency set: 2026.2

Lungfish 2026.9.5 makes Viral Recon run to completion on Apple Silicon. A run
launched from the app previously failed after most of the pipeline had already
succeeded, discarding results that had in fact been produced. Four separate
launch defects and two pipeline-step failures are fixed.

## Highlights

Viral Recon completes on Apple Silicon. A run on a SARS-CoV-2 amplicon dataset
now finishes every process and publishes consensus sequences, variants,
alignments, and the MultiQC report.

The engine is resolved from Lungfish's own managed copy rather than whatever is
first on the shell path. An app launched from the Finder inherits a bare path
and previously either failed to find Nextflow at all or found an older system
copy too old for the pipeline's plugins.

Inputs and the Nextflow work tree are kept on paths without spaces. Project
directories are named by the user and routinely contain them, which several
pipeline tools reject outright. Recorded provenance still refers to the real
project paths.

Resource caps reach the pipeline again. viralrecon 3.0.0 replaced the older
parameters with Nextflow's own resource limits, so the caps were silently
inert and a single step could ask for far more memory than the machine had.

Freyja no longer runs under Viral Recon. The pipeline pins it to a container
built only for Intel, and under emulation its bootstrap workers are killed,
which failed the whole run. Lineage abundance remains available through the
Wastewater Surveillance tools, which run Freyja natively.

A task that dies on an unexpected status is retried once, so a single transient
container fault no longer discards a pipeline that has otherwise succeeded.

## Fixes

Freyja lineage de-mixing works from the Tools menu and the command line again.
It had been passing an option removed in Freyja 2.0.3, so every run stopped
before starting.
