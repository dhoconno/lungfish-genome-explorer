# Lungfish 2026.9.62

Channel: Preview

Previous versioned release: v2026.9.61

Stable baseline: v2026.9.60

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes two problems found while recapturing the user manual's screenshots on 2026.9.61.

## Fixes

- **A reference bundle made with Create Bundle stays in the project of the window it came from.** With two project windows open, closing one could make Create Bundle in the other copy the new bundle into the closed project's Downloads folder and switch the sidebar to that project.
- The assembly sheet's Readiness card is tall enough for its message again.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.61.
