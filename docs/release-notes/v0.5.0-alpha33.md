# Lungfish 0.5.0-alpha33

Previous release: v0.5.0-alpha32

## TaxTriage Responsiveness

This alpha focuses on making TaxTriage results usable when an organism has a
large alignment payload. Previous builds could leave the main window feeling
stuck while moving between organisms, opening contextual menus, or waiting for
the lower alignment panel to update. That was caused by expensive miniBAM
reference and read loading work happening too close to the UI path.

TaxTriage now keeps the expensive alignment loading work off the main thread
and ignores stale alignment-load completions when the user has already selected
another organism. The alignment view also avoids drawing per-base reference
details when the current zoom level cannot show those bases clearly, which keeps
large hits responsive while still preserving the ability to inspect the data at
useful scales.

The default TaxTriage result view now opens directly into the list-over-detail
layout with the top alignment selected. Users should see the TaxTriage content
without first choosing a layout in the sidecar, and ordinary selection changes,
right-clicks, and organism-name copying should no longer block on the alignment
renderer.

This remains an alpha prerelease. The build was published as a notarized Apple
Silicon DMG and added to the Sparkle alpha update feed.
