# Lungfish 2026.9.66

Channel: Preview

Previous versioned release: v2026.9.65

Stable baseline: v2026.9.65

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes problems found while taking the user manual's remaining screenshots.

## Fixes

- **Bundles imported from an ONT run folder can be mapped and assembled.** The barcode bundles recorded Oxford Nanopore only in a place mapping and assembly do not read, so reads without nanopore-style headers showed Read Type Auto and minimap2 would not run. Re-import a run folder imported with an earlier build, or set its Read Type once in the Inspector.
- **A failed FASTQ operation's row shows the tool's own error.** A SPAdes run with a bad extra argument filled its row with the command-line tool's progress messages, drawn over the line below. The row now shows the error on one line, and the full text stays in its tooltip and log.
- **Variant tracks called with bcftools no longer read Incomplete in the Provenance Inspector.** The stream that bcftools mpileup passes to bcftools call was checked for a checksum and size, which a stream does not have.
- The SRA Runs pane's Accession hint gives run accessions as examples, such as SRR36291587.

## Documentation

- The user manual says to drag along the Consensus row to select a stretch of an alignment, and names the Provenance Source picker's first entry as the app shows it.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.65.
