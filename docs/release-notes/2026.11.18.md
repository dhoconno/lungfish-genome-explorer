# Lungfish 2026.11.18

Channel: Preview

Previous versioned release: v2026.11.17

Stable baseline: v2026.11.14

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This Preview adds View > Reset View, which returns the view on show to its start. The Inspector now keeps its tab and sections for each item, and the line that says a bundle's data changed no longer covers any track. No result, number or file changes.

## What works differently

### Views remember where you left them

- **View > Reset View.** View > Reset View returns the view on show to its start, and it is dimmed when nothing differs from the start. It changes nothing in your bundle. The item takes the place of View > Reset View Settings to Defaults, but it no longer resets the nucleotide colours, track height or quality overlay. Choose it when you want the view as it first opened.
- **Reset to Defaults under Sequence Style.** The Reset to Defaults button under Sequence Style (Inspector, View tab, Annotations) restores default nucleotide colours, track height and the quality overlay in every bundle. It no longer resets the annotation height, spacing, visibility and filters. Reset View does that for the view on show.
- **The Inspector keeps each item's tab.** An item opens on its own Inspector tab, not on the last tab used, and the Inspector keeps each item's tab, its Samples & Metadata disclosure and its Alignment, Annotations or Reads choice on the View tab. A tab that the app opens by itself, such as Selected Item when you click a residue in an alignment, is not kept. Pick a tab once, and the item opens on it at your next visit.
- **The line that says the data changed covers no track.** In reference and mapping results it now sits above the tracks, and a mapping result shows it before you click a contig row. It goes when you leave the bundle or choose Reset View.
- **The line and the warning about an old result.** When a result shows both the line that says the data changed and the warning line about an old result, the data line sits above the warning and covers none of its words. Reset View takes the data line away and leaves the warning in place.
- **A filter you typed in a Kraken2 or EsViritu result stays on.** After you showed another result and came back, the field could hold your filter while the table listed every row. The table now lists the rows that match, for example "3 of 13 assemblies".

## Things to know

The limits in the 2026.11.17 notes still apply, as do the earlier limits they keep, except its View memory lines, which the lines below replace.

### View memory

- **Restored contig.** A mapping result loads its alignment evidence by itself when you come back to the row it opened on, with the same read filters. When you come back to a row you picked, it still waits for one click on that row. Until you click it, the consensus row and Extract show "Click the selected row in the list to load its alignment evidence." If the result opened with no row selected, a click on row 1 counts as a pick too.
- **Files outside a project.** A file opened outside any project keeps no view.
- **Kinds that keep no view.** Primer analyses and primer orders, PDFs, Quick Look previews, a FASTA file opened by itself and status pages keep no view.
- **Reset View in five kinds of result.** In Kraken2, EsViritu, NAO-MGS, NVD and TaxTriage results, Reset View can be on before you change anything, can leave part of the view as it was, or can stay on after you use it, and nothing in the result changes. Set back by hand any part it leaves.
- **Reset View leaves some filters.** On a genotype result it leaves the row and sample filter texts and some locus and allele choices, and on a mapping result it leaves the consensus minimum depth and the read groups. While one is set, the counts are not the default counts, so set it back by hand.
