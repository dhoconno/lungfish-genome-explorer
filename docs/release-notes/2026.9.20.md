## PCR primer design

Install the optional PCR Primer Design pack in Plugin Manager, then open **Tools → PCR primer design → Primer3…** or **PrimalScheme3-LGE (custom fork)…**. Both designers use the selected project sequences or alignments and report progress through Operations. Results are saved inside the originating project as durable primer-analysis bundles with inputs, native outputs, settings, runtime identities and reproducibility provenance.

Primer3 supports target regions, product-size ranges, primer pairs and internal qPCR probe candidates. Its result view shows each candidate's binding sites and amplicon on the design template. PrimalScheme can build one scheme per MSA or a combined panel, with explicit minimum, target and maximum amplicon sizes. The custom fork supports treating uncovered alignment ends as missing observations and bounded multicore discovery. Panel selection now explains **Uniform position weighting** and **Prioritize variable regions (entropy)**.

Inspect amplicons, pools, coverage and primer variants in Overview and Results. Alignment binding inspection places the selected primer in its own track, with matching bases represented by dots and differences by letters. Files and Provenance use the Inspector. Context menus support inspecting, copying and saving selected primers or reference amplicons with provenance.

Inspector display filters operate on the saved selected primer set. **Export displayed primer order…** exports that exact displayed subset without manual reselection. Orders retain the populated IDT oPools template as the first worksheet, optional metadata and filter details on the second worksheet, a template-only upload copy and a detailed CSV. Each order remains in the project with the source and selection evidence.

## Genotype Excel reports

LGE is the editing authority for genotype and haplotype results. **Export to Excel…** creates a point-in-time report containing **Genotype Matrix - All**, **Genotype Matrix - Filtered**, and **Export Metadata**, with **Haplotype Calls** included when the analysis has call content. The workbook includes full evidence as well as the filtered view; filtering does not redact the All worksheet.

The filtered matrix follows the captured viewport's samples, row order, displayed values, review annotations and styles. Evidence rows without a positive displayed read count in any visible sample are omitted. Both matrices and the optional calls sheet share the same effective H1/H2 assignments and colors. Provenance retains the captured filters, sources and replay information.

Excel synchronization and edit-import controls are retired. Make edits in LGE and export a new report. Existing scientific annotations and historical artifacts remain available.

## Dependency versions

The optional pack adds Primer3 2.6.1 and **PrimalScheme3-LGE 3.3.0+lge.2 (custom fork)** in separate managed conda environments. The fork's public source and pinned release artifacts are available at https://github.com/dhoconno/primalscheme3-lge/releases/tag/v3.3.0-lge.2. Other managed dependency pins remain unchanged.
