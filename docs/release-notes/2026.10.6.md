# Lungfish 2026.10.6

Channel: Preview

Previous versioned release: v2026.10.5

Stable baseline: v2026.9.78

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release reorganizes the Tools menu so each command sits where you would look for it. Variant calling gets its own submenu, genotype review moves to the Selection menu and can now be undone, and the online database searches move to the File menu. Several tools have clearer names, and the advice on removing duplicate reads now warns against using it on amplicon data.

## A reorganized Tools menu

The Tools menu now has four groups, separated by lines. Read preparation comes first, with QC & Reporting, Demultiplexing, Trimming & Filtering, Decontamination, Read Processing, and Search & Subsetting. Read analysis follows, with Mapping, Variant Calling, Assembly, Clustering, Classification, and Genotyping. The third group holds the commands that work on sequences and alignments rather than reads, Alignment & Phylogenetics and PCR Primer Design. Workflows and the Plugin Manager come last.

- **Variant Calling** is new. It holds **Call Variants…**, which used to stand alone lower in the menu, and **Viral Recon (SARS-CoV-2)…**, which used to sit among the read mappers.
- **12S Amplicon Matching** moves from Genotyping to Classification, because it identifies species from their 12S sequence.
- **Remove Low-Complexity Reads** and **Remove Duplicate Reads** move from Decontamination to Trimming & Filtering, because neither removes sequence from another organism.
- **MHC Haplotype Definitions…** moves into Genotyping. It is always in the menu now, and while no MHC genotyping workflow is enabled it is greyed out with a tooltip that says how to turn it on.
- **PCR Primer Design** moves from the top of the menu into the sequences group.

A workflow that is not yet enabled used to appear greyed out with "(not enabled)" after its name, although choosing it still did something. It now reads **Enable** before its name, such as **Enable 12S Amplicon Matching…**, and opens the same prompt. A linked workflow package that this build cannot run reads **Show** with its name **in Workflow Library** and opens its card there. The FASTQ operations dialog and the launcher list beside a FASTQ dataset use the same categories as the menu, so Viral Recon now opens under Variant Calling.

## Clearer names

| Before | Now |
|---|---|
| fastp Adapter + Quality Trim | fastp Adapter & Quality Trim |
| Remove ribosomal RNA sequences | Remove Ribosomal RNA Reads |
| Low-Complexity Filter | Remove Low-Complexity Reads |
| Remove Duplicates | Remove Duplicate Reads |
| Reverse Complement and Translate in Read Processing | Reverse Complement All Sequences and Translate All Sequences, so they are not confused with the Sequence menu commands of the same names |
| Viral Recon | Viral Recon (SARS-CoV-2), the only virus it supports |
| miSeq amplicon MHC genotyping | MiSeq Amplicon MHC Genotyping |
| Full-length ONT MHC genotyping | Full-Length ONT MHC Genotyping |
| Haplotype Definitions… | MHC Haplotype Definitions… |

The Operations panel shows the new names. Output folders, batch labels and recorded commands keep their earlier wording, so existing projects and saved commands work as before.

## Genotype review in the Selection menu, with Undo

The genotype review commands move from **Tools > Genotype Review** to the Selection menu, beside the other commands that act on what you have selected. **Selection > Genotype Sample** holds Mark Sample Reviewed (Command-R), Mark Sample Confirmed (Command-K), Flag Sample for Review (Shift-Command-F), and Sample Detail… (Shift-Command-O). **Selection > Genotype Call** holds the matrix review commands with their Option-Command shortcuts. Every shortcut is unchanged.

Mark Sample Reviewed, Mark Sample Confirmed and Flag Sample for Review can now be undone with Command-Z and redone with Shift-Command-Z, and the Edit menu names the change it will undo. A stray Command-K no longer overwrites a sample's earlier status for good. Undo history for a genotype result ends when the viewer shows something else.

The genotype audit log now records the status each change replaced, where it used to leave that value empty. An Undo back to no status adds a Clear status entry, which the audit timeline shows as the earlier status followed by "none". The LabKey export's audit_log.csv carries these values in its before column, with clearSampleStatus as the new action name.

## Online database searches in the File menu

**File > Search Online Databases** now holds Search NCBI…, Search SRA… and Search Pathoplexus…, right after Import Center…, because these searches bring data into the project.

## Deduplication advice

Remove Duplicate Reads now says it collapses PCR and optical duplicates in shotgun libraries, and that amplicon reads are identical by design and should be kept. Identical amplicon reads are the measurement, such as allele support or a species' share of reads, so collapsing them would change the result. The Exact PCR preset in the FASTQ metadata drawer no longer recommends itself for amplicon data. No preset or default changed.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.10.5.
