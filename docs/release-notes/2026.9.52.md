# Lungfish 2026.9.52

Channel: Stable

Previous versioned release: v2026.9.51

Stable baseline: v2026.9.50

Dependency set: 2026.2

## Tool updates

- Fix the micromamba checksum failure reported by **Update tools to 2026.2**. The updater now verifies the transformed and signed executable shipped inside the app, while retaining the upstream checksum pin.
- Verify the staged executable's bytes and version before replacing the installed runtime. Failed verification leaves an existing installation in place.
- Release checks now exercise the actual packaged tool-update operation, including the installed binary, dependency receipt, provenance record, and subsequent update plan.

After installing this update, retry **Update tools** if an earlier attempt reported the micromamba failure. Existing tool environments remain available, and scientific data and saved analyses do not require migration.

This corrects [issue #34](https://github.com/dhoconno/lungfish-genome-explorer/issues/34).

## Included preview releases

Includes Preview 2026.9.51. This release reconciles that preview's notes and the changes since Stable 2026.9.50; no additional product changes are introduced by Stable promotion.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions remain unchanged from Stable v2026.9.50. Micromamba remains pinned to 2.9.0-0 with the same upstream checksum. The lock also records the reproducible packaged checksum used by local Debug builds.
