# Lungfish 0.5.0-alpha8

Hotfix release for ONT FASTQ bundle import and project-to-project copy safety.

- Fixed copying existing `.lungfishfastq` bundles so the entire bundle payload is copied atomically instead of re-importing only `preview.fastq`.
- Updated Import Center FASTQ routing so `.lungfishfastq` bundles are treated as atomic project bundles and their internal chunks are not scanned as raw FASTQ inputs.
- Kept raw ONT directory imports on the CLI-backed `lungfish fastq import-ont` path with storage choices for native chunks or flattened per-barcode FASTQ payloads.
- Added provenance for atomic FASTQ bundle copies, including source and destination paths, copied payload descriptors, command argv, options, runtime identity, exit status, and wall time.
- Fixed the ONT directory import option popup sizing so chunk/flatten choices are visible in AppKit alerts.
