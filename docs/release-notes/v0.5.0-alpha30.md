# Lungfish 0.5.0-alpha30

Previous release: v0.5.0-alpha29

## Alpha Release

This alpha release improves workflow provenance and Nextflow launch
reproducibility for metagenomics workflows. It publishes a notarized Apple
Silicon DMG and updates the Sparkle alpha appcast for testers.

## Highlights

- TaxTriage is updated to v3.3.6 and its launch command file now records the
  GitHub release tag, exact revision, repository, and durable workflow-source
  snapshot path.
- EsViritu is updated to v1.3.1. Kraken2 remains current at v2.17.1.
- Provenance now records a human-friendly GitHub release version for GitHub
  hosted workflows and tools when that release tag is known.
- nf-core viralrecon run bundles now preserve the selected workflow release/tag
  in the run manifest and provenance.

## Included Commits

- 6f4287d4 fix: expose GitHub release versions in workflow provenance

## Notes

- This release remains a prerelease build.
