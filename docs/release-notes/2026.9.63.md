# Lungfish 2026.9.63

Channel: Preview

Previous versioned release: v2026.9.62

Stable baseline: v2026.9.60

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes one problem found while recapturing the user manual's screenshots on 2026.9.61 and updates the manual's captions.

## Fixes

- The Binding inspection view of a primer analysis fits the viewport. Its alignment was wider than the viewport of a 1400-point window, so the view was cut off at both edges.

## Documentation

- Captions and procedure text in the user manual now match the current Operations Panel, assembly sheets, Nextflow export, and variant tables.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.62.
