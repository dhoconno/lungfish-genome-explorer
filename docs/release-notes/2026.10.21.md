# Lungfish 2026.10.21

Channel: Preview

Previous versioned release: v2026.10.20

Stable baseline: v2026.9.78

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release moves more of Lungfish Genome Explorer (LGE) onto `lungfish-cli` on top of Preview 2026.10.20, so that the row of a run in the Operations Panel records the command that ran and Copy CLI Command copies it. The BLAST Verify actions of the NVD, EsViritu, TaxTriage, 12S and Kraken2 results, the result, VCF and CZ-ID imports of the Import Center, the copy of an item from another project, the extraction of a region from a document, Export Sequences… of an open document, the PCR Primer Design dialog and the exports of tables, sequences, trees, workbooks and reports from the viewers now run the matching `lungfish-cli` command, and the row of each records that command. The AI Haplotyping row records its command too, and the run itself stays inside the app.

The three hidden keys that 2026.10.20 added are gone. They are `TaxTriageLaunchRoute`, `GATKVariantCallingRoute` and `BlastReadActionRoute`, and a value that you wrote with `defaults write` for any of them has no effect. Three hidden keys are new, and each keeps an earlier route for this release. They are `ClassifierBlastRoute`, `RegionExtractionWithoutBundleRoute` and `CrossProjectCopyRoute`. Each takes `cli`, the default, or `legacy`, and the section of its area below names its sites and says that 2.13 deletes it. Set one with `defaults write com.lungfish.browser.preview <key> legacy`, where `com.lungfish.browser.preview` is the identifier of this Preview, and delete it with `defaults delete com.lungfish.browser.preview <key>`.

The owner check list under Checks still to run blocks a Stable promotion until a walk with a person at the Mac has covered every row.

## Reads and downloads

**Result imports.** The Import Center now runs `lungfish-cli import kraken2`, `import esviritu`, `import taxtriage`, `import nao-mgs` or `import nvd` for a result, and the row shows the command with `--format json`. The app no longer carries a helper mode for these imports. Cancel ends the import as Cancelled inside 6 seconds, removes only the folder that its own run began, so another import in the same Imports folder stays whole, and records the cancel. The record of each import names the sample ids of the result, with an Illumina `_S<n>_L<n>` tail cut from a NAO-MGS id, and a digest of the source result. A TaxTriage record no longer names the combined report as a sample.

**BAM, CZ-ID, alignment and tree imports.** The Import Center runs `lungfish-cli import cz-id` for a CZ-ID result, and a cancelled CZ-ID import ends Cancelled inside 6 seconds. A new BAM import record names `lungfish-cli import bam`, a command that you can run. Older records keep the old helper command, and an export lists that step as an in-app step and does not replay it. The app no longer has its BAM helper mode. `lungfish-cli import bam` into a plain folder prints progress events with `--format json`. A cancelled `lungfish-cli import msa` or `import tree` never leaves a part of a bundle in the project, because the bundle is written aside and moved into place in one step.

**VCF import.** The Import Center imports a VCF with `lungfish-cli import vcf` in one process at every size and profile. A compressed VCF of 1 GB or more, with 128 or more contigs, or at the Ultra Low Memory profile no longer splits by chromosome into child processes, and the import profile you choose still sets its memory use. A compressed VCF whose header lists more than 512 contigs, or that has records on a contig its header does not list, now imports every record. The earlier split by chromosome skipped those records, so a track built from such a file by an earlier version lacks them, and importing the file again with the replace choice adds them. A cancelled VCF import ends Cancelled inside 6 seconds. Copy CLI Command copies the exact command, `--resume` and `--materialize` included, and each of those two refuses a track that is already finished. The VCF import helper is gone.

**Translate.** `lungfish-cli fastq translate` numbers the mates of an interleaved pair that share a read id with `.1` and `.2`, and its help says what the frame labels mean. Only interleaved and mixed inputs change. The FASTA ids of two adjacent mates that share a read id gain `.1` and `.2` right after the id, so the ids are unique. A single-end file, a pair named with `/1` and `/2`, a long-read bundle and a mixed file recorded as single-end keep every byte.

## Alignments, bundles and variants

**Region extraction from a document.** Extracting a region to a new bundle from a viewer that shows a document with no reference bundle now runs `lungfish-cli extract sequence`. Its row records the command, Copy Command copies it, and Cancel stops it. A bundle made from a GenBank file keeps no annotations, as before, and its record now says so. The record of such a bundle has the one shape that every region bundle has. It no longer holds the entries `flank`, `flank3`, `flank5`, `extractedLength`, `requestedStart`, `requestedEnd`, `region`, `lineWidth`, `headerRegion`, `headerCoordinateSystem` and `output`, while its command keeps the region and the flanks and `start` and `end` give the span. The hidden key `RegionExtractionWithoutBundleRoute` is new. It takes `cli`, the default, or `legacy`, which brings back the earlier in-process route for this release, and its one site is the region extraction in `ViewerViewController+Extraction.swift`. 2.13 deletes it.

**Export Sequences….** Export Sequences… in the sidebar now runs `lungfish-cli convert` for an open document or a project sequence too, so the Operations row shows the command. It runs the command on a copy that the app saves in the project's `.tmp` folder, or in the system temporary folder when no project is in reach or the project cannot be written. A file that Lungfish cannot read by name, such as a `.seq` or `.txt` file, is copied as FASTA first. In 2026.10.20 an export that included a document held in memory with no file, or such a file, was written in the app and recorded no command.

**GenBank files.** GenBank files that Lungfish writes, from Export Sequences… or from `lungfish-cli convert`, no longer hold the internal qualifiers `/_lf_raw_feature_type` and `/_lf_raw_genbank_location` under each feature. Earlier releases wrote them when the source was a GenBank file.

**Primer design.** The PCR Primer Design dialog runs Primer3, PrimalScheme3 and varVAMP designs through `lungfish-cli primers design`, so a design can be cancelled like any other command, the row shows the command's progress, and Copy CLI Command gives the command that ran. The row text is unchanged. A blank assay rule now records `primer3-default`. A failed `lungfish-cli primers design primer3`, `primalscheme3` or `varvamp` now exits with status 64 after its failed event, or 126 when a tool is missing, where it exited with status 1. A refusal keeps status 3 and a cancel keeps status 125. An Olivar design still runs inside the app, and `olivar` still exits with status 1 on failure. A replay of the recorded command to a bundle is proven on the real tool for Primer3, PrimalScheme3 and varVAMP. For Olivar the recorded command is proven to resolve to the dialog's options.

**AI Haplotyping.** The AI Haplotyping row records `lungfish-cli genotype ai-haplotyping` with the provider and model that it resolved, and it keeps that command when the bundle changes before the run starts. The API key reaches no row, log, sheet or record. The recorded command replays through the CLI with the key in its environment and sends the same provider request. The run itself stays inside the app.

## Classifiers

**TaxTriage in the app.** The hidden key `TaxTriageLaunchRoute` is gone, and a value that you wrote with `defaults write` for it has no effect. Tools > Classification > TaxTriage… runs `lungfish-cli taxtriage run --project` and has no other route. The app writes nothing after the command ends, because the cross-reference files, the run history and the backfill of earlier records are gone from the app. The `batch-run-history.json` and `taxtriage-ref-<runId>.json` files and the backfilled root records that earlier releases wrote stay on disk as they are.

**Keys that left.** The hidden keys `GATKVariantCallingRoute` and `BlastReadActionRoute` are gone, and a value that you wrote with `defaults write` for either has no effect. The Call Variants dialog's GATK row always runs `lungfish-cli variants call --caller gatk`, and the NAO-MGS, assembly and FASTA selection BLAST actions always run `lungfish-cli blast submit`. A value left in your defaults is harmless, and `defaults delete com.lungfish.browser.preview <key>` removes it.

**BLAST Verify.** The BLAST Verify actions of the NVD, EsViritu, TaxTriage, 12S and Kraken2 results now run `lungfish-cli blast submit`, so each row shows the command to copy and Cancel stops the whole tool tree. The record of a search names the SHA-256 of its query and the result or bundle that it came from. A failed NVD or EsViritu search leaves a `failed` record beside the query copy. With no project open, the NVD and EsViritu actions show the alert `No Project Open` over `Open or create a project before running BLAST.` and start nothing.

**BLAST Verify rows that extract reads.** The EsViritu row appears at once with `Extracting reads for selected accessions…`, Cancel stops the BAM extraction and the search, and the command shows once the reads are in. The TaxTriage and 12S rows also appear at once. Cancel stops the BAM extraction of a TaxTriage search or the export of a 12S search and then the search, and the command shows once the reads or sequences are in. The record of a TaxTriage search names the tax ID and the accessions, and the record of a 12S search names the bundle. The record of a TaxTriage organism names the sample whose BAM it searched, a re-run from the results drawer searches the same BAM, and a request from the organism table with no sample picked records none.

**Kraken2 BLAST Verify.** A cancel during the read lookup ends the row as Cancelled with no search. The search keeps NCBI `nt`, and its record names the database, the taxon, and the count and seed of the read draw. The search is saved in the `blast-verifications` folder of the result, where reopening the result shows it again beside older saved verifications.

**The `ClassifierBlastRoute` key.** The hidden key `ClassifierBlastRoute` is new and takes `cli`, the default, or `legacy`, which keeps the earlier in-process search of these five BLAST Verify actions for this release. Its sites are the BLAST Verify code in `ViewerViewController+Nvd.swift`, `ViewerViewController+EsViritu.swift`, `ViewerViewController+TaxTriage.swift`, `ViewerViewController+TwelveS.swift` and `ViewerViewController+Taxonomy.swift`. 2.13 deletes it.

**Extraction.** Copy CLI Command now replays a clipboard or share extraction from the classifier extraction sheet, which runs `lungfish-cli extract reads --by-classifier` into a scratch file and then copies it. A taxa collection extraction picks reads the same way as the other classifiers, and `lungfish-cli extract reads --by-classifier --tool kraken2` takes `--taxon-scope exact` for the reads classified to a taxon itself. `lungfish-cli conda extract` is gone, and its notice already named `extract reads --by-classifier --tool kraken2`.

## Projects and the sidebar

**Copy between projects.** A project item dropped on the sidebar from another project now runs `lungfish-cli project copy-item`. The row shows the command, Cancel stops the copy, and a cancelled copy leaves no partial item, because the item is staged and moved into place in one step. The record names the source item by its path inside the source project, names the source project, and holds digests of the copied files. The hidden key `CrossProjectCopyRoute` is new. It takes `cli`, the default, or `legacy`, which brings back the in-app copy for this release, and its sites are `CrossProjectCopyRoute.swift` and `MainSplitViewController+CrossProjectCopy.swift`. 2.13 deletes it.

## Viewer exports

**Every viewer export has a row and a command.** An export from a viewer now begins a row in the Operations Panel that shows the `lungfish-cli` command, Copy CLI Command replays it, and the record of the export names `lungfish-cli` and that command. The table lists each export that runs a command in this release.

**Result tables.** An EsViritu detections export of a batch of more than one sample fills the metadata columns of each row with that row's own sample values, where those columns were blank before. A Kraken2 taxonomy table of several samples with a metadata column gives the rows of each sample that sample's value, where every row carried the first picked sample's value, and tied taxa keep one order. The record of the taxonomy export names the files that the table was read from and its samples, and no longer names the classified reads.

**Failed exports.** A failed export from the BLAST drawer now ends its row as failed and shows the failure alert, where the drawer only logged it. A failed Export CSV from the folder sheet now fails its row and shows an Export Failed alert, where it only logged. A failed taxonomy table export ends its row as failed and shows the same alert as before.

**Sequences.** The FASTA exports in the table read a FASTA copy of the records and a selection file that the app saves in a hidden `.lungfish-export-inputs` folder beside the export, and the record names those two files. Export Sequence as FASTA saves the sequence as a one-record FASTA file in that folder, and the command wraps it at 80 columns. Copy Sequences on a reference's sequence list no longer builds the reference a second time.

**Trees, workbooks and definitions.** A subtree exported from the tree viewer now ends with a newline, as the CLI's does, and its record names the CLI and the two bundle files that the export reads instead of the whole bundle. Copy CLI Command replays the genotype Excel export from the capture that the viewer froze at export, and cancelling that export from its row writes no file and shows no error alert. The record of a manual haplotype definitions export names the CLI instead of the app, and the record of a haplotype definition export now names the project, assay and scope that the export used.

**Provenance report.** The provenance report export, from File > Export > Provenance and from the Inspector's export menu, builds the report in a hidden staging folder and publishes it when it is complete, so Cancel leaves the output folder as it was. An existing output folder keeps the files that the export does not write.

**Variants and annotations.** The sample metadata template export gains a provenance record and a failure alert, and the bookmarked variants export names the variant databases it read where it recorded a `/bin/cp` replay. The annotation table export, in every tab, replays from the selection file beside the output, and its `/bin/cp` replay is gone. A Selected Rows export of a variant table with more than 4,000 matching variants now leaves the coding feature, consequence and amino-acid change blank for a variant outside the cached coding features, as All Matching does, and no longer writes the Zoom in placeholders.

**Primer exports.** Copy CLI Command now replays Save Primer FASTA Bundle and Extract Reference Amplicon with `lungfish-cli primers analysis export-selection`, for a primer, an amplicon, a numbered pool or a native pool, with `--kind primer-fasta` or `--kind reference-amplicon`.

## Command line help

**New commands and options.** The commands `project copy-item`, `blast export table`, `kraken2 export table`, `esviritu export detections`, `nao-mgs export table`, `nvd export contigs`, `taxtriage export organism-matrix`, `taxtriage export batch-report`, `taxtriage export results`, `fastq export reads`, `fastq export sample-barcodes`, `genotype export-manual-definitions`, `primers analysis export-selection`, `variants export bookmarked`, `variants export sample-template`, `bundle export-gff3` and `bundle export-annotation-table` are new, and `conda extract` is gone. `extract reads` takes `--taxon-scope`, `extract sequence` takes `--source-document`, `--sequence`, `--selection` and `--force`, `import vcf` takes `--resume` and `--materialize`, and `metadata export` takes `--output`, `--selection` and `--force`. `import cz-id`, `import esviritu`, `import kraken2`, `import nao-mgs`, `import nvd`, `import taxtriage`, `import vcf`, `primers design primer3`, `primers design primalscheme3` and `primers design varvamp` take `--format` and print events with `--format json`. The help of `fastq translate` and `translate` says what the `--frame` labels mean. Each is described in the section of its area above.
