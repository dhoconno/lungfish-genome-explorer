# Lungfish 0.5.0-alpha35

Previous release: v0.5.0-alpha34

## Native Genotyping Matrix Annotations

This alpha adds a native annotation workflow for genotype-only amplicon result
bundles, so users can inspect, decorate, and triage the genotype matrix inside
Lungfish instead of moving back and forth to Excel for common review marks.
The genotyping viewport now supports cell, row, and column selections; fill,
text, and border colors; bold and italic text styling; plain-text comments; and
quick-pick color palettes for both MCM-style and generic high-contrast review
colors. Dark fills automatically switch cell text to a readable light color, so
palette choices retain their full visual depth.

The matrix also gained review-focused navigation and filtering. The genotype
and statistic columns stay pinned while sample columns scroll horizontally, the
sample header stays visible while scrolling vertically, and each sample column
has a read-count row. Row and column selections can be persisted until cleared,
then used to show only the selected rows or columns. Search now filters both
allele rows and sample columns, and threshold helpers can preview and apply
styles only to cells in selected rows or columns that have at least the chosen
read support.

Annotations are stored in Lungfish sidecar metadata and synchronized back into
the current Excel workbook so existing Excel-based review workflows remain
interchangeable with in-app editing. Clearing styles now removes applied cell,
row, and column formatting across the selected annotation targets while leaving
the scientific call data unchanged.

## Haplotype Review Integration

Haplotyping result bundles continue to open in the haplotyping result view by
default, but the inspector now offers a remembered toggle into the genotyping
matrix for users who want to make lightweight LGE-native edits on the raw
genotype calls. MCM reference bundles still use their canonical haplotype color
defaults, while haplotype definition editing now allows explicit color overrides
for bundle authors who need different palettes.

This remains an alpha prerelease. The build was published as a notarized Apple
Silicon DMG and added to the Sparkle alpha update feed.
