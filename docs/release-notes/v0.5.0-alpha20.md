# Lungfish 0.5.0-alpha20

Previous release: v0.5.0-alpha19

## Highlights

This release is a substantial ONT MHC workflow update. It adds project-native
full-length ONT MHC genotyping, replaces the slow pbAA clustering path with
Savont for routine full-length amplicon analysis, and makes large ONT
demultiplexing gentler on memory by running cutadapt over physical chunks
instead of one monolithic FASTQ problem.

### Full-length ONT MHC genotyping

- Full-length ONT MHC genotyping can now run on batches of `.lungfishfastq`
  bundles directly from the workflow dialog, with reference sequences selected
  from project bundles.
- Savont is now the default clustering engine for this workflow. Guide
  sequence selection is no longer required, which simplifies the dialog and
  avoids the slowest step of the earlier pbAA-based workflow.
- Batch processing schedules larger samples first and uses bounded
  per-sample parallelism so 48 to 96 sample runs provide useful Operation
  Status progress while keeping all cores productively occupied.
- Low-coverage samples that cannot produce Savont ASVs now complete as
  zero-cluster samples instead of aborting the entire batch. The failed Savont
  attempts and the empty-cluster fallback are recorded in provenance.

### Genotyping workbooks and artifacts

- Full-length ONT outputs now include the same current-workbook pattern used by
  the miSeq MHC workflow: the original workbook is retained and
  `artifacts/workbooks/current.xlsx` is the analyst-editable current copy.
- The genotype workbook now includes the miSeq-style full sequencing pivot
  sheet, sample summaries, unmatched cluster sheets, and haplotype output when
  haplotyping is enabled.
- Clusters that do not match the reference are written both as FASTA artifacts
  and workbook rows so they can be reviewed without leaving the result bundle.
- Multiple clusters that resolve to the same allele are consolidated in the
  reported genotype rows with read support summed.

### ONT import and demultiplexing

- ONT PacBio-barcode demultiplexing now works chunk-by-chunk across ONT run
  folders, avoiding the memory pressure caused by sending a very large
  materialized FASTQ into one cutadapt process.
- The ONT import interface now exposes a recipe for demultiplexing full-length
  MHC ONT amplicons with PacBio barcodes, so the required barcode definition
  file is selected up front from the project workflow.
- Chunk processing is parallelized across physical ONT chunks, with progress
  based on completed chunks so the Operation Status panel shows meaningful
  movement during long imports.

### Provenance and project polish

- Result-bundle provenance discovery now recognizes workflow-named provenance
  files such as `full-length-ont-mhc-genotyping-provenance.json` in the bundle
  root, so the right-side Inspector shows the actual run lineage for these
  outputs.
- Scientific output cleanup was tightened so failed operations do not leave
  stale output directories that block reruns.
- Sidebar folder expansion state is preserved more reliably during project
  refreshes.

## Notes

- This release remains a prerelease build.
- The release was validated with focused workflow tests, full-length ONT MHC
  CLI runs on the NB15 batch, workbook integrity checks, and the standard
  signed/notarized release pipeline.
