# Lungfish 2026.9.60

Channel: Stable

Previous versioned release: v2026.9.59

Stable baseline: v2026.9.54

Dependency set: 2026.2

This release fixes MiSeq MHC genotyping, keeps unfinished analyses out of the sidebar, keeps your folder paths and account name out of the records LGE writes into a project, and fixes the problems found by clicking through every feature the user manual describes. It collects Preview releases 2026.9.55 to 2026.9.59.

## MiSeq MHC genotyping

- **Genotyping failed at the pair-merge step with "Unable to locate a Java Runtime"** on a Mac without its own Java. The merge now uses the Java that LGE installs with BBTools.
- **Genotyping failed after mapping with "Retained-read demultiplex filter did not return valid JSON"** when reads merged at import were still recorded as read pairs. LGE now maps such reads as they are, counts every fragment in the run total, and finishes with a warning if a total is ever unavailable. Rerun any cohort that failed either way.

## Unfinished analyses stay out of the sidebar

- **An analysis result appears in the sidebar only when its run finishes.** Opening a result while it was still being written could break the viewport. A run that finishes with warnings counts as finished. Failed and cancelled runs stay hidden. This covers TaxTriage, Kraken2, EsViritu, mapping, assembly, pbAA, Savont, Viral Recon, 12S matching and amplicon genotyping, from the window or from `lungfish-cli`.
- **Interrupted runs are listed in the Operations Panel.** If LGE or the Mac stops during a run, the next time the project opens an Interrupted row shows the run and its size on disk, including its temporary working files. Remove Partial Output deletes them after you confirm. LGE never deletes partial output on its own.
- The quit and close-window warnings say where partial output goes and update if a run finishes while they are open. Universal search no longer finds files inside an unfinished analysis. A finished result is selected in the sidebar, even when LGE rescans the project at the same moment, and folders keep their expansion.

## Privacy

- **Project records no longer contain your private folder paths or account name.** Provenance, run history, operation logs, alignment statistics, variant databases, BAM `@PG` lines, VCF headers and bundle manifests use paths relative to the project, the run workspace, or the managed tool and storage roots, and `<external>/<file name>` for files outside the project. Run Again, `workflow run --repeat-from` and provenance export still work, including after a project is moved. Projects written by earlier builds load unchanged.
- Provenance written by analyses that LGE runs through its bundled `lungfish-cli` names the release build instead of "(dev)".

## Fixes

- Opening a classification result could make the main window thousands of points tall. Long names now truncate inside their tile.
- The Operations Panel's Results button and Reveal Output Files work for FASTQ operations and for Kraken2, EsViritu, TaxTriage and other analyses. A failed operation's log ends with its error, and the details title is no longer clipped. Removing a failed analysis also removes its result folder.
- The mapping result's Track column shows track names, the Alignment Summary counts each read once (including primer-trimmed tracks), derived tracks are described as derived, and the mapping viewer has Variant Tracks toggles.
- The Provenance Source picker lists a mapping result's variant tracks, including on first selection.
- Hide high-gap sites in the Consensus section no longer clears the selected contig or disables Extract Consensus.
- Variant table headers sort on a click and open the column menu on a right-click, and the drawer's toolbar buttons no longer overlap at narrow widths.
- The Analyses list shows readable settings. Call Variants defaults to the duplicate-marked track after Mark Duplicates. Demultiplex Barcodes starts on a kit that matches the reads' platform.
- Save as Primer Scheme names the record, Primer3 order groups are named after the record accession, and the alignment Inspector's Pairwise Identity table fits the Inspector.
- CZ ID imports record the sample name, and Viral Recon's genome-wide coverage table has its own title.
- Viral Recon uses the MN908947.3 bundle a project already holds in Reference Sequences instead of downloading a second copy.
- The Operations Panel's details drawer opens at its full height, so a failed run's log and controls are no longer hidden under the Clear Completed footer, and a failed row's error text is readable when the row is selected.
- The Primer Trim sheet labels its Output Track Name field, and the field shows the default name whole.
- The Workflow Library no longer goes blank or hangs after a workflow is switched on. A fresh install opens on the Welcome window's Required Setup card. Relaunching no longer opens a second window of the same project. Finished genotyping runs no longer leave an empty lock file.

## Demo projects and documentation

- All ten demo projects were rebuilt with this release's `lungfish-cli`.
- The MHC genotyping chapters use a de-identified cohort (Animal_01 to Animal_30).

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.54.
