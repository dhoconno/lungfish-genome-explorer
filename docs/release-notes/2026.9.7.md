# Lungfish 2026.9.7

Channel: Preview

Previous versioned release: v2026.9.6

Stable baseline: v2026.9.4

Dependency set: 2026.2

Lungfish 2026.9.7 is a fixes release from a day of MiSeq genotyping and
metagenomics work with the 2026.9.6 preview. It restores the Inspector for
classifier results, stops a genotyping run from hanging on its merge step, adds
a Cancel button to that run, fixes a crash in the known-allele view, and puts
the filtered pivot export where the filters are set. Preview builds are under
rapid iterative development. Features may be incomplete, change quickly, or
require additional feedback.

## Highlights

The filtered pivot export is now a copy of the result workbook. The Inspector's
Genotype Display section ends with a single Filtered Pivot button, placed
under the Min Reads and Min Percent filters it applies. It writes the result's
current workbook with only the pivot sheet changed: allele values below the
filters are blanked, each row's Total and observation count are recomputed,
and rows left empty are removed. The Long Summary, Sample Summary, Run Stats,
Overrides and Audit Log sheets, and all formatting, come through unchanged.
The copy is a one-way export. Edits made to it in Excel never flow back into
the result. Min Percent respects the matrix's Percent Basis, so the export
drops exactly the cells the matrix hides. On a 30-sample cohort the export
kept the same 140 of 305 rows the Inspector showed.

The earlier Export Filtered Pivot action lived in a viewport lens that MiSeq
results never show, so it could not be reached. The plain Excel view export
is no longer offered from the Inspector.

## Fixes

The Inspector shows its content again for EsViritu, TaxTriage and NVD
results. Selecting one of those batches left the sidecar almost empty, with
no sample filter, batch details or panel layout, only a blank Bundle tab. The
alignment evidence viewport embedded in those results reset the Inspector to
an empty mode whenever it cleared, which it does during the result's own
initial load. The Inspector now keeps the mode its host viewport publishes.
Kraken2 was never affected.

Every result list uses one row height. The minimap2 mapping list and the
reference-bundle sequence list drew each row on two lines, with the contig
identifier under the bundle name, so their rows were almost twice as tall as
every other list. That secondary text now sits inline after the name, and the
TaxTriage table and the EsViritu detection list use the same 22 point
baseline as everything else.

MiSeq genotyping no longer stalls while merging read pairs. bbmerge finished
each sample in about a second, but the app occasionally missed the child's
exit and waited for the rest of the session with no child process and no way
to stop it. The wait now uses the termination handler Foundation guarantees
to call, and the run's row in the Operations panel offers Cancel.

A genotype-only result shows its matrix alone. Selecting an allele used to
open a detail pane holding nothing but the allele name and a note that a
fresh analysis was required to generate graphical reference records. When a
selection has no graphical record, no GenBank fields and no comments, there
is nothing to detail, so the pane stays hidden and the matrix keeps the
space. It returns as soon as a selection has something to show.

The app no longer crashes while laying out the known-allele detail view. With
a MiSeq result open beside the Inspector, the view could flip between its
wide and narrow arrangements on every layout pass until AppKit gave up. A
narrow view now waits for 40 more points of width before going wide, and a
flip back to an arrangement already left in the same pass is refused.
