# Lungfish 2026.9.44

Channel: Preview

Previous versioned release: v2026.9.43

Stable baseline: v2026.9.28

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release adds ready-to-use demo projects for the user manual and fixes a set of problems with TaxTriage, BLAST verification, EsViritu, MHC genotyping, and paired reads stored in one file.

## Demo projects

- **Help > Demo Projects… lists eight practice projects that go with the user manual.** Each one holds the reads and references a chapter needs, already imported, so you can start at the analysis. They cover genes and sequences, human reads, human mapping and variants, long reads and assembly, SARS-CoV-2 amplicons, pathogen detection, MHC genotyping, and 12S metabarcoding.
- **Download & Open** downloads a project, checks it, saves it in your Documents folder under LGE Demo Projects, and opens it. Each project has a README that lists its sources and the chapters that use it.
- On the command line, `lungfish-cli demo list`, `demo info`, and `demo fetch` do the same.

## TaxTriage

- **Paired reads stored in one file now run as pairs.** Before, TaxTriage treated each mate as a separate read.
- **A new Exclude host taxa setting** removes host organisms before TaxTriage picks its reference genomes. It is set to 9606, the human taxonomy ID, whenever a sample is a clinical sample. Without it, a human sample could make TaxTriage download the whole human genome and run out of memory. On the command line this is `--remove-taxids`.
- **A run where some steps failed now ends as Completed with Warnings** and names the failed step, for example a step stopped for lack of memory. Before, it could look like a complete success with every score at 0.
- **Reopened TaxTriage results work fully again.** Open Report, Copy Summary, provenance, and CSV and TSV export all work. So do the sample buttons, the All Samples overview, and View > Next Sample and Previous Sample.
- **The alignment pane no longer goes blank** after you tick or untick a sample in the Inspector's Sample Filter.
- The BLAST Verify button in a TaxTriage result opens the read-count popover instead of sending 50 reads at once.

## BLAST verification

- **Hits are judged by taxonomy ID.** A hit to a relative in the same genus, such as herpes simplex virus 2 when you checked type 1, no longer counts as supporting.
- **Verifications are saved with the result** and come back when you select the same taxon again.
- A read that NCBI returns no result for is now marked as an error instead of disappearing from the table.
- The popover names the database searched, nt or core_nt.
- The limit of 50 reads per hour now carries over when you quit, and the app and the command line share it.

## Other fixes

- **EsViritu warns before running on reads shorter than 100 bases**, which it cannot use, and a failed run now shows EsViritu's own reason.
- **MHC genotyping against an annotated reference works again.** It failed because the reference's annotation file was left out of a working copy.
- **A single file of paired reads is recognised as paired.** The Import sheet now picks Interleaved when a file's reads alternate between the two mates. Bundles imported earlier as single-end by default are also treated as paired when their reads alternate, which fixes MHC genotyping finding no reads on such bundles. A pairing you chose yourself is always kept.
- Genotyping no longer fails when the output folder is under /tmp.
- View > All Samples now has its own shortcut, Cmd-Shift-0. It used to share Cmd-Opt-0 with Content Text Size > Default.
- A rare crash while drawing sequence letters is guarded against.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap pins are unchanged from v2026.9.43.
