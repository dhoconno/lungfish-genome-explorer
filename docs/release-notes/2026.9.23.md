# Lungfish 2026.9.23

Channel: Preview

Previous versioned release: v2026.9.22

Stable baseline: v2026.9.4

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## PrimalScheme3 coverage panel optimization

PrimalScheme3-LGE now supports the bounded `coverage` panel-selection algorithm for combined whole-MSA designs. The selector records its resolved metric, target, seed, optimizer starts, repair rounds, time limit, mispriming product-size limit, input mapping and effective coverage outcome in native analysis artifacts.

Coverage execution requires the explicit local PrimalScheme3-LGE lge.3 executable and verifies its capabilities, source revision, runtime, schema, profile and supported-scope contract before running scientific work. Native coverage catalogues, optimizer output, independent validation, publication metadata and complete execution provenance are retained together so an accepted panel can be audited and reproduced.

The release includes native, empty-result and uncertain-result coverage fixtures, including generated fixture provenance and deterministic publication checks. Unsupported combinations fail closed instead of silently switching to another selection algorithm.

## More flexible primer inputs

The GUI and CLI accept raw aligned nucleotide FASTA files alongside native `.lungfishmsa` bundles for PrimalScheme3 design. One-row FASTA input is valid; RNA `U/u` is normalized to DNA `T`, unknown `N/n` bases are treated as alignment gaps, and a row map records the source-to-consumed transformation. Gzipped FASTA contigs can be prepared for extraction without leaving temporary files behind.

Primer-design readiness is shared between the dialog and pipeline, and viewer/CLI handling now preserves the relevant input and extraction behavior while retaining the existing durable provenance requirements.

## Documentation

The PrimalScheme3-LGE feature documentation now describes the coverage selector, its strict supported scope, lge.3 capability contract, provenance records and uncertainty behavior. The foundations chapter has been revised to keep reference-genome concepts focused and readable.

## Dependency versions

Dependency set 2026.2 (2026-08-18) and the managed tool, optional pack, pipeline, database and bootstrap pins are unchanged from v2026.9.22. The managed PCR Primer Design installation remains pinned to Primer3 2.6.1 and PrimalScheme3-LGE 3.3.0+lge.2; coverage execution uses the explicitly supplied lge.3 contract.
