# Lungfish 2026.10.8

Channel: Preview

Previous versioned release: v2026.10.7

Stable baseline: v2026.9.78

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release makes the EsViritu and Kraken2 dialogs show their progress when many samples are selected, saves the phylogenetic trees LGE builds inside the Analyses folder, and fixes several tree commands, including Extract Subtree failing on long sequence names.

## EsViritu and Kraken2 with many samples

Before Run is available, LGE reads the start of each sample's reads to tell paired reads from single reads. With dozens of samples this took minutes, every sample read "checking…" the whole time, and the dialog looked stuck. LGE now checks several samples at once, each sample's line fills in as soon as it is checked, and the bottom of the dialog reads "Checking read layouts (12 of 57)…" until Run becomes available.

The run mode choice between "Run separately per bundle" and a greyed-out "Combine all inputs" is gone from both dialogs, because only one mode ever existed. As before, LGE runs the classifier on each sample and saves all of the results together in one batch result.

## Phylogenetic trees in the Analyses folder

Trees built with IQ-TREE, and trees made from them with Root on Selected Branch or Extract Subtree, are now saved in the project's Analyses folder under Phylogenetic Trees, next to Multiple Sequence Alignments, where MAFFT alignments already go. Imported trees still go to the top-level Phylogenetic Trees folder, and trees from earlier releases stay where they are.

## Tree command fixes

- Extract Subtree failed with "File name too long" when the selected clade's sequences had long names, because the new tree was named after the full sequence names. Names are now shortened, for example to the first sequence name followed by "-3-more", so they stay within the macOS limit of 255 bytes per file name. The same limit now applies to rerooted trees and to trees built with IQ-TREE.
- Running `lungfish-cli tree reroot`, `tree extract-subtree` or `tree relabel` with `--output` naming a tree that already existed refused to overwrite it, and then deleted it. The existing tree is now left untouched.
- The tree commands in `lungfish-cli` now refuse an output name longer than 255 bytes before writing anything, with a message that says so.
- Root on Selected Branch is no longer offered for the root of the tree, and Extract Subtree is no longer offered for a single tip, since neither could succeed there.
- Export Subtree now shows an alert explaining a failure, where it used to only beep, and its suggested file name is shortened the same way.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.10.7.
