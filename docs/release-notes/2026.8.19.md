# Lungfish 2026.8.19

Channel: Preview

Previous versioned release: v2026.8.18

Stable baseline: v2026.8.13

Dependency set: 2026.2

Lungfish 2026.8.19 is a preview release that carries forward the portable,
side-by-side Debug, Preview, and Stable release profiles and the clean-runner
dependency handoff from v2026.8.18. It also removes an ambient-clock dependency
from the exact-tag release tests.

v2026.8.15, v2026.8.16, v2026.8.17, and v2026.8.18 were prepared and tagged
during release-process validation but were not published as GitHub releases or
Sparkle updates. This release supersedes those unpublished preparations.

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## Highlights

### Exact-tag CalVer tests use a deterministic date

The nightly-release integration fixture now pins its August 2026 scenario to an
explicit date. A release gate that starts after a UTC month boundary therefore
tests the intended fixture instead of deriving a different month from the
runner's ambient clock. Production CalVer selection remains based on the
release machine's local date.

### Preview and Stable installations are independent

Preview uses the dedicated bundle identifier `com.lungfish.browser.preview`,
the `Lungfish Preview.app` wrapper, the visible Preview name, and the Beta feed.
Stable retains `com.lungfish.browser`, `Lungfish.app`, and the Stable feed. The
two applications can be installed and used side by side without sharing
Launch Services identity, identifier-keyed settings, or updater state.

Older Preview builds used the Stable identifier. Moving to this Preview requires
a one-time manual installation from the 2026.8.19 Preview DMG rather than an
in-place Sparkle update. Migrate any desired Preview-only settings manually.

### Exact-tag release gates restore their verified dependencies

The credentialless dependency job and the Preview and Stable source-test jobs
run on separate GitHub machines. Source-test jobs restore the exact
manifest-keyed cache produced by the dependency job and verify its reconciled
dependency receipt before running tests. A missing or mismatched cache fails
closed rather than presenting hundreds of unrelated missing-tool failures.

When a long source gate encounters a bounded set of load-sensitive XCTest
classes, each class is retried once in its own process. Tool-required gates keep
their fail-closed tool requirement during those retries, and any isolated
failure still blocks publication.

### Releases use one verified operator path

Release-machine validation, credentialless packaging, and credentialed
publication use the release coordinator. Unsigned candidates are receipt-bound
to their channel, commit, toolchain, metadata, and exact payload hashes.
Publication checks live Sparkle floors, waits for required CI jobs on the exact
tagged commit, and only then signs, notarizes, staples, and publishes.

## Known issues

- The 20260626 Kraken2 indexes display taxid 3418604 as
  `Betacoronavirus pandemicum`; identifiers are unchanged.
- The Apple Silicon bioconda Bracken compatibility package lacks a usable
  driver. Fresh installs receive the managed Bracken 3.1 source overlay, while
  existing working environments are preserved.
- `bioconda::bwa-mem2=2.3=hda5e58c_0` self-reports 2.2.1 because of an upstream
  packaging defect; Lungfish verifies the package identity from conda metadata.
