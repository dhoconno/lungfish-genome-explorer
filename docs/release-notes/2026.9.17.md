# Lungfish 2026.9.17

Channel: Preview

Previous versioned release: v2026.9.16

Stable baseline: v2026.9.4

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## Filtered pivot exports

Filtered Pivot Excel exports now use the exact visible LGE genotyping-matrix projection. Visible samples and allele rows retain their viewport order, hidden rows and columns are excluded, candidate-only rows are supported, and projected cell values are reproduced in the workbook. The exporter fails closed when a projected sample or genotype cannot be matched uniquely instead of producing a misleading spreadsheet.

Analyst review state is carried into Excel. Visible false-positive calls are exported with bracketed, italic gray styling; visible false-negative calls receive an explicit `FN` marker and warning styling. Visible sample, allele-row, and cell comments are written as native Excel comments with their author and timestamp. Stable candidate identities are matched exactly so annotations cannot drift to a similarly named row.

The export provenance records immutable projection and annotation inputs, exact user-facing arguments and resolved defaults, plus the nested managed Python/openpyxl transformation with runtime identity, command, inputs, outputs, checksums, exit status, stderr, and wall time.

## Haplotype review and ordering

The haplotype-call inspector now provides a per-locus **Swap H1 ↔ H2** action. A swap writes both slot overrides together immediately through the existing atomic, audited mutation path. The action is unavailable for unresolved, uncalled, error, or homozygous pairs.

Default MCM slot ordering now prioritizes an intact haplotype over a recombinant or incomplete haplotype. When both calls have the same intactness rank, the lower numbered M family is assigned to H1, so M1 sorts ahead of M3. Existing manual overrides remain authoritative.

## Dependency versions

Dependency set 2026.2 and managed tool version pins are unchanged.
