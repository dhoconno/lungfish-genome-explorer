# Lungfish 0.5.0-alpha13

Previous release: v0.5.0-alpha12

## Highlights

This release folds in the concurrent 12S performance work, shared sample
metadata import support for 12S result bundles, MHC genotype workbook revision
tracking, and ONT FASTQ bundle import improvements.

### 12S matching and metadata

- 12S matching now defaults to an Illumina exact-match mode backed by a
  byte-level length/hash index, with the original indel-tolerant matching kept
  as an explicit ONT mode.
- The 12S workflow dialog now exposes a primary Read Platform segmented control
  for Illumina exact versus ONT indel-tolerant matching.
- 12S result sample tables now include `sample` and `sample_name` aliases while
  preserving the existing `sample_id` and `display_name` columns.
- CSV/TSV sample metadata can now be imported into `.lungfish12s` result
  bundles through the same result-bundle metadata importer used by other
  classifiers, with provenance written for the import.

### MHC genotyping workbooks

- ONT/MHC genotyping can now preserve and expose genotype workbook revisions
  from the analysis bundle.
- The app and CLI surfaces have been wired so retained workbook payloads can be
  opened from the result and inspected consistently with other genotyping
  outputs.
- Workbook revision provenance and bundle metadata were expanded so downstream
  imports retain the final stored payload paths.

### FASTQ and project handling

- ONT FASTQ bundle import and merge handling now carries shared source metadata
  more reliably across project imports and derived bundles.
- Project deletion planning and FASTQ batch import tests were expanded for the
  new shared-bundle surfaces.

## Notes

- The release remains a prerelease build.
- This release was validated by the automated test suite and release guardrails
  before packaging.
