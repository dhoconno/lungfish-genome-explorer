# Lungfish 0.5.0-beta19

Previous release: v0.5.0-beta18

## Synchronized miSeq haplotype and genotype views

Completed miSeq MHC analyses that include haplotyping now open in **Haplotype
Calls**. A simple two-choice selector moves between **Haplotype Calls** and
**Genotype Matrix**. The former Review and Audit viewport destinations are no
longer shown for these results, so the analysis opens directly into the two
scientific views used for interpretation. Review history, provenance,
workbook actions, artifacts, and detailed call evidence remain available from
the Inspector and selected-call tools.

The Genotype Matrix is the same full comparison matrix used for full-length
MHC genotyping. It includes raw genotype and candidate rows, read support,
search and visibility controls, comments and annotations, and cohort-aware
navigation. Its Haplotype Calls band uses the same effective calls and included
locus order as the primary Haplotype Calls view and `current.xlsx`. Excluded
loci therefore remain excluded consistently, including the default handling of
MHC-E in MCM analyses.

Edits and restores made in either view are reflected immediately in the other.
Active searches and Smart Cohorts are recalculated when a changed haplotype can
affect membership, while unrelated rows and columns are left alone. The matrix
is created only when first opened and then reused. On a representative mounted
52-sample by 120-genotype result, the view-switch performance gate measured
p95 and p99 times within the 16.7 ms and 33.4 ms release limits.

## Safer, traceable haplotype corrections

A single Save can now change both haplotype slots as one all-or-nothing
operation. Lungfish validates the complete request before writing. If the
annotation or its reproducibility record cannot be published, the visible
calls, stored files, and workbook state remain unchanged, and the analyst's
draft stays available to correct or retry. Read-only results are rejected
before any in-memory change.

Every changed slot is tied to the same operation identifier, timestamp,
author, rationale, baseline, and active analysis identity. The saved
provenance contains the exact replay information and input/output checksums.
The new `lungfish-cli genotype replay-call-overrides` command verifies the
recorded bundle and prior annotation state before reproducing an operation.
Older sidecars remain readable and are not rewritten merely by opening them;
an unsafe identity-less restore is rejected rather than allowing an edit from
another analysis revision to be removed.

Smart Cohorts, the viewport, Inspector summaries, and workbook publication now
share one effective-call resolver. Valid analyst overrides use deterministic
timestamp and identity rules, stale overrides cannot silently replace active
calls, and H1/H2 status is retained separately. Selecting H1 or H2 in the
matrix also focuses the corresponding evidence card with a visible Selected
marker and a matching accessibility description.

## More accessible and responsive matrices

The miSeq Haplotype Calls band supports mouse, keyboard, and VoiceOver
interaction. Each target identifies its sample, locus, haplotype slot,
displayed call, status, and whether the value came from the pipeline or an
analyst correction. Space, Return, and accessibility activation select the
same target, and status is not communicated by color alone. Long labels,
included-locus changes, high contrast, text scaling, and structural updates
refresh the band without rebuilding the underlying genotype table.

Deterministic performance checks now guard the intended behavior in normal CI:
opening the default Haplotype Calls view does not construct the matrix, a warm
view switch reuses the existing model, and a one-sample correction cannot
reload unrelated rows or rebuild the workbook and haplotype analysis. The
mounted frame-time benchmark remains an explicit release gate so machine load
does not make ordinary CI unreliable.

## More accurate zero-SNP and partial DRB candidates

Full-length ONT MHC classification now handles post-crop, zero-SNP genomic
candidates more carefully. A reference-ready candidate with one uniquely
compatible genomic reference is folded back into the corresponding named call.
Ambiguous ties remain candidates for review. An incomplete zero-SNP genomic
sequence remains reviewable as a partial extension rather than being presented
as a complete named allele.

The classification rule and its canonical comparison inputs are recorded in
provenance. This preserves the distinction between a named call, an ambiguous
candidate, and a partial extension while preventing rows labelled as novel
with zero nucleotide differences from being produced by the resolved case.
For full-length genotype-only analyses, the redundant Audit selector is also
removed so the genotype matrix is the analysis view.

## Project storage cleanup on ExFAT volumes

Project Storage cleanup now recognizes the directory link-count behavior used
by ExFAT while retaining the existing identity and containment checks. Cleanup
receipts preserve large filesystem identifiers exactly and match completed
items to current project paths rather than temporary scan identifiers. This
allows genuinely orphaned staging data to be removed from ExFAT-hosted
projects without weakening the safeguards that prevent active bundles or
unrelated files from being deleted.

Temporary project-local cleanup entries now describe their lock state
accurately when no publication lock applies. Resource-close tests were also
made deterministic under full-suite concurrency so descriptor-number reuse by
unrelated work cannot masquerade as a cleanup failure.
