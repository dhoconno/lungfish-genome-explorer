# Lungfish 2026.11.9

Channel: Preview

Previous versioned release: v2026.11.8

Stable baseline: v2026.11.7

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This Preview shows the words of the note above a result that a version with a known fault made. In 2026.11.8 the window's title bar hid them. It also brings the first RNA-seq commands to `lungfish-cli` and records the sequencing instrument when you import FASTQ files.

## What works differently

- **The note above a result with a known fault now shows its words.** In 2026.11.8 it showed only as a thin colored line across the top of the viewer. It is now a yellow band above the result that says what the fault is and what to do. If a result has more than one known fault, the band gives the first and counts the others, which you read under Warnings on the Inspector's Provenance tab. The band goes when you select another result. It works for TaxTriage, Kraken 2, EsViritu, NAO-MGS, NVD and assembly results. Viral Recon, Call Variants, trimmed reads, reads imported with a recipe and Demultiplex results still get no note, so use the redo lines in the 2026.11.8 notes for those.

## What's new

- **Import RNA-seq results.** `lungfish-cli import rnaseq` brings salmon quant folders or a gene count table into a project as an RNA-seq result.
- **Build an RNA-seq reference set.** `lungfish-cli rnaseq reference-set` builds a named reference set from a genome, an annotation and extra sequences, with a stable id. Read counting comes in a later Preview.
- **A FASTQ import records the instrument.** It records the sequencing instrument when the read names carry it, and says when a library repeats one already in the project. A large paired import takes about a minute longer for this check.
- **The RNA-seq plugin pack** now installs salmon 2.11.0 and gffread 0.12.9.

## Things to know

- **A click on a detection in a result with a known fault.** The Inspector's Provenance tab then shows the record of that detection's alignment evidence, with no Affected result rows, until you select the result again in the sidebar. The note above the viewer stays.
- **`lungfish-cli rnaseq --help`** says it counts RNA-seq reads. That command comes in a later Preview, and `reference-set` is the only one for now.

The limits in the 2026.11.8 notes still apply.

## Updating

Choose Check for Updates… in the app menu to install this release. It adds no tool to install on the Mac. The RNA-seq plugin pack is optional.
