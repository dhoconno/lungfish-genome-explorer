# Lungfish 2026.9.35

Channel: Preview

Previous versioned release: v2026.9.34

Stable baseline: v2026.9.28

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## Portable mapping projects

Mapping analyses now store bundled reference, BAM, and index paths relative to their final project location, so copied or renamed projects continue to open their mapping results. Existing sidecars with absolute paths are rebased when their files moved with the project, while unrelated external references remain external. The project root's internal `metadata.json` file remains on disk and is hidden from the project sidebar.

## Reliable project shutdown

Closing the last project window releases its writer lock, and quitting waits for outstanding project-loading tasks before completing store cleanup. Projects that are cleanly closed can be compressed and shared without carrying an active lock that triggers unnecessary recovery on another computer.

## Variant inspection and export

Calls from multiple variant tracks now retain independent row identities and display their caller and track context consistently in the table. Consequence inference recognizes reference-bundle chromosome aliases and refreshes when sequence and annotation inputs arrive, with gene and protein labels used to distinguish overlapping coding features.

Variant hovers now summarize every call at a position with richer genotype, quality, depth, filter, track, consequence, and amino-acid details, and the same text can be copied from the viewer. Variant-table exports include the reference FASTA and bundle manifest in their reproducibility provenance when local consequence predictions depend on them.

## Flexible viewer layout

Mapping split panes can now be resized close to either edge and keep the chosen position through relayout. Annotation drawers clamp stale saved heights to the space currently available, keeping both the drawer and its surrounding viewer reachable in small windows.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap pins are unchanged from v2026.9.34.
