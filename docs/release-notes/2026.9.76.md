# Lungfish 2026.9.76

Channel: Preview

Previous versioned release: v2026.9.75

Stable baseline: v2026.9.72

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release tidies the sidebar of a new project.

## Projects

- **A new project's sidebar is empty until something is added.** LGE no longer creates an empty Primer Schemes folder when it makes a project. The folder appears when the first primer scheme is saved, and it opens so the scheme is visible. Projects made by earlier versions keep their empty Primer Schemes folder on disk, but the sidebar hides it until it holds a scheme.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.75.
