# Lungfish 2026.10.3

Channel: Preview

Previous versioned release: v2026.10.2

Stable baseline: v2026.9.78

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release moves the pairwise identity list of an alignment into a full distance matrix under the alignment, adds corrected distances, and fixes the Discriminating Sites section of the Inspector, which kept disappearing from view.

## Distance matrix under the alignment

The alignment viewport now has a pane along its bottom edge with two tabs, Annotations and Distances. Choose **View > Show Distance Matrix** (Control-Command-M) or the matrix button in the alignment toolbar to open it on the Distances tab. Every pair of sequences gets a cell, coloured by its value, with a legend beside the controls.

- Click a cell to select both sequences in the alignment. Command-click and Shift-click select several cells, and Return shows the pair in the alignment.
- The arrow keys move between cells. VoiceOver reads each cell as its row, its column, its value and the number of positions compared.
- Command-C copies the selected cells with their names. **Copy Matrix** and **Export Matrix as TSV…** give the same table `lungfish-cli msa distance` writes, and the export records that command in the Operations Panel.
- The Inspector's **Bundle** tab keeps a **Pairwise Distance** section that shows the counts behind the selected cell.

**View > Show Drawer** (Control-Command-B) now opens this pane on an alignment too. Before, it did nothing there.

## New distance models and options

The matrix and `lungfish-cli msa distance` offer Identity, p-distance, Jukes-Cantor (JC69) and Kimura 2-parameter (K2P) for DNA, and Identity, p-distance and Poisson for protein. A cell reads `nan` when a pair shares no position to compare and `inf` when a corrected distance is saturated, and the command warns when either occurs.

Two new options apply to both. `--gaps complete` compares every pair over the same columns, and `--order average-linkage` places the most alike sequences next to each other. The defaults, pairwise deletion and alignment order, match earlier releases.

## Values that change

Ambiguity codes such as N, R and Y are now treated as missing data, the same as a gap. Earlier releases compared them as letters, so two sequences with N at the same place counted as a match and N against A counted as a difference. Identity and p-distance therefore change for alignments that contain ambiguity codes, most often consensus genomes with low-coverage stretches. Alignments without ambiguity codes give the same values as before. The provenance record of a distance matrix now names this rule, so a record from an earlier release can be told apart.

## Discriminating Sites

The Discriminating Sites section of the alignment Inspector ran correctly, but the Inspector jumped to the Selected Item tab when the alignment opened and whenever a site was clicked. On return to the Bundle tab the section had collapsed, so the results looked lost. The section now stays on the Bundle tab and stays open. Tests now check that the window's run gives the same report as the command for the same targets and exclusions.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.10.2.
