# Lungfish 2026.9.71

Channel: Preview

Previous versioned release: v2026.9.70

Stable baseline: v2026.9.69

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release tidies the TaxTriage and NVD result views, with problems found while retaking the user manual's screenshots.

## TaxTriage

- **A failed quality-control step no longer reads as lost results.** When FastQC, NanoPlot, or MultiQC fails, the run's message now says only the MultiQC plots are missing and the classifications, alignments, and TASS scores are complete. A step that was killed is described as usually having run out of memory, rather than certainly.
- **One Filter organisms field.** A batch result showed a second filter field above the organism table, which filtered only the rows already loaded. The field in the row of sample buttons remains.
- **A run from the command line into a project's Analyses folder opens as a TaxTriage result**, whatever the folder is named. It used to show as a plain folder unless its name followed the app's pattern.
- The Inspector's Summary tab no longer says to select a result above the Operation Details of the result that is open.
- The Building database message no longer overlaps the empty viewport's prompt, and the alignment pane under the organism table no longer shows the prompt to select a file from the sidebar.
- Operation Details reads "1 ignored failure across 1 sample" instead of "1 ignored failures across 1 samples".

## BLAST verification

- A BLAST verification of a single sequence, such as one NVD contig, reads "(1 read)" in the results drawer and the Operations panel instead of "(1 reads)".
- The alignment pane under an NVD contig no longer shows the prompt to select a file from the sidebar.

## Documentation

- The TaxTriage chapter's example tables match a fresh run of the two corneal samples.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.70.
