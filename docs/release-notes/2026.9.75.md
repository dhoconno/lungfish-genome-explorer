# Lungfish 2026.9.75

Channel: Preview

Previous versioned release: v2026.9.74

Stable baseline: v2026.9.72

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes five problems found while filming the overview video.

## Fixes

- **The Inspector names quality binning the way the import sheet does.** A FASTQ bundle imported with Illumina binning now shows "Illumina (7-level)" under Ingestion instead of the internal name "illumina4".
- **The SRA and ENA import sheet shows the real download size.** It used to read "Total size: Zero KB" because the files had not been downloaded yet. It now shows the size the archive reports for a single run, or says the size is shown when the download starts.
- **A Viral Recon result shows its provenance.** The Provenance tab for a Viral Recon result now opens the record the run wrote beside its raw pipeline results, instead of reporting missing provenance.
- **Provenance exports start in the current project.** The save panel for File > Export > Provenance and the Inspector's Export menu now opens in the project that holds the selection. Before, it opened in the last folder used, which could be inside a different project.
- **A project that opens read only because it has no project store now says why.** A project folder without its hidden `.project.db` file, for example one built only with `lungfish-cli` or copied without its hidden files, still opens with "(Read Only)" in the title. An alert titled Opened Read Only now explains the cause and how to recover. The manual's Shared Projects and Troubleshooting appendices describe the alert.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.74.
