# Lungfish 2026.9.36

Channel: Preview

Previous versioned release: v2026.9.35

Stable baseline: v2026.9.28

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## Scientific table export

Annotation, variant-call, genotype, and sample tables can now export either all matching rows or the selected rows as XLSX, CSV, TSV, or JSON. Exports preserve the table's filtering and sorting semantics, retain exact numeric and textual values, and include reproducibility provenance for the active source databases, retained VCF overlays, and reference inputs used to derive coding consequences.

Large exports collect rows off the main thread, support cancellation, and publish the payload and provenance sidecar atomically. Variant exports can derive coding feature, consequence, and amino-acid fields from a frozen reference and annotation snapshot without blocking the interface or silently producing partial codon context.

## Variant tables and inspection

iVar FORMAT fields, including depth and allele frequency, are retained in imported variant databases and exposed through a read-only compatibility overlay for older bundles. Variant columns now sort and filter with schema-aware numeric and string behavior, track identity remains stable when row identifiers overlap, and individual variant tracks can be hidden or restored without affecting other callers.

Selecting one variant opens a richer Inspector with caller, track, genotype, depth, quality, filter, consequence, and amino-acid context without moving the genome viewport. Selecting multiple calls or genotype rows produces an ordered multi-selection Inspector summary and preserves identities across sorting, filtering, and asynchronous query refreshes.

## Viewer interaction

Hover cards size to their content, organize long variant and mapping details into readable sections, and can be pinned for closer inspection and dismissed when finished. Long CIGAR strings remain available without clipping.

Zoom to Annotation now fits the selected feature inside the usable genome-view width after accounting for the Inspector and viewport insets. Empty successful classifier alignment states no longer display a redundant readiness banner.

## Metadata tables

Imported EsViritu metadata columns now participate in stable sorting and search alongside the built-in columns, with persisted column presentation and typed values retained across refreshes.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap pins are unchanged from v2026.9.35.
