# Lungfish 2026.11.20

Channel: Preview

Previous versioned release: v2026.11.19

Stable baseline: v2026.11.14

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This Preview adds rhesus and cynomolgus macaque to the RNA-seq reference sets, and each set now downloads a ready-made index, so it installs faster and needs far less memory. A TaxTriage organism that the report names differently from its reference genome now opens its alignment.

## What works differently

### RNA-seq

- **Four reference sets.** Plugin Manager > Databases > RNA-seq Reference Sets now offers:
  - Human, GRCh38 with GENCODE 50
  - Mouse, GRCm39 with GENCODE M39
  - Rhesus macaque, Mmul_10 with Ensembl 116
  - Cynomolgus macaque, T2T-MFA8v1.1 with RefSeq
- **A ready-made index.** Download fetches the genome, the gene annotation and a salmon index built ahead of time, checks each file, and sets them up for the count step. Before, every install built the index on your Mac. An install now needs about 6 GB of memory instead of about 16.6 GB, so a Mac with 16 GB can install a set and count against it. The mouse install took about half an hour on the test Mac.
- **The rows look like the other database rows.** The reference sets are the last section of the Databases list, drawn like the metagenomics database rows. Each row shows one figure, the disk space the set uses once installed: human 18.6 GB, mouse 15 GB, rhesus 10.9 GB and cynomolgus 13.5 GB. A row says why Download is off on that row, and an installed set reads **Installed**. Download on an installed set downloads nothing.

### TaxTriage

- **An organism reported under another name opens its alignment.** TaxTriage can report an organism under one name and download its reference genome under another, such as Haemophilus parainfluenzae, whose reference is named Parahaemophilus parainfluenzae. Such a row showed "No reference was recorded for this organism in this sample." Lungfish now links the row to its reference through their shared NCBI taxonomy ID, within the same sample, and keeps the name the report gave. When the ID matches references of more than one organism, or two rows of the same sample share the ID, the row stays unlinked.

## Things to know

The limits in the 2026.11.19 notes still apply, as do the earlier limits they keep, except that four RNA-seq reference sets are now offered and a Mac with 16 GB of memory can now install one.

- **Older TaxTriage results keep their unlinked rows.** The link uses a TaxTriage file that earlier versions of Lungfish deleted when a run finished. A result made by an older version keeps its unlinked rows. Run TaxTriage again to link them.
- **The cynomolgus set counts no mitochondrial genes.** Its T2T assembly has no mitochondrial genome.
- **A reference set cannot yet be removed** from the Plugin Manager.
- **The Databases total leaves out RNA-seq sets.** The footer of the Databases tab counts only the metagenomics databases.

## Updating

Choose Check for Updates… in the app menu to install this release. The RNA-seq reference sets use salmon and gffread from the RNA-Seq Analysis pack, which you install from the Plugin Manager if you have not.
