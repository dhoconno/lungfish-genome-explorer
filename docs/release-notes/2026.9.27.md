# Lungfish 2026.9.27

Channel: Preview

Previous versioned release: v2026.9.26

Stable baseline: v2026.9.4

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## Release toolchain

SwiftPM build and test helpers now use the supported Swift Build engine and ask
that same engine for its product path, so cached products cannot be confused
with output from another build engine. Release and CI configuration now targets
Xcode 27 / Swift 6.4 with macOS SDK 27 while keeping macOS 26 as the minimum
deployment target.

The 2026.2 managed dependency set and its existing pins are unchanged.

## Managed storage and release cleanup

Preview and Debug can share managed tools and databases when their dependency
manifests and verified receipt match. Debug adopts the compatible Preview
storage only when no explicit Debug storage has been selected; explicit storage
still wins, and child workflows receive the resolved storage paths.

Stable now uses its own managed-storage and configuration roots and does not
silently inherit Preview or legacy storage preferences. Dependency verification
rejects every known managed root, while CI uses an isolated temporary storage
root.

Local release retention is an explicit, audited cleanup workflow. It keeps
receipts and evidence, holds candidates with unfinished signing or unverified
publication, checks for active compiler/release processes and open files, and
records a witness before removing only eligible old payloads.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database,
and bootstrap pins are unchanged from v2026.9.25.

## Known setup limitation

A first CLI-only setup in an empty managed-storage root can report a micromamba
bootstrap checksum mismatch because app packaging re-signs that executable.
The required environments can still finish installing. Rerun the same
`tools update --apply --yes --required-only` command and require successful
completion with no pending changes before using that root. This release does
not change or relax the pinned source checksum. The newly provisioned Stable
root on the release machine passed that follow-up check; clean one-pass setup
is not claimed.
