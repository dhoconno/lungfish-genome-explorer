# Lungfish 0.5.0-beta2

Previous release: v0.5.0-beta1

## Highlights

- Fixed weekly import and analysis issues covering EsViritu empty-result handling, classifier folder inputs, TaxTriage miniBAM resolution for downsampled reads, VSP2 human-read removal, and VSP2 read-reduction reporting.
- Added the revised Tools menu with concrete tool entries in each category submenu.
- Added Trim Galore support for FASTQ storage optimization, including a GUI compression-tool chooser and dynamic BBTools/Trim Galore defaults based on input size and available memory.
- Kept storage optimization as the final import/recipe stage and records before/after on-disk file sizes for inspector provenance.
- Restored the exact ONT/PacBio demultiplexing path for built-in PacBio barcode IDs and added compact sample-sheet help in the ONT import dialog.
- Updated Sparkle release packaging so beta builds publish through the `sparkle-beta` feed while bridging legacy alpha installations through `sparkle-alpha`.

## Notes

- GenBank submission tooling remains deferred to a future release.
