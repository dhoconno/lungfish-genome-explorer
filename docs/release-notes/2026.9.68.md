# Lungfish 2026.9.68

Channel: Preview

Previous versioned release: v2026.9.67

Stable baseline: v2026.9.65

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes primer design in a project.

## Fixes

- **Primer designs are saved again.** Since 2026.9.57, every Primer3, PrimalScheme, Olivar, and varVAMP design run inside a project finished its work and then failed with "Invalid primer analysis provenance: output inventory does not match". LGE records paths inside a project relative to the project, and the check that opens a saved design still expected full paths. Designs saved before 2026.9.57 were not affected, and they still open.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.67.
