# Lungfish 2026.9.56

Channel: Preview

Previous versioned release: v2026.9.55

Stable baseline: v2026.9.54

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes a second MiSeq MHC genotyping failure that 2026.9.55 uncovered.

## Fixes

- **MiSeq amplicon MHC genotyping failed after mapping with "Retained-read demultiplex filter did not return valid JSON".** Read bundles merged at import could still be recorded as holding read pairs. Genotyping then sent them through a pair merge that found nothing to merge and counted zero fragments for every sample. With a run total of zero, the retention percentage could not be computed and the run stopped even though genotyping had succeeded. LGE now maps reads that were merged at import as they are, counts every fragment in the run total, and finishes the run with a warning if a total is ever unavailable. The "inputs contain unmerged read pairs" message now counts only samples whose reads have mates. Rerun any cohort that failed this way.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.55.
