# Lungfish 0.5.0-beta6

Previous release: v0.5.0-beta5

## Highlights

This beta fixes a failure in the full-length MHC ONT import recipe when users
load a PacBio barcode-pair sample sheet with built-in barcode IDs such as
`BC1001` and `BC1021`. The importer now treats this recipe as a PacBio
barcode-pair workflow, accepts compact headerless rows in
`sample_id,barcode_1,barcode_2` order, and resolves those `bc*` IDs against the
built-in PacBio Sequel barcode sets before demultiplexing.

The same validation now happens immediately when the recipe starts, before
Lungfish creates the output directory or begins the more expensive FASTQ
processing work. If the sample sheet is malformed, the error now explains the
expected format and includes the first non-empty row from the sheet, which
should make it much easier to distinguish a missing column from an unsupported
barcode value.

This also removes the confusing failure mode where a generic two-column
`sample,barcode` sheet could be interpreted as a custom barcode kit and pass
`BC1001` through to cutadapt as though it were a DNA sequence. That is what
produced the earlier `Character '1' in adapter sequence 'BC1001' is not a valid
IUPAC code` error.

## Notes

This remains a beta prerelease. The release is packaged as a signed and
notarized Apple Silicon DMG and published to the Sparkle beta feed for testers.
