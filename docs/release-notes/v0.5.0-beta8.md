# Lungfish 0.5.0-beta8

Previous release: v0.5.0-beta7

## Highlights

This beta fixes the split genotype comparison matrix so the pinned genotype
columns and the per-sample columns remain on the same row while scrolling in
either direction. Scrolling the left identity pane now drives the sample pane,
and scrolling the sample pane drives the identity pane, without disturbing the
sample pane's horizontal position.

It also fixes the last visual mismatch at the top and bottom of the matrix.
Both panes now reject provisional vertical origins outside their document
bounds, so the pane under the pointer cannot rubber-band independently while
the other pane remains aligned. The result is a stable row-for-row matrix at
normal positions and at both vertical boundaries.

## Notes

This remains a beta prerelease. The release is packaged as a signed and
notarized Apple Silicon DMG and published to the Sparkle beta feed for testers.
