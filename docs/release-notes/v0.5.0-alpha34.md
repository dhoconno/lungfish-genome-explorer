# Lungfish 0.5.0-alpha34

Previous release: v0.5.0-alpha33

## Genotyping Workbook Preview

This alpha fixes the main viewport for amplicon genotype result bundles created
from references that do not provide haplotype definitions. Those bundles still
produce a reproducible Excel workbook, but previous builds opened the native
haplotype-oriented genotype viewport whenever genotype call rows were present.
Without a haplotype analysis to render, that could leave the central viewport
empty while the Inspector correctly listed `artifacts/workbooks/current.xlsx`.

Opening a `.lungfishgenotype` bundle with no haplotype analysis now previews the
resolved workbook directly, including the editable `current.xlsx` workbook when
the bundle has one. Bundles that do include haplotype analysis continue to open
in the native genotype review viewport.

## Release Maintenance

Sparkle appcast release-note links now publish with the alpha release flow, so
graphical updater metadata points users at the matching version notes.

This remains an alpha prerelease. The build was published as a notarized Apple
Silicon DMG and added to the Sparkle alpha update feed.
