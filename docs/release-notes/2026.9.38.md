## Haplotype definition editor

The haplotype editor now keeps the associated allele list distinct from the diagnostic subset used by calling rules. Shared matrix coloring applies across associated alleles, while each definition retains exact provenance for its stored metadata and source identity.

The editor dialog is resizable and presents compact metadata and palette controls. The internal color token label is no longer shown in the visible editor UI; stored color token indices remain unchanged.

Existing definitions retain their diagnostic selections and calling thresholds until explicitly edited.
