# Lungfish 2026.10.26

Channel: Preview

Previous versioned release: v2026.10.25

Stable baseline: v2026.9.78

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This Preview fixes one wrong number in Preview 2026.10.25. The owner checks before the planned Stable release found it, and this build replaces 2026.10.25 as the build planned to become the next Stable release.

## What works differently

### Read statistics

- **A read set being counted no longer shows another read set's numbers.** In 2026.10.25, when you selected an older demultiplexed, trimmed or filtered read set whose statistics had not been counted, Lungfish Genome Explorer (LGE) counted its reads out of sight. Until the count finished, about 13 seconds for each million reads, the cards, the reads list and the Inspector kept the numbers of the item you had open before, such as another barcode's read count, Mean Q and GC. The viewer now clears at once and shows `Measuring the read statistics for <name>...` with a running count of reads, and then the read set's own numbers. If you copied numbers of such a read set in 2026.10.25 right after selecting it, open it again and check them.
- **A sample metadata edit stays with its sample.** A change you have just typed into a sample's metadata, or a read type you have just chosen, is saved to that sample when you select another read set, and never to the next one.
- **A read set with no FASTQ file says so.** Selecting one left the previous read set's numbers on screen. The viewer now clears, and the status bar says to wait for its import to finish or to import the reads again.

## Things to know

- **Older read sets are counted once a session.** An older demultiplexed, trimmed or filtered read set is counted the first time you open it after each launch. If you select another item while it is counted, the count stops and starts again when you come back.
- The limits in the 2026.10.25 notes still apply.
