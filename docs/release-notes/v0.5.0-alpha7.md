# Lungfish 0.5.0-alpha7

Hotfix release for ONT FASTQ import and amplicon-genotyping input preparation.

- Fixed copying existing `.lungfishfastq` bundles into another project so ONT bundles are preserved atomically instead of being re-ingested from the preview or first chunk.
- Added ONT directory import storage options: keep chunks, flatten each barcode to a single FASTQ, and optionally optimize flattened payloads with clumpify.
- Added matching `lungfish fastq import-ont` CLI options and provenance recording for storage mode, optimization, quality binning, and clumpify steps.
- Ensured failed ONT import optimization rolls back created bundles, manifests, and provenance instead of leaving partial scientific outputs behind.
- Guarded operation progress updates so late background progress cannot overwrite completed or failed operation state.
