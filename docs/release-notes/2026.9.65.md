# Lungfish 2026.9.65

Channel: Stable

Previous versioned release: v2026.9.64

Stable baseline: v2026.9.60

Dependency set: 2026.2

This release fixes problems found while retaking the user manual's screenshots, makes provenance exports of mapping results usable again, and ships the retaken screenshots with the manual. It collects Preview releases 2026.9.61 to 2026.9.64.

## Provenance and assembly records

- **Provenance exports of a mapping result are usable again.** Exporting a minimap2 result as a Nextflow, Snakemake, shell, or Python script wrote only a "Replay unavailable" stub because the run ends with an in-app step that prepares the viewer. The export now replays the tool steps and notes the in-app step as not replayed.
- **A Flye run started from the window records its profile and why it was chosen.** The Inspector's Assembly Context now shows Profile and Profile Basis rows, such as Nano Raw chosen for reads below Q10.

## Fixes

- **A reference bundle made with Create Bundle stays in the project of the window it came from.** With two project windows open, closing one could make Create Bundle in the other copy the new bundle into the closed project's Downloads folder and switch the sidebar to that project.
- Running an analysis no longer leaves an empty Downloads folder in the project.
- Opening a primer analysis no longer widens the project window, and the Binding inspection view fits its column. The alignment stays inside its box, and in narrow spaces its toolbar hides the color scheme, variable-site, and site-mode controls until the rest fit.
- The Type column of the Variants table and the GT and Zygosity columns of the Genotypes table are readable on a selected row.
- The assembly sheet's Curated extra arguments section lists only options it has controls for, and its Readiness card is tall enough for its message.

## Documentation

- The user manual's screenshots were retaken on this release series, and captions and procedure text now match the current Operations Panel, assembly sheets, primer analysis views, Nextflow export, and variant tables.

## Included preview releases

Includes Preview 2026.9.61, 2026.9.62, 2026.9.63 and 2026.9.64. This release reconciles those previews' notes and the changes since Stable 2026.9.60. Stable promotion adds no further product changes.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from Stable v2026.9.60.
