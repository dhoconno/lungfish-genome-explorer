# Lungfish 2026.9.74

Channel: Preview

Previous versioned release: v2026.9.73

Stable baseline: v2026.9.72

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release lets you read exported workflows inside LGE.

## Viewer

- **Workflow and script files that macOS cannot preview now open as text in the viewer.** A provenance export's Nextflow `main.nf` and `nextflow.config`, a Snakemake `Snakefile` and its conda environment `.yaml` files, `.smk`, `.R` and `.toml` files, and extension-less files such as `Makefile` and `Dockerfile` show as selectable, read-only monospaced text. Before, they showed only a generic document icon. Files macOS can preview, such as Markdown, keep using the system preview.
- Text previews are capped at 2 MB, and the status bar says when a file is truncated. Binary files are never shown as text.

## Documentation

- The provenance export chapter says the exported Nextflow and Snakemake files can be read in the viewer, and the file formats appendix lists which text files preview.
- A catalogue of planned quick videos for learners, people switching from other apps, and command-line users (`screencasts/CATALOGUE.md`).

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.73.
