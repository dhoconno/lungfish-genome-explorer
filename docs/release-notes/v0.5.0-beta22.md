# Lungfish 0.5.0-beta22

Previous release: v0.5.0-beta21

## Reliable actions for Savont cluster results

This release completes the standalone Savont workflow by making the standard
FASTA right-click actions work consistently for one selected cluster or a group
of selected clusters. **Extract Sequence**, **Copy FASTA**, **Export FASTA**,
**Create Bundle**, **Align with MAFFT**, **Verify with BLAST**, and **Run
Operation** now use the visible selection in its displayed order. Right-clicking
within an existing multi-row selection preserves that group; right-clicking an
unselected row makes that row the action target.

The implementation reuses Lungfish's existing FASTA detail view, BLAST results
drawer, MAFFT interface, operation chooser, and reference-bundle workflow. It
does not introduce a separate Savont-only interface. This keeps the behavior of
cluster consensus sequences aligned with ordinary FASTA records throughout the
application.

## BLAST results in the FASTA detail pane

BLAST verification now opens the existing results drawer in the lower pane and
shows submission progress, completed matches, and useful failure information.
Cancel and rerun controls operate on the current request, while selecting a new
row cancels an in-progress request and restores the normal FASTA sequence
detail. Older network responses can no longer replace results for a newer
selection.

The BLAST limit remains explicit: up to 50 selected sequences can be submitted
at once. Larger selections leave the action unavailable rather than beginning a
request that cannot be represented safely.

## Extraction, bundle creation, and alignment

Sequence extraction and FASTA export now report errors instead of silently
failing. Creating a reference bundle from a Savont result directly reuses the
existing `extract contigs` workflow, which supports one or many selected FASTA
records and preserves their requested order. MAFFT now opens directly in the
existing alignment operation rather than sending users through an unrelated
generic chooser.

Reference bundles created from selected Savont clusters retain the durable
source FASTA, the exact selected record identifiers, resolved options, output
checksums and sizes, and the command needed to reproduce the bundle. Temporary
selection files are not treated as durable inputs and do not remain embedded in
the final provenance.

## Cleanup and provenance safeguards

Temporary FASTA selections are now registered before they are returned to an
operation, removed as a complete unit when materialization fails, and cleaned
up synchronously when Lungfish quits. They are stored in session temporary
space rather than hidden inside a project, reducing the chance that exploratory
operations inflate project archives.

Annotated extraction also records the durable source sequences, selected
record identifiers, exact annotation definitions, and the checksum and size of
the generated interval data. Multi-document FASTA collections retain their
source scope when moving into a sequence detail and back, so subsequent actions
continue to refer to the files the analyst actually opened.

## Notes

This remains a beta prerelease. It is distributed as a signed and notarized
Apple Silicon DMG through GitHub and the Sparkle beta update feed. The same
signed update entry is published to the legacy alpha bridge so older alpha
installations can move onto the beta channel.
