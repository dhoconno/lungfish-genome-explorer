# Lungfish 0.5.0-beta12

Previous release: v0.5.0-beta11

## Highlights

The genotype viewport is now a more complete review surface. Analysts can mark
supported calls as false positives, mark unsupported calls as false negatives,
and add one editable comment to a cell, sample column, or allele row. These
decisions are visible in the matrix, recorded in the bundle audit trail, and
carried into `current.xlsx`: false positives retain their read count in faded
italic brackets, false negatives receive a clear cell border, and comments are
written as Excel cell comments.

Genotype-only workflows now have the same practical review tools for both
full-length ONT and miSeq amplicon MHC results. The matrix can show provisional
exon 2 sequences, while keeping them separate from named alleles. Analysts can
also add manual haplotype labels beneath each sample header, edit them from the
sample detail pane, reuse labels entered elsewhere in the analysis, and copy
selected assignments from another sample without copying an entire genotype
profile.

The sample detail pane has been rebuilt for readability and accessibility. It
uses the available width for manual assignments and Supported Alleles, keeps
the sample context fixed while evidence scrolls, supports larger macOS text
sizes, and explains the automated call-support status in plain language.
Search now matches sample names and allele text reliably, filters accept typed
numeric values, selected rows and columns are visibly consistent, and controls
that do not apply to genotype-only analyses are hidden.

## Workbook and project reliability

Workbook updates are now coordinated rather than attempted for every small
edit. Lungfish tracks whether `current.xlsx` is up to date, refreshes it after
an idle period or when changing bundles, and offers **Update and View Current
Excel Version** when an immediate handoff is needed. Workbook update attempts
are audited, and failed or stale results no longer replace a valid workbook.

Project storage management now identifies removable workflow staging data and
old workbook generations, explains what will be reclaimed, moves eligible data
to the Trash, and records the cleanup decision and result for traceability.
Genotyping workflows also retire temporary staging data after a successful run
instead of retaining repeated full copies of a result bundle.

## Notes

This remains a beta prerelease. The release is packaged as a signed and
notarized Apple Silicon DMG and published to the Sparkle beta feed for testers.
