# Lungfish 2026.9.49

Channel: Preview

Previous versioned release: v2026.9.48

Stable baseline: v2026.9.28

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## Assembly viewer layout

- Assembly results now offer **Bundle**, **View**, and **Provenance** tabs in the Inspector. Under **View**, choose detail on the left, list on the left, or list above detail.
- Layout changes apply immediately and keep the selected contig and active name/header filter. The chosen layout is remembered for later assembly results.
- The assembly summary and contig search field now sit below the window toolbar instead of extending behind it. They remain visible when the window is resized.

These changes apply to existing assembly results as well as new runs. Assembly sequences, statistics, and provenance are unchanged.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap pins are unchanged from v2026.9.48.
