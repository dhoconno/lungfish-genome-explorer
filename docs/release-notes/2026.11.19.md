# Lungfish 2026.11.19

Channel: Preview

Previous versioned release: v2026.11.18

Stable baseline: v2026.11.14

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This Preview lets you install a human or mouse RNA-seq reference from the Plugin Manager and count reads per gene with no Terminal step. TaxTriage now picks every organism Kraken2 finds for alignment, and far more organisms show a Unique Reads count. Extract Sequence saves to a FASTA file again on an older GTF track.

## What works differently

### RNA-seq

- **Install a reference set from the Plugin Manager.** Plugin Manager > Databases has a new section, RNA-seq Reference Sets, with two rows: Human, GRCh38 with GENCODE 50 and Mouse, GRCm39 with GENCODE M39. Download fetches the genome and gene annotation, checks each file, and builds the index the count step needs. It needs the RNA-Seq Analysis pack, about 16.6 GB of memory and 64 GB of free disk while it builds, and about 18 GB stays afterwards. The row tells you before you start when the pack or the memory is missing, and when the disk is short Download stops before anything downloads. The human install took about an hour on the test Mac, and a second Download reuses what is there.
- **The count dialog points you to the install.** When no reference set is installed, the count dialog says "Download a reference set in Plugin Manager to count these reads." with a button that opens the Databases tab. The list fills in after an install.
- **Clearer names.** Quantify RNA-seq Reads is now **Count Reads per Gene**. Export RNA-seq Counts is now **Export Counts and Analysis Scripts**. In the Import Center, RNA-seq Counts is now **Existing Bulk RNA-seq Counts** and Single-cell Counts is now **Existing Single-cell Counts**. The bulk card says how to start from FASTQ files: import them as Sequencing Read Files, then choose Tools > RNA-seq > Count Reads per Gene.

### TaxTriage

- **Every organism is picked for alignment.** TaxTriage aligns reads only to the organisms it picks from the Kraken2 report. Advanced Settings now has **All organisms** beside Top hits, on by default, so TaxTriage picks every species Kraken2 finds, and each one it finds a reference genome for gets a BAM. A run with many species downloads more references and takes longer. Turn All organisms off to set a number, now up to 1,000, for a quicker run. On the command line the default stays 10, and `--top-hits 1000000` picks every species.
- **Unique Reads shows for far more organisms.** Unique Reads now counts only reads with a mapping quality of 5 or more, the same rule TaxTriage uses for Reads Aligned. Before, reads that fit several genomes equally well were counted too, the count came out above Reads Aligned, and the table showed a dash. In one test sample, 112 of 130 organisms showed a dash and now 10 do. Results made by an older version keep their old counts until TaxTriage runs again.

### Other fixes

- **Extract Sequence saves again on an older GTF track.** On a transcript or coding sequence of a GTF track that an older version imported, Extract Sequence… then Save to File… showed a note about the GTF and then never opened the save panel, so no file was written. The note now shows after you choose where to save.
- **Remove All removes GATK Core, Variant Phasing and Single-Cell Analysis.** In the Plugin Manager, Remove All on these three packs removed nothing and said nothing, so their tools stayed installed and used disk space. It now removes them like the other packs.
- **The Provenance Signing words say what happens.** Under Settings > General > Provenance Signing, the status line said a record was signed with a stored Keychain key when no record was signed. It now says that Lungfish signs a record only when `LUNGFISH_PROVENANCE_SIGNING_KEY` or `LUNGFISH_PROVENANCE_SIGNING_KEY_FILE` holds a key, and that the saved key is not used.

## Things to know

The limits in the 2026.11.18 notes still apply, as do the earlier limits they keep.

- **No comparison of conditions in the app yet.** Count Reads per Gene gives counts per gene. Finding which genes change between conditions still means running the scripts that Export Counts and Analysis Scripts writes, in R outside the app.
- **Two RNA-seq reference sets.** Only human and mouse are offered, and a reference set cannot yet be removed from the Plugin Manager.
- **A Mac with 16 GB of memory or less** cannot build the index, which needs about 16.6 GB, and Download is off there.
- **A signing key saved in Settings is not used.** Set one of the two variables above to sign records.

## Updating

Choose Check for Updates… in the app menu to install this release. The RNA-seq reference sets use salmon and gffread from the RNA-Seq Analysis pack, which you install from the Plugin Manager if you have not.
