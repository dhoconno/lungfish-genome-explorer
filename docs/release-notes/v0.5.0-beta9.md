# Lungfish 0.5.0-beta9

Previous release: v0.5.0-beta8

## Highlights

This beta adds annotated GenBank support for MHC reference bundles. A GenBank
reference can now be imported with its recoverable sequence annotations and
record fields, while FASTA-only MHC bundles continue to work as before. The
reference view exposes GenBank record fields as filterable columns, and limits
the annotation detail display to the records currently visible in the list.

MHC genotype results now retain the embedded GenBank record metadata used for
the run. In the comparison matrix, choose which available GenBank fields appear
in the left identity pane, including allele labels instead of opaque accession
identifiers. The genotype-only workflow has one Summary viewport with a
list-over-detail layout: selecting samples, alleles, or cells now shows the
corresponding useful metadata and support details rather than low-coverage
sample summaries.

## Stability

The matrix keeps its identity and sample rows synchronized while scrolling,
including at the first and last rows. Large multi-selections and duplicate
support records are handled without redundant refreshes or duplicate evidence.

Fluidigm ONT sample splitting now writes complete provenance when its input is
a FASTQ directory such as a FASTQ_pass barcode folder. Directory inputs and
generated sample directories receive aggregate checksums and sizes, so a split
that has successfully materialized its sample bundles no longer fails during
final provenance recording.

## Notes

This remains a beta prerelease. The release is packaged as a signed and
notarized Apple Silicon DMG and published to the Sparkle beta feed for testers.
