# Lungfish 0.5.0-alpha19

Previous release: v0.5.0-alpha18

## Hotfix Alpha Release

This alpha hotfix restores the ONT import workflow needed for Fluidigm sample
splitting before amplicon genotyping.

## Highlights

- ONT run-folder import now opens a recipe-oriented dialog instead of the
  legacy storage-only dialog.
- The default ONT recipe is "Split by Fluidigm sample barcodes", with a required
  barcode definition selector so users can choose the CSV/TSV/TXT file that
  deconvolutes reads by sample during import.
- The sample-splitting import route uses the existing CLI-backed
  `fastq ont-fluidigm-samples` operation, producing counted per-sample
  `.lungfishfastq` bundles without importing the individual ONT barcode chunks
  when that recipe is selected.
- Legacy ONT chunked and flattened imports remain available from the same
  dialog for older projects and non-Fluidigm use cases.

## Verification

- Focused GUI and FASTQ operation regression tests cover the new ONT import
  route, barcode-definition requirement, CLI invocation, and provenance
  rehydration for generated sample bundles.
