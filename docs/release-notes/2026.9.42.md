# Lungfish 2026.9.42

Channel: Preview

Previous versioned release: v2026.9.41

Stable baseline: v2026.9.28

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release adds two new primer design tools, lets you copy results between projects by dragging them, and saves disk space when more than one copy of LGE is installed. It also fixes how the Krona chart labels its percentages and how read tools treat files that mix merged reads with pairs.

## Primer design

- **Olivar and varVAMP join the PCR Primer Design pack.** Olivar designs tiled amplicons in two pools. varVAMP designs single amplicons, tiled schemes, or qPCR assays with a probe. Both start from an alignment you already have in the project. Install or update the pack from **Tools > Plugin Manager** to get them.
- **All scheme designers now share one result view.** PrimalScheme, Olivar and varVAMP results open in the same viewer and Inspector, with pools, primer roles and probes shown the same way.
- Saved primer analyses record the exact settings, inputs and tool versions used, and reopen without the design tools installed.
- Exported primer schemes keep their pools and primer names exactly as designed.
- Primer packs exported from an earlier version still import.

## Copying between projects

- **You can drag any LGE item from one project into another.** Before, dragging a Kraken 2 result or other analysis folder into a new project scattered its files and the result would not open. The whole item is now copied, and it opens in the new project.
- If a copied item points to reads or a reference that stayed behind in the first project, the new project says so. A banner in the viewer and a **Missing sources** section in the Inspector list what is missing, and actions that need it are turned off with an explanation. Everything else about the item still works.

## Krona chart and taxonomy percentages

- **The Krona chart now says what each percentage is out of.** The centre shows the share of all reads, and a zoomed view shows the share of classified reads. Before, the labels did not say which, so numbers looked wrong next to the table.
- Small groups of taxa that are pooled into one wedge are coloured like their parent and show their members when you point at them.
- The taxonomy table's tooltips use the same wording.

## Reads that mix merged reads with pairs

A read file can hold both merged reads (where the two mates overlapped and were joined into one read) and pairs that could not be merged. Every read tool in LGE now has a rule for these files. Tools that can handle both kinds do so. The rest treat every read as a single read, which is safe, instead of pairing reads by position and mixing up mates.

- **BWA-MEM2, Bowtie2 and BBMap now map a paired sample stored in one file as pairs.** Before, they mapped each mate as an unrelated read.
- Splitting a paired file into two files (deinterleave) can now write the merged reads to a third file with `--unpaired`.
- Result rows say how the reads were actually treated, for example as pairs or as single reads.
- Recipes, the Workflow Builder, MHC merging and Kraken 2 use the same rule.

## Disk space

- **The command-line tool inside LGE Preview now uses the same storage folder as the app.** Before, it kept its own copy of every tool and database.
- **Different LGE versions on one Mac now share tool downloads.** Preview, Stable and Debug keep one shared copy of each downloaded tool package, and a database that one version has already downloaded and checked is copied from it instead of downloaded again. These copies take no extra space on the Mac's disk.
- **Settings > Storage has a new Reclaim Duplicate Space button**, and `lungfish-cli storage dedupe` does the same from the command line. Both find identical files across LGE's storage folders and make them share space. `lungfish-cli storage info` shows where each version keeps its files.

## Other changes

- **Tools > Workflows** lists the linked workflow packages in one submenu.
- **Flye** now preselects the **Nano Raw** profile when the reads' average quality is below Q10, and **Nano HQ** otherwise. A caption under the Profile picker says why, and you can still change it. The command line applies the same rule when `--profile` is left off.
- After you open another project in the same window, the viewer no longer keeps showing the previous project's item.
- The primer design tools read their install settings from the same list as every other tool.

## Dependency versions

Dependency set 2026.2 is unchanged. The optional PCR Primer Design pack adds two tools, each in its own environment with a checksum-bound package lock for macOS on Apple silicon:

- Olivar 1.3.3 (`bioconda::olivar=1.3.3=pyhdfd78af_3`)
- varVAMP 1.3.2 (`bioconda::varvamp=1.3.2=pyhdfd78af_0`)

All other managed tool, optional pack, pipeline, database, and bootstrap pins are unchanged from v2026.9.41.
