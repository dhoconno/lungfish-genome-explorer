# Lungfish 0.5.0-alpha6

Hotfix release for haplotype definition management and platform-aware amplicon genotyping.

- Added a CLI-backed haplotype definition manager so compatible definitions can be imported, exported, cloned, edited, and selected before running genotyping.
- Added assay/species-scoped haplotype definition selection to the genotyping workflow.
- Added the `lungfish fastq genotype` CLI seam for ONT barcode-demux and prepared Illumina sample-bundle genotyping.
- Added the `illumina-amplicon-merge` FASTQ import recipe so Illumina R1/R2 amplicon reads are merged and clumpified before genotyping.
- Updated Illumina genotyping to consume prepared per-sample bundles and record provenance that no internal read merge was performed.
