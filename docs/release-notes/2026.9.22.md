# Lungfish 2026.9.22

Channel: Preview

Previous versioned release: v2026.9.21

Stable baseline: v2026.9.4

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## Genotyping Inspector and matrix presentation

All five genotyping Inspector tabs now use a more compact, consistent presentation. Labels and values adapt at narrow widths, long identities and status text wrap cleanly, and scientific values remain selectable. Routine explanation has moved into contextual help while selection identity, review controls, annotations, filter state, warnings and complete provenance remain available.

In paired haplotyped MiSeq results, the Genotype Matrix now uses the available viewport without opening the bottom detail pane, including after selection and refresh changes. The Haplotype Calls detail and editing workflow remains intact, as do the existing detail behaviors for ONT, genotype-only and manual-workbench results. Narrow split layouts now allocate the matrix viewport consistently.

Genotype export keeps a single, native save action with progress and actionable failure feedback. Static save-panel explanation and persistent last-export presentation have been removed without changing the captured scientific snapshot or durable export provenance.

## Editable genotype workbooks

Every worksheet in an exported genotype workbook is now editable. Calls, literal values, colors, filters, comments, annotations, stable identifiers, formatting and export provenance are preserved, and the workbook remains a one-way report rather than a source for reimport into Lungfish.

## Dependency versions

Dependency set 2026.2 (2026-08-18) and all managed tool, optional pack, pipeline, database and bootstrap pins are unchanged from v2026.9.21. The PCR Primer Design pack remains pinned to Primer3 2.6.1 and PrimalScheme3-LGE 3.3.0+lge.2.
