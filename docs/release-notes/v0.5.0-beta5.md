# Lungfish 0.5.0-beta5

Previous release: v0.5.0-beta4

## Highlights

This beta improves full-length ONT MHC genotyping when an amplicon contains a
putative novel allele that is not yet in the reference database. Unmatched
clusters are now normalized to the mapped amplicon boundaries of their closest
reference target before deduplication, so replicate samples with the same novel
sequence are reported as the same unmatched cluster instead of being separated
by extra flanking sequence. The genotyping workbook now includes the normalized
unmatched-cluster analysis, a unified pivot table that combines known reference
genotypes and novel unmatched clusters, and an exported FASTA of deduplicated
unmatched clusters with occurrence counts and sample membership in each header.

The unmatched-cluster FASTA is now a first-class genotype bundle artifact. It is
recorded in the bundle manifest and provenance, and the app inspector exposes it
alongside the workbook, CSV summaries, run stats, provenance, and audit sidecar
so users can retrieve the exact novel sequences used in the workbook summaries.

This release also carries the TaxTriage result layout follow-up from the beta4
series. Detail-leading table views retain usable table space while still showing
the selected detail region, preventing stacked layouts from collapsing the rows
that users need for navigation and review.

## Notes

This remains a beta prerelease. The release is packaged as a signed and
notarized Apple Silicon DMG and published to the Sparkle beta feed, with the
legacy alpha appcast bridge kept current for older prerelease installations.
