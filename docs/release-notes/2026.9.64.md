# Lungfish 2026.9.64

Channel: Preview

Previous versioned release: v2026.9.63

Stable baseline: v2026.9.60

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes one more layout problem in the Binding inspection view of a primer analysis.

## Fixes

- The alignment in the Binding inspection view stays inside its box. Its toolbar kept its full width, so the rightmost buttons and the alignment rows ran past the right edge. In narrow spaces the toolbar now hides the color scheme, variable-site, and site-mode controls, in that order, until they fit.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.63.
