# Lungfish 0.5.0-alpha21

Previous release: v0.5.0-alpha20

## Release Notes

This alpha is a tightening pass on the new full-length ONT MHC genotyping path.
The main change is that low-coverage DRB-style samples no longer force users to
choose Savont parameters by hand. Lungfish still starts with the strict Savont
default of QV90 and minimum cluster size 3, but when that strict pass produces
no ASVs it quietly retries that sample with the empirically useful QV90/minimum
cluster size 1 preset. The fallback keeps the quality filter in place, avoids
the false-positive riskier no-QV run, and records exactly which preset was used
in the sample summary and provenance.

The same path now treats Savont panics as sample-local failures during the
hidden fallback. A panic still appears in provenance with the failing command,
exit status, and stderr, but the rest of the plate can finish and the affected
sample is reported as a handled no-call instead of aborting the whole run. The
retained Savont output is also easier to audit: final ASVs and logs are kept in
the result bundle, while regenerable temporary tables are cleaned away after
provenance has been written.

ONT-derived FASTQ bundles also carry better cached statistics in this build.
Fluidigm sample demultiplexing, Fluidigm amplicon materialization, and PacBio
barcode demultiplexing now compute read length, base, GC, and quality summaries
from the emitted reads rather than storing placeholder counts. That makes newly
materialized ONT bundles more useful immediately in the app without requiring a
separate statistics refresh.

The workflow dialogs received a small layout pass at the same time. Full-length
ONT MHC and standard ONT genotyping controls now group report names, run
parameters, length filters, and call thresholds more consistently, while keeping
the Savont full-length workflow free of the older pbAA guide controls.

## Notes

- This release remains a prerelease build for testers.
- The release was validated with focused full-length ONT MHC workflow tests,
  ONT materializer tests, workflow dialog state tests, and the signed/notarized
  macOS release pipeline.
