# Lungfish 0.5.0-beta14

Previous release: v0.5.0-beta13

## More flexible MHC reference libraries

Full-length ONT MHC genotyping now accepts controlled provisional allele
labels in annotated Lungfish reference bundles. This includes extension labels
such as `Mamu-E*02:16:ext01` and nested provisional labels such as
`Mamu-E*02:new14:new01`. This makes it possible to run the supplied reference
set without renaming its records or stripping useful provisional information.

The reference is checked before Lungfish starts staging or processing samples.
If a reference contains an invalid label, the run stops early with a clear
message instead of spending time processing input reads. Reference import and
failure records continue to be written into the bundle for traceability.

## Smoother review and project behavior

This release also prevents the search index from reacting to its own temporary
provenance files, which avoids an unnecessary refresh loop while a project is
open. The manual haplotype strip uses its existing draw-based presentation,
which is more reliable during view updates, and the app’s cleanup and shutdown
callbacks now use safer main-window handoffs.

## Notes

This remains a beta prerelease. It is packaged as a signed and notarized Apple
Silicon DMG and published through the Sparkle beta update feed for testing.
