# Lungfish 2026.9.6

Channel: Preview

Previous versioned release: v2026.9.4

Stable baseline: v2026.9.4

Dependency set: 2026.2

Lungfish 2026.9.6 makes Viral Recon usable end to end. Runs now produce a
result you can see and open, and the wizard asks four questions instead of
nineteen. It also carries the launch fixes prepared as 2026.9.5, which was
built but never published.

## Highlights

Viral Recon results appear in the sidebar. A finished run used to leave a
raw pipeline directory and nothing else, so there was no entry to click and
nothing to open. A run now produces an analysis bundle whose viewport shows
the alignment and the variant calls over one coordinate system.

The reported symptom was that the aligned reads could not be displayed. The
alignment file was never at fault. The viewer opens a reference bundle whose
contents are registered for display, and Viral Recon was not building one.

Viral Recon is now explicitly a SARS-CoV-2 tool and says so. Every bundled
primer scheme is defined against that genome, so the reference is no longer
a question the wizard asks. It uses the SARS-CoV-2 genome already in your
project, and downloads it for you if it is not there yet.

The wizard shows four controls: your inputs, the primer scheme, the minimum
mapped reads, and whether the run is ready. Everything else has a sensible
default. Advanced users can still set any pipeline parameter through an
Advanced section, which now checks parameter names as you type rather than
failing several minutes into a run.

Docker is the only execution method offered, because it is the only one that
ever worked. Choosing Conda or Local previously produced a run that failed
after the wait. Both are refused up front now, and the manual is corrected.

## Fixes

Viral Recon runs to completion on Apple Silicon. Four separate launch
defects and two pipeline-step failures are resolved, including a reference
that could not be found, input paths containing spaces, resource caps that
were silently ignored, and a lineage step whose container cannot run on this
architecture.

Freyja lineage de-mixing works again from the Tools menu and the command
line. It had been passing an option removed in the version we ship.

MiSeq genotyping surfaces unmerged Illumina pairs, reports read counts
consistently across the genotype report, and filters pivot exports.
