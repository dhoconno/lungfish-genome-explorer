# Lungfish 2026.9.39

Channel: Preview

Previous versioned release: v2026.9.38

Stable baseline: v2026.9.28

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## EsViritu database downloads

Fixed EsViritu database installation incorrectly failing with “missing or empty hash.k2d.” The shared installer now validates the EsViritu archive format, installs it where EsViritu discovery expects it, and preserves the database's catalog version. Transactional rollback, payload checksums, and reproducibility provenance continue to reference the final installed files.

## Taxonomy sunburst plots

Corrected the Krona-style taxonomy plot so drawn sectors, labels, and mouse targets agree. Full-circle rings now respond across the entire ring, and zooming, resizing, or replacing the tree clears stale hover state. Tooltips now calculate “% of classified” using classified reads.

Read counts, percentages of all sample reads, and intentional gaps for reads assigned directly to parent taxa remain unchanged.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap pins are unchanged from v2026.9.38.
