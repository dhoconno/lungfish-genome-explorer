# Lungfish 2026.8.17

Channel: Preview

Previous versioned release: v2026.8.16

Stable baseline: v2026.8.13

Dependency set: 2026.2

Lungfish 2026.8.17 is a preview release that makes Debug, Preview, and Stable
builds explicit, portable profiles and turns release publication into a
receipt-bound transaction that can be repeated safely from a provisioned Mac.

v2026.8.15 and v2026.8.16 were prepared and tagged during release-process
validation but were not published as GitHub releases or Sparkle updates. This
release carries their user-visible changes forward and supersedes those
unpublished preparations.

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## Highlights

### Preview and Stable installations are independent

Preview uses the dedicated bundle identifier `com.lungfish.browser.preview` in
addition to its `Lungfish Preview.app` wrapper, visible name, Beta feed, and
updater host. Stable retains `com.lungfish.browser`. This separates Launch
Services identity, identifier-keyed settings, updater state, and app launch
behavior while allowing both applications to remain installed together.

Older Preview builds used the Stable identifier. Moving to this Preview requires
a one-time manual installation from the 2026.8.17 Preview DMG rather than an
in-place Sparkle update. Migrate any desired Preview-only settings manually.

### Releases use one verified operator path

Release-machine validation, credentialless packaging, and credentialed
publication enter through one coordinator. Unsigned candidates are bound to
their channel, commit, toolchain, metadata, and exact payload hashes before any
tag or remote release is created. Publication verifies that receipt, checks live
Sparkle build floors, pushes the source and annotated tag atomically, waits for
the required CI jobs on the exact tag commit, and only then signs, notarizes,
staples, and publishes the DMG and update feeds.

Interrupted publication is recovered by running the same publish command. The
candidate is reverified and reused without rebuilding, and no release command
implicitly deletes tags, releases, candidates, worktrees, or caches.

### Release checks are portable across provisioned Macs

Release Doctor no longer depends on developer-local package caches or an
optional ripgrep installation. CI installs its declared packaging prerequisites,
uses a committed Xcode package resolution, and exercises unsigned Preview and
Stable packaging on clean runners. SwiftPM tests locate packaged resources only
through the actually loaded test bundle, while installed apps and standalone
CLIs remain unable to fall back into a source checkout.

### Release Macs reuse bounded compiler intermediates

SwiftPM and Xcode intermediates are stored in an owner-only cache namespace
whose fingerprint includes the repository, Xcode, Swift, SDK, architecture,
deployment target, dependency locks, release contract, and build recipe. A
compatible release Mac can reuse those intermediates, while a toolchain or
recipe change selects a new namespace. Candidates, receipts, credentials,
signatures, and published artifacts never derive authority from cached files.

### Debug is an isolated local profile

`Lungfish Debug.app` uses `com.lungfish.browser.debug`, isolated state and cache
locations, no updater, and a local ad-hoc signature. Its assembly includes a
relocation and self-containment check so the app cannot silently depend on the
source checkout or Swift build directory. Debug has no tag, notarization, or
publication path.

## Known issues

- The 20260626 Kraken2 indexes display taxid 3418604 as
  `Betacoronavirus pandemicum`; identifiers are unchanged.
- The Apple Silicon bioconda Bracken compatibility package lacks a usable
  driver. Fresh installs receive the managed Bracken 3.1 source overlay, while
  existing working environments are preserved.
- `bioconda::bwa-mem2=2.3=hda5e58c_0` self-reports 2.2.1 because of an upstream
  packaging defect; Lungfish verifies the package identity from conda metadata.
