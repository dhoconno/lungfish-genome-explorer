# Lungfish 2026.9.58

Channel: Preview

Previous versioned release: v2026.9.57

Stable baseline: v2026.9.54

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes the problems found by clicking through 2026.9.57.

## Fixes

- **Opening a classification result could make the main window thousands of points tall.** The summary bar measured a long taxon name before it had a width. Long names now truncate inside their tile, and no result view can resize the window.
- **Interrupted runs now account for their scratch files.** The Operations Panel's Interrupted row counts the run's temporary working files in its size, and Remove Partial Output deletes them too, after you confirm.
- The quit and close-window warnings say where partial output goes (an Interrupted row in the Operations Panel), and they update if a run finishes while the warning is open.
- Relaunching LGE no longer opens a second window of the same project.
- Finished amplicon genotyping runs no longer leave an empty lock file beside the result.
- Provenance recorded by analyses that LGE runs through its bundled `lungfish-cli` now names the release build instead of "(dev)".
- The Provenance Source picker appears the first time a mapping result is selected.
- The Alignment Summary counts reads from primer-trimmed tracks only once.
- The Operations Panel's Results button opens Kraken2, EsViritu, TaxTriage and other analysis results.
- A finished result is selected in the sidebar, and folders keep their expansion, including when the sidebar search was used during the run.
- The variant drawer's toolbar buttons no longer overlap at narrow widths.
- The alignment Inspector's Pairwise Identity table fits the Inspector, with its Identity and Sites columns and Export button visible.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.57.
