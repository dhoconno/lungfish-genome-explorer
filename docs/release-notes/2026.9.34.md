# Lungfish 2026.9.34

Channel: Preview

Previous versioned release: v2026.9.32

Stable baseline: v2026.9.28

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## List column preferences

Lists with attached metadata now remember which metadata columns are shown and their column order when switching to another bundle and back. The fix covers EsViritu and other lists using the shared metadata table controls. Each list retains its own layout, and metadata updates preserve the positions of existing columns.

## Release packaging

DMG creation now reserves explicit space for the app and filesystem overhead, correcting a macOS image-sizing failure encountered while preparing 2026.9.33. That version was tagged but not published; this Preview delivers the column-persistence fix relative to the last published version, 2026.9.32.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap pins are unchanged from v2026.9.32.
