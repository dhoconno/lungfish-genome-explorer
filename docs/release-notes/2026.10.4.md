# Lungfish 2026.10.4

Channel: Preview

Previous versioned release: v2026.10.3

Stable baseline: v2026.9.78

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes the Search Online Databases window, which grew taller than the screen when its advanced search filters were shown, and shows the distance matrix when you open an alignment bundle.

## Distance matrix open by default

When you open an alignment bundle, the pane under it is now open on the Distances tab unless you hid it earlier, so the pairwise matrix is in view without a menu command. An alignment of more than 200 sequences shows a note in that tab instead of the grid. Hide it with **View > Hide Distance Matrix** (Control-Command-M), or switch to the Annotations tab, and LGE remembers that choice for the alignments you open later.

## Search window buttons stay in reach

Clicking Show on Advanced Search Filters in the Search Online Databases window made the window grow past the bottom of the screen, so its Cancel, Search and Download Selected buttons could not be reached. The window now keeps its size when the filters open, the filters and results scroll inside it, and the buttons stay at the bottom where you can click them or reach them with the Tab key.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.10.3.
