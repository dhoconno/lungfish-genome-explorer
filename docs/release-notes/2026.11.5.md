# Lungfish 2026.11.5

Channel: Preview

Previous versioned release: v2026.11.4

Stable baseline: v2026.10.29

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This Preview gives a previewed PDF an Inspector and toolbar that suit a PDF, shows the command a Demultiplex Barcodes row really ran, and gives a sample's own reads from a raw nf-core TaxTriage result or a refusal in words.

## What's new

- **A previewed PDF no longer keeps the Inspector and toolbar of the last result.** Before, a PDF or another file that you previewed after a Kraken 2 result kept the words of that result in the Inspector, such as "Select a metagenomics result in the sidebar to view its summary here." After a FASTA it kept the Chromosomes and Translate buttons in the toolbar. Now the Inspector and the toolbar suit a PDF in both cases.
- **A Demultiplex Barcodes row shows the command its run recorded.** The row in the Operations Panel now shows the command that the run's record holds, with your input and the run folder, and its Log no longer says that the row records no command. The limit for a rebuilt input is under Things to know.
- **Extract Reads on a raw TaxTriage result takes a sample's own BAM file.** When a TaxTriage result folder has lost its database, the Extract route in the app and `lungfish-cli extract` now take a sample's BAM by the name the pipeline gives it. They no longer take the reads of a sample whose name only begins the same way, such as S1 and S10. If two BAM files could belong to one sample, Lungfish stops and names both files, and you keep only that sample's file in the `minimap2` folder and try again. The limit that remains is under Things to know.
- **The buttons under a Kraken 2 result work again after its drawer closes.** Before, once you had opened and closed the Collections and BLAST Results drawer of a Kraken 2 result, the buttons under the table (Verify with BLAST, Export, Extract Reads, BLAST Results and Collections) took no click until you opened the drawer again.
- **A BLAST search that comes back after you reopen Lungfish opens from its row.** The Results button of a BLAST row that finished after you quit and reopened the app is now active, as it is for a search that finishes while the app stays open.

## Things to know

- **A Demultiplex row on a rebuilt input.** A Demultiplex row still shows the command recorded at launch, with `-o '<derived>'`, when the app had to rebuild the input as one file first. That is the case for a subset or other derived FASTQ. It is also the case for a bundle of several files, such as an ONT import, unless you pick the Exact Bare Barcode or Read Names engine.
- **A sample's own BAM file is gone.** If a sample's own BAM is gone, and another sample's name starts with this one's followed by a dot, underscore or hyphen (S1 and S1_2), the other sample's BAM can be taken when it has a name the pipeline does not give. Keep every sample's BAM file in the folder.
- **Earlier notes.** The limits in the 2026.11.4 notes still apply.

## Updating

Choose Check for Updates… in the app menu to install this release. It adds no tool to install on the Mac.
