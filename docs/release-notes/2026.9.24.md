## Deterministic Xcode dependency resolution

The release build now carries the complete Xcode package-resolution lock for the current project, including the ViewInspector revision used by the test graph. This keeps native release packaging reproducible on a fresh checkout and prevents Xcode from resolving an incomplete dependency set during candidate assembly.

## Included worktree state

The release source includes the integrated history from all open development worktrees. No worktree contained additional uncommitted or unmerged changes at release preparation time; the Preview candidate is built from the resulting clean main checkout.
