# Lungfish 0.5.0-alpha5

Hotfix release for the ONT genotyping and genotype result viewer workflows.

- Enabled bundled ONT Genotyping by default on fresh installs while preserving explicit workflow library disable/enable choices.
- Show the primary Excel genotype workbook for `.lungfishgenotype` bundles that were run without deterministic haplotyping, instead of opening a blank haplotype viewport.
- Clear stale native genotype views before showing workbook previews so switching between haplotyped and non-haplotyped bundles leaves the viewport in the correct state.
