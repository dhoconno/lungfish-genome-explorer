# Lungfish 0.5.0-alpha22

Previous release: v0.5.0-alpha21

## Release Notes

This alpha focuses on making the ONT-heavy workflows easier to audit after a
run finishes and less disruptive while the app is managing large projects.

Full-length ONT MHC genotyping now gives unmatched Savont clusters a more useful
workbook trail. The existing raw `Unmatched Clusters` sheet is still present,
but the workbook also includes a closest-match detail sheet and a shared pivot
that groups unmatched clusters by their nearest reference-like identifier across
samples. SNP-containing alignments are retained for closest-match reporting
instead of being discarded as non-genotype calls, and indel-only zero-SNP hits
are labeled as extensions of the nearest reference. The result is a better
review surface for the cases that are biologically interesting precisely because
they did not become exact calls.

ONT demultiplexing imports now let the operator name the destination folder for
recipe-generated FASTQ bundles. The app suggests a stable name from the run
folder, sanitizes unsafe characters, and uses that folder when launching the
Fluidigm and PacBio barcode demultiplexing recipes. The GUI-visible command now
points at the final planned output target rather than only the recipe staging
root, which keeps the command preview and provenance easier to reconcile.

Project deletion and move-menu behavior received a responsiveness pass. The
delete planner now builds a structured dependency index instead of repeatedly
rescanning every project object, ignores incidental path-looking text outside
dependency fields, and treats MHC and 12S bundles as opaque project objects.
The Move To menu now derives candidate folders from the sidebar model rather
than walking the whole project tree again. These changes are intended to make
large project interactions feel steadier while preserving the same dependency
warnings before destructive cleanup.

The workflow dialog also caches haplotype and reference-bundle summaries during
a dialog session, reducing repeated filesystem and bundle-library reads while
the user edits unrelated controls. A lightweight `PerfSignpost` helper now marks
sidebar deletion, filesystem trashing, model mutation, notification, and outline
refresh intervals for Instruments traces, so future responsiveness work can be
measured directly instead of inferred from UI pauses.

## Notes

- This release remains a prerelease build for testers.
- The release was validated with focused FASTQ import, full-length ONT MHC,
  project deletion, sidebar selection, and release packaging tests, followed by
  the signed/notarized macOS release pipeline.
