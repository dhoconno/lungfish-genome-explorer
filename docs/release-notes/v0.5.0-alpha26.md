# Lungfish 0.5.0-alpha26

Previous release: v0.5.0-alpha25

## Summary

This alpha focuses on making genotype review more trustworthy and easier to
audit. The most visible change is in the haplotype visualization viewport: weak
automated haplotype calls are now tinted when they are supported by less than
5% of reads at a locus or by fewer than 5 reads overall. This is intended to
draw attention to calls such as a dominant M1 signal with only a few M2 reads,
where a reported heterozygote may need manual inspection as a possible
homozygote. Manual haplotype assignments remain full opacity so reviewer
decisions are visually distinct from low-support automated evidence.

The release also carries forward a larger set of MHC haplotyping improvements:
new MCM miSeq specialist presets, a generalist macaque MHC prompt evaluation
workflow, better AI haplotyping validation, Azure OpenAI endpoint support, and
additional provenance hardening for genotype and workflow operations.

## Genotype Review And Haplotype Evidence

The genotype result viewport now computes weak support for displayed haplotype
slots from the read evidence at each locus. Automated haplotype assignments are
tinted when the supporting allele evidence is below the review threshold, while
manual assignments and manual overrides restore the slot to the normal full
opacity rendering. This gives reviewers an immediate visual cue for calls that
are formally present in the result but should not be treated as equally
well-supported evidence.

The genotype evidence views were also updated to use Lungfish's semantic danger
palette consistently rather than raw system red, so weak or problematic evidence
is presented with the same application-level visual language across light and
dark appearance modes.

## MCM And Macaque MHC Haplotyping

This release adds the MCM miSeq specialist haplotyping preset and bundles the
associated reference resources, haplotype definitions, provenance, and prompt
material needed to run the workflow reproducibly. The preset work is intended
to make MiSeq-based MCM MHC review less ad hoc by giving users a packaged
reference, prompt, and workflow configuration instead of requiring manual setup.

The macaque MHC prompt work also advanced substantially. Lungfish now includes
tools and tests for extracting blinded prompt evidence, validating model output
schemas, scoring de novo haplotype calls, and iterating the generalist prompt
against in-environment examples. The scoring logic was hardened so partial
calls, duplicate labels, unresolved calls, and slot ordering do not distort
evaluation results. These changes make prompt experiments easier to compare and
reduce the chance that malformed model output is mistaken for a valid
haplotyping result.

## AI Services

AI service configuration now supports Azure-hosted OpenAI deployments, including
v1 endpoint handling and a helper script for creating Azure OpenAI deployments.
This lets teams use managed Azure OpenAI infrastructure while keeping the same
Lungfish AI provider surface used by the rest of the app.

The assistant service was also made more robust around provider resolution and
concurrent requests. Tests now cover missing API key handling and prevent
overlapping assistant requests from being processed at the same time.

## Workflow And Provenance Reliability

Several workflow and FASTQ/genotype operation paths were tightened so generated
outputs carry better command context, current-workbook update behavior, and
provenance rehydration. These changes are part of the ongoing effort to make
GUI-triggered and CLI-triggered scientific workflows produce outputs that can
be traced back to the exact tool invocation, inputs, options, and runtime
context used to create them.

## Release Quality

The release includes expanded tests for weak haplotype tinting, genotype
evidence rendering, haplotype analyzer behavior, active analysis resolution,
AI provider configuration, MCM preset loading, ONT barcode demultiplexing, and
workflow operation routing. A small number of UI tests were also stabilized so
the release gate is less sensitive to timing and layout noise.

The shipped Apple Silicon DMG was built from `main`, notarized, stapled,
published to GitHub, and added to the Sparkle alpha appcast.
