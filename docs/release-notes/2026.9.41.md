# Lungfish 2026.9.41

Channel: Preview

Previous versioned release: v2026.9.40

Stable baseline: v2026.9.28

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes problems found while the user manual was checked, step by step, against the app. Several of them affected paired sequencing reads, where each DNA fragment is read from both ends and the two reads (called mates) belong together. If you imported or processed paired reads in 2026.9.40, please read the first section.

## Paired reads stay together

- **Importing paired files without Optimize storage kept only the first file of each pair.** The second file was discarded, so the sample held half its reads. Both files are now kept. If you imported paired reads with Optimize storage turned off in 2026.9.40, import them again.
- **Most read operations split or reordered the two mates of a pair** when a sample's mates were stored together in one file, which is how LGE stores paired samples. This affected subsampling, extracting reads by motif, selecting reads by sequence, and removing duplicates, contaminants, low-complexity reads, human reads, and ribosomal RNA. Each of these now keeps or drops both mates together. Results made with these operations on paired samples in 2026.9.40 should be made again.
- **Subsample by Count** now returns exactly the number of reads you ask for.
- **The Pairing choice on the Import FASTQ sheet now takes effect.** Before, LGE ignored it and decided pairing from the file names alone. The Compression Tool choice now applies to SRA downloads too.
- **Kraken 2 now classifies a paired sample as pairs.** Before, a sample whose mates were stored in one file was classified as single reads.
- Quality score rounding, when you ask for it on import, now works even when Optimize storage is off.

## More accurate results

- **bcftools variant calling on human and other animal samples is diploid again.** Since 2026.9.40 it assumed one copy of each chromosome, which is right for viruses but hid most heterozygous variants in human data. LGE now picks the right setting from the reference, and a new **Ploidy** control in the Call Variants dialog lets you choose Haploid or Diploid yourself. On the command line this is `--ploidy`.
- **Re-rooting a tree** no longer writes extra copies of some tips. A re-rooted tree now has exactly the tips it started with, and its support values stay on the right branches.
- Trees extracted or relabelled from an unrooted tree no longer claim to be rooted.

## Things that now work

- A mapping result opens in the read viewer again when the reference also carries an imported variant track.
- Clicking a primer scheme in the sidebar shows its details in the Inspector instead of an error.
- Bracken abundance estimates work when the project folder's path contains a space.
- The Inspector clears the previous project's selection when you open another project in the same window.
- Files added to a folder that was empty now appear in the sidebar without reopening the project.
- The genotype matrix's row and hidden-cell counts fill in the Inspector.

## Clearer display

- Feature positions count from 1 everywhere in the window, matching GenBank records, the ruler and Go to Location. The annotation table's Start column used to count from 0.
- The expanded per-position quality chart fits its panel and shows every position on long reads.
- The MAFFT dialog opened from the Tools menu shows how many sequences it will align.
- The Paired End rows for mapping and EsViritu results say when paired reads were stored in one file.

## New

- The NCBI search can import a list of GenBank accessions at once, and downloaded records keep their download history.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap pins are unchanged from v2026.9.40.
