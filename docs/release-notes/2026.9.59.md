# Lungfish 2026.9.59

Channel: Preview

Previous versioned release: v2026.9.58

Stable baseline: v2026.9.54

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release refreshes the demo projects and fixes problems found while recapturing the user manual's screenshots on 2026.9.58.

## Fixes

- **Viral Recon no longer downloads a second copy of the reference.** A project that already holds MN908947.3 in Reference Sequences now uses that bundle instead of downloading another into Downloads. A bundle of NC_045512.2 is still never used in its place.
- **The Operations Panel's details drawer opens at its full height.** For a failed run in a 1200 x 650 panel, the log, Follow latest, Jump to latest, text size and Actions controls were hidden under the Clear Completed footer.
- The error text under a failed row in the Operations Panel is readable when the row is selected.
- A finished result is selected in the sidebar even when LGE rescans the project at the same moment.
- The Primer Trim sheet labels its Output Track Name field, and the field is wide enough to show the default name for the longest built-in scheme.

## Demo projects

- All ten demo projects under **Help > Demo Projects…** were rebuilt with this release's `lungfish-cli`. Their provenance records name the release build, use paths relative to the project, and hold no account name or build-machine path.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.58.
