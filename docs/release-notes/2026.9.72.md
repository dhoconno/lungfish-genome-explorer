# Lungfish 2026.9.72

Channel: Stable

Previous versioned release: v2026.9.71

Stable baseline: v2026.9.69

Dependency set: 2026.2

This release makes BLAST verification judge NVD, TaxTriage, and EsViritu results against their own taxonomy, stops TaxTriage runs from hanging at a quality-control step, tidies the TaxTriage result view, and ships the last of the user manual's retaken screenshots. It collects Preview releases 2026.9.70 and 2026.9.71.

## BLAST verification

- **BLAST Verify on an NVD contig judges hits by the contig's adjusted taxon.** A SARS-CoV-2 contig whose BLAST hits were all SARS-CoV-2 was reported as contradicting its assignment.
- **BLAST Verify on a TaxTriage or EsViritu row judges hits by the row's taxonomy.** A TaxTriage row counted an NCBI hit to its own tax ID as contradicting when the two used different names for the organism, such as Simplexvirus humanalpha1 and Human alphaherpesvirus 1. An EsViritu detection now also accepts hits named by its species.
- A verification of a single sequence reads "(1 read)" instead of "(1 reads)".

## TaxTriage

- **A TaxTriage run can no longer hang at FASTQC.** On some samples the step that draws FastQC plots never finished, and the run waited on it forever. LGE now skips that step. Its plots only fed a report LGE does not show.
- **A failed quality-control step no longer reads as lost results.** The run's message says only the MultiQC plots are missing, and a killed step is described as usually having run out of memory.
- **One Filter organisms field.** A batch result showed a second filter field above the organism table. The field in the row of sample buttons remains, and it updates the Organisms card.
- **A run from the command line into a project's Analyses folder opens as a TaxTriage result**, whatever the folder is named.
- The Inspector's Summary tab no longer says to select a result above the Operation Details of the open result, and Operation Details reads "1 ignored failure across 1 sample".
- The Building database message no longer overlaps the empty viewport's prompt, and the alignment pane under a TaxTriage or NVD table no longer shows the prompt to select a file from the sidebar.

## Variants

- **Variant columns added in recent releases stay where they belong after you change the column layout.** Variant Track, Caller Settings, and Gene / Protein moved to the far right of the Variants table after the next change in a layout saved before they existed. Checking a hidden column again now shows it straight away.

## Demo projects and documentation

- **The Pathogen Detection demo project includes contig FASTA files for its NVD results**, simulated from the SARS-CoV-2 reference, so BLAST Verify works on its NVD contigs. Download it again from Help > Demo Projects… to get them.
- The user manual's last screenshots were retaken on this release series: the Welcome window, the genotype pivot workbook, the Variants table, the TaxTriage results from a fresh run of the two corneal samples, and the NVD BLAST drawer. The TaxTriage chapter's example tables match that run.
