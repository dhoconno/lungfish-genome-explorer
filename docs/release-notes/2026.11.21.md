# Lungfish 2026.11.21

Channel: Stable

Previous versioned release: v2026.11.20

Stable baseline: v2026.11.14

Dependency set: 2026.2

This Stable release brings the work since Stable 2026.11.7 and its patch, Stable 2026.11.14. You can now count RNA-seq reads per gene in the app from a human, mouse or macaque reference set and open the results in their own viewer. It also corrects results that earlier Stable releases could make wrong without a word, such as reads that Demultiplex Barcodes put in the wrong sample, two specimens run as one sample, read pairs out of step and adapter bases left by a trim. Read What works differently before you compare with old results. A result made by an earlier version stays as it was, except an older TaxTriage result, which is counted again when it opens in a project you can edit, and many now show a warning that says what to do.

## What works differently

### RNA-seq

- **Count reads per gene in the app.** Plugin Manager > Databases > RNA-seq Reference Sets offers Human (GRCh38, GENCODE 50), Mouse (GRCm39, GENCODE M39), Rhesus macaque (Mmul_10, Ensembl 116) and Cynomolgus macaque (T2T-MFA8v1.1, RefSeq). Download fetches the genome, the annotation and a ready-made salmon index, and checks each file. It needs the RNA-Seq Analysis pack and about 6 GB of memory, and an installed set takes 10.9 to 18.6 GB of disk. Import your FASTQ files as Sequencing Read Files, then choose Tools > RNA-seq > Count Reads per Gene.
- **RNA-seq results open in their own viewer.** A bulk result shows its count tables, Quality and Correlation. A single-cell result shows its cells, quality and not-host counts, and no cell is called infected. Export Counts and Analysis Scripts writes the counts and R scripts for DESeq2, edgeR, limma voom and dream. In the Import Center, Existing Bulk RNA-seq Counts and Existing Single-cell Counts bring in salmon, count table, Cell Ranger or STARsolo results.

### TaxTriage

- **Every organism is picked for alignment.** All organisms in Advanced Settings is on by default, so TaxTriage picks every species Kraken2 finds, and each one it finds a reference genome for gets a BAM. Such a run takes longer, so turn it off to set a number up to 1,000. On the command line the default stays 10.
- **Unique Reads shows for far more organisms.** It counts only reads with a mapping quality of 5 or more, as Reads Aligned does. In one test sample, 112 of 130 organisms showed a dash and now 10 do.
- **An organism reported under another name opens its alignment,** such as Haemophilus parainfluenzae, whose reference is named Parahaemophilus parainfluenzae. Lungfish links them by their shared NCBI taxonomy ID within the sample.
- **A row that sums several strains counts on every strain,** and an older result keeps its top folder. An older result's strain rows are counted again when you open it in a project you can edit, while its report files are there.
- **Extract Reads no longer gives a sample another sample's reads** when the sample's own BAM is missing and the result lists the other sample. When a sample reads another file whose name fits it, the action bar, the Inspector and the BLAST Verify row say so.

### Samples and read pairs

- **Each FASTQ bundle runs as its own sample in TaxTriage, Classification and EsViritu.** Two bundles from two specimens named like Swab_1 and Swab_2 ran as one sample, Swab, with their organisms mixed and a negative control mark lost. To run two read files as one sample, import them together as a pair. Run such samples again.
- **Two loose read files given as a pair are checked first.** A pair whose read counts differ, or whose reads are out of order by their names, now stops with a message, in TaxTriage, Classification, EsViritu, mapping, assembly, Viral Recon sample sheets, FASTQ import and the `lungfish-cli fastq` commands that pair two files. A command line batch of Classification or EsViritu pairs R1 and R2 only within one folder. If you ran or imported such a pair, run it again.
- **Other counts.** CZ ID reports import with their true read counts, where a tab copy imported with every taxon at 0 reads. NAO-MGS Unique Reads no longer read low. Import these again.

### Demultiplex Barcodes

- **Reads no longer land in the wrong sample at a distance above 0.** With Cutadapt, a read stays in a sample only when that sample's barcode fits it better than any other's, and a tie goes to Unassigned. With a dual-index kit at Both Ends, the reads of both strands are placed. If you ran with a distance above 0, or a run left many reads in Unassigned, run it again. A sample of a large run is no longer left out, as in Stable 2026.11.14.
- **A Custom Definition of dual indexes is searched only at the read ends,** each secondary sequence is read the way your reads carry it, and a run at 5' End or 3' End stops and says why. Before, such runs could put reads with no barcode, or another row's reads, in a sample.
- **Grouped Result of two or more datasets runs every dataset,** here and in other FASTQ operations, where it ran the first one only. Run it again and delete the old result.
- **Runs that cannot be checked for chance matches stop** before they make sample files, as with the Fluidigm Access Array kit or very short barcodes, unless you choose Keep Unchecked Samples. IDT for Illumina UD Indexes is refused, so enter a Custom Definition from your index sheet.
- **A run from the Demux tab uses what the tab shows,** and a search of more than 6,000 Cutadapt lines stops before it starts, where it could run for hours.

### Trims, Viral Recon and variants

- **A trim no longer lets fastp guess its adapter from the first reads,** which could leave adapter bases on some reads. Read pairs go to fastp in a fixed random order, single reads with no adapter named use TruSeq Read 1 and five known adapters, and a recipe names its adapter. The unpaired reads of a mixed file are the exception (see Things to know). Trim the original reads again and redo any mapping or variant calling made from them.
- **Viral Recon** gets its read pairs in a fixed random order and names the Illumina adapters for single-end samples. On one real run the old order moved an allele frequency from 0.868 to 0.418. Each sample takes only its own lineage tables, and a run with another variant or consensus caller, or on Nanopore reads, shows its variants, consensus and lineage tables. Run Viral Recon again and compare.
- **iVar no longer joins two changes of one codon into one record at the lower frequency,** which could hide a change at 30%, and typed `impact=` and `gene=` filters read every key the file holds. Illumina amplicon genotyping keeps two sample IDs with one file stem, such as `S-1` and `S--1`, apart. Call, filter or genotype again.

### Quality, annotations and other results

- **Quality figures are measured.** Fluidigm reads read "No quality scores", Merge Overlapping Pairs keeps the measured scores and the pairs that did not merge, and the Inspector shows the Mean Depth samtools measured, where Est. Coverage assumed reads of 150 bp.
- **Annotations stay whole.** GFF3 and GTF import keeps every feature, a GTF transcript or CDS joins its exons, exports keep types such as misc_RNA, and extraction keeps every annotation. Import, attach or export such files again.
- **Verify with BLAST… no longer counts a read for a row by a name in another species's record,** such as Woolly monkey hepatitis B virus on a Hepatitis B virus row. Run such a check again.
- **Memory.** Extract Reads of a large Kraken 2 taxon, a large demultiplex by Read Names and steps such as Merge Into New Bundle… could fill the Mac's memory, and are fixed.
- **What you type is kept** in the FASTQ drawer when you select another dataset or quit, and a typed filter in a Kraken 2 or EsViritu result stays on.

### Views

- **Views remember where you left them,** also after you quit, on this Mac only, and View > Reset View returns a view to its start. It takes the place of View > Reset View Settings to Defaults, and nucleotide colours and track height now reset with Reset to Defaults under Sequence Style on the Inspector's View tab. The Inspector keeps each item's tab. General explanations sit behind a small i button beside the control they explain.

## What's new

- **Older results with a known fault say so,** in a band above the viewer and under Warnings on the Inspector's Provenance tab, with what to do. This covers classifier, assembly, Viral Recon, variant, trim, import and demultiplex results, among others.
- **Cell maps.** A cell map shows the cells of a single-cell result on a UMAP, t-SNE or PCA. Import Embedding… in Tools > RNA-seq reads your own tool's files, or `lungfish-cli rnaseq cell-map compute` clusters the cells with Scanpy from the optional Single-Cell Analysis pack. Colour the cells by cluster, sample, totals or one gene, then lasso cells and pseudobulk them.
- **RNA-seq on a Linux machine.** `lungfish-cli` plans STAR, STARsolo and UMI counts for a Linux machine and imports what they return. On public data these plans gave the counts of the reproduction scripts.

## Things to know

- **Older results.** No warning does not mean a result is fine. A result that `lungfish-cli` made before 29 September 2026, or a Viral Recon result of builds 1618 to about 5900, can show none.
- **RNA-seq.** The app does not compare conditions yet, so run the R scripts that Export Counts and Analysis Scripts writes. A reference set cannot yet be removed, the Databases total leaves the sets out, and the cynomolgus set counts no mitochondrial genes. Building the index on the Mac instead, with `lungfish-cli rnaseq install-reference --build-index`, still needs about 16.6 GB of memory.
- **Cell maps.** `compute` has run on one Mac only, and its number of clusters is one seed's answer, from Scanpy and not Cell Ranger.
- **TaxTriage.** An older result keeps its unlinked rows and old Unique Reads until TaxTriage runs again. On a result that lists no samples, a sample whose own BAM is missing still reads the one file whose name fits it, so check the BAM line in the Inspector.
- **Demultiplex Barcodes.** A barcode not in your pool can still pass as a sample, in about one run in 1,000 for each one and more often in amplicon files, so check samples with few reads against your sample sheet. Exact Bare Barcode checks no chance. With both distances at 0, a barcode a few bases in from a read end is out of reach, and the read can go to another sample with no warning, so set the distances to that many bases.
- **12S matching** still pairs the two files of a bundle whose read names carry no mate number by position, and the warning in the result is the only sign.
- **Trims.** A single-read library whose adapter is not TruSeq Read 1 or one of the five known adapters keeps it, and with no adapter named fastp still guesses the adapter of the unpaired reads in a file that mixes pairs and single reads, so name your adapter. For a Nextera-based library, choose VSP2 target enrichment rather than Wastewater metagenomics, and turn on Remove ribosomal RNA reads. A FASTQ import that uses Trim Galore decides for itself whether to cut poly-G tails, and a recipe you write yourself that turns fastp's poly-G option off lets fastp decide from the read names.
- **Call Variants.** The Merge AF distance field and `--ivar-merge-af-threshold` no longer decide an iVar merge, though their help says they do.
- **Viral Recon results of versions 2026.9.6 to 2026.9.52** could give a sample another sample's lineage tables. Run such a batch again.
- **Earlier notes.** The limits under Things to know in the 2026.11.7 notes still apply, such as the 0 percent columns of a Kraken 2 sample with no total and reads tied at one score in BLAST Verify. Its known issues are fixed, apart from those above. The technical record lists every limit that still holds.

## Updating

Choose Check for Updates… in the app menu to install this release. It adds no tool to install on the Mac. The RNA-seq reference sets need the RNA-Seq Analysis pack, and `rnaseq cell-map compute` needs the Single-Cell Analysis pack of about 800 MB. Both are optional and install from the Plugin Manager. If you update from a Stable release older than 2026.11.7, also read the [page of Stable 2026.11.7](https://github.com/dhoconno/lungfish-genome-explorer/releases/tag/v2026.11.7).

## Dependency versions

Dependency set 2026.2 is unchanged. Since Stable 2026.11.7 the Mac's tool lock gains salmon 2.11.0 and gffread 0.12.9 of the RNA-Seq Analysis pack, and Scanpy 1.11.5, python-igraph 1.0.0, leidenalg 0.12.0 and umap-learn 0.6.0 of the Single-Cell Analysis pack. Both packs install only on request. The Linux tool lock of the CHTC image gained the RNA-seq tools and STAR 2.7.3a, and it installs nothing on the Mac.
