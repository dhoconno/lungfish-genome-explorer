# Lungfish 2026.9.67

Channel: Preview

Previous versioned release: v2026.9.66

Stable baseline: v2026.9.65

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes problems found while taking the user manual's remaining screenshots.

## Fixes

- **Off-target screening works in a project whose folder name has a space.** varVAMP qPCR and Olivar designs screened against a reference bundle failed with a BLAST database error in a project such as Primer Design, because BLAST reads a space in the database path as the start of a second database.
- **A primer trim started from a mapping result shows the trimmed track.** After the run, the viewport briefly showed the reference bundle and then went back to the mapping result. It now stays on the bundle, and Bundle > Alignment Tracks in the Inspector lists the new track. Creating a deduplicated bundle had the same problem.
- **A workflow opened from Tools > Workflows starts with its own settings.** Its Result Name read amplicon-genotyping instead of the workflow's name, and its Project Reference ignored the reference selected in the sidebar and chose the copy inside a mapping result.
- Expanding Discriminating Sites in an alignment's Inspector no longer widens the Inspector past its column and clips its text and controls. Its Exclusions choice is now a pair of radio buttons.
- The Import Annotation Track alert is wide enough for its Reference, Track Name, and Track ID fields, which drew over its message and past its right edge.
- BLAST Verify on an NVD contig says why it cannot run when the result has no contig FASTA, instead of doing nothing.
- The action bar under an imported CZ-ID result names the import again.
- The genotype Export to Excel save panel shows its title, Export Genotype View.

## Documentation

- The 12S chapter says the Project Reference menu lists a bundle you built by its path in the project.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.66.
