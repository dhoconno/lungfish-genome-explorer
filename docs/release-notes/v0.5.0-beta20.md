# Lungfish 0.5.0-beta20

Previous release: v0.5.0-beta19

## Corrected miSeq analysis presentation

This release corrects a beta19 routing problem that could leave a completed
miSeq MHC analysis in the older Summary, Review, and Audit interface when its
input samples originated from the ONT-compatible bundle transport. Lungfish
now identifies the scientific workflow independently of the container used to
carry the reads. Completed miSeq analyses that include haplotyping therefore
open in **Haplotype Calls**, with **Genotype Matrix** available as the only
alternate analysis view.

The correction also applies to existing beta19-era results when they contain
the established miSeq assay identity and usable haplotype data. Those bundles
do not need to be rerun or rewritten: opening them in beta20 selects the
synchronized two-view presentation automatically. The exact reported
`Test_1.lungfishgenotype` result was exercised as a release regression case,
including its original legacy-shaped manifest.

Haplotype Calls and Genotype Matrix continue to use the same effective call
state. Edits made in either view appear in the other, workbook publication uses
the same included loci and current calls, and the former Review and Audit
viewport tabs are not shown. Review history, detailed evidence, annotations,
provenance, artifacts, and workbook actions remain available through the
Inspector and selected-item tools.

## Durable workflow identity and provenance

New miSeq results now record their miSeq workflow identity and haplotyping mode
in the final result manifest regardless of whether their inputs were FASTQ,
Illumina-derived bundles, or ONT-compatible sample bundles. This identity is
preserved when the app reconstructs a queued operation and is also recorded in
success and failure provenance, together with the existing command, options,
paths, checksums, runtime details, timing, and exit status.

Compatibility detection is deliberately narrow. It recognizes the known
legacy miSeq shape only when the old workflow fields are genuinely absent and
the assay and haplotype data agree. Malformed declarations and unknown future
workflow values remain visible as validation problems rather than being
silently reinterpreted.

## Notes

This remains a beta prerelease. It is distributed as a signed and notarized
Apple Silicon DMG and through the Sparkle beta update feed.
