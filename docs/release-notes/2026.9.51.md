# Lungfish 2026.9.51

Channel: Preview

Previous versioned release: v2026.9.50

Stable baseline: v2026.9.50

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## Tool updates

- Fix the micromamba checksum failure reported by **Update tools to 2026.2**. The updater now verifies the packaged bootstrap using the appropriate integrity check for the app's transformed and signed executable.
- Existing tool environments remain available. After installing this update, retry **Update tools** if an earlier attempt reported the micromamba failure.

This corrects the update operation reported in [issue #34](https://github.com/dhoconno/lungfish-genome-explorer/issues/34). Scientific data and saved analyses do not require migration.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.50. Micromamba remains pinned to 2.9.0-0 with the same upstream checksum. The lock now also records the reproducible packaged checksum used by local Debug builds.
