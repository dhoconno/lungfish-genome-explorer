# Lungfish 0.5.0-alpha31

Previous release: v0.5.0-alpha30

## Alpha Release

This alpha release fixes TaxTriage reruns on machines with dirty Nextflow
workflow caches and reduces retained TaxTriage intermediate files in project
directories. It publishes a notarized Apple Silicon DMG and updates the Sparkle
alpha appcast for testers.

## Highlights

- TaxTriage now fetches missing workflow refs into the local Nextflow cache
  without switching the dirty cached checkout, then runs from an isolated
  workflow snapshot.
- Successful TaxTriage runs now prune downloaded taxonomy and reference FASTA
  intermediates from the per-sample output directory.
- Regression coverage now exercises dirty-cache fetches and confirms downloaded
  TaxTriage staging intermediates are removed after durable outputs are
  collected.
