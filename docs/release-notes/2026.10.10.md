# Lungfish 2026.10.10

Channel: Preview

Previous versioned release: v2026.10.9

Stable baseline: v2026.9.78

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release makes projects on external drives work. Most external SSDs come formatted as ExFAT, and several analyses failed on ExFAT at the step that saves their results, after all the work was done.

## Results on ExFAT drives

ExFAT, like FAT and network (SMB) shares, does not support two ways of renaming a folder that LGE relied on. One refuses to replace an existing folder, and the other exchanges two folders in one step. On these drives the following failed, and each now works.

- Viral Recon finished but its results never appeared, with the message that the batch folder "couldn't be saved in the folder Analyses". Every analysis that saves into `Analyses` was affected in the same way.
- Primer design with Primer3 or PrimalScheme lost its results at the final save.
- Primer selection exports and primer order exports always failed.
- Running mapping again into an existing mapping result, running full-length MHC genotyping again into an existing output, and rebuilding cohort alignments all failed whenever the earlier result existed.

On these drives LGE now reserves the name first and then renames into it, or exchanges two folders with three ordinary renames. If LGE stops in the middle of such an exchange, the earlier result is kept under a hidden name and put back the next time the project opens. A run's provenance records which method saved its results.

A Viral Recon run that finished on an ExFAT drive under an earlier version kept its raw output in its `viralrecon-results-` folder, but it cannot be shown. Run it again to see it in the viewer.

## For contributors

- Every rename that must not replace a file, or that exchanges two files, now goes through one helper, `PortableRename`. A pre-push check refuses any other use of those system calls.
- `docs/contracts/EXTERNAL-VOLUMES.md` lists what differs on ExFAT, measured on a real ExFAT disk image, and which call to use.
- `scripts/testing/exfat-tests.sh` runs the tests on a scratch ExFAT disk image. With `--simulate` it runs every suite that renames as if the disk were ExFAT.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.10.9.
