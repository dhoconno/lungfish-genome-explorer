# Lungfish 2026.9.47

Channel: Preview

Previous versioned release: v2026.9.46

Stable baseline: v2026.9.28

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release keeps every nucleotide sequence in the T alphabet, and fixes primer analyses that would not open when they were designed from RNA-virus references.

## Sequences keep T, including RNA records

- **GenBank records marked as RNA, such as "genomic RNA" virus segments, are now imported with T instead of U.** Earlier releases wrote these sequences with U, and alignments and primer designs built from them carried the U forward.
- RNA remains a molecule-type label. Sequences read with U are stored and written with T, and their complement uses T. The viewer's RNA display option is unchanged.
- References downloaded with an earlier release keep their U. Download them again to store them with T, then rebuild any alignments and primer analyses that used them.

## Primer analyses from RNA references open again

- **VarVAMP and Olivar analyses designed from alignments that contain U now open.** Previously they failed to load with "Invalid binding inspection FASTA rows".
- Primer binding inspection compares U in a saved alignment as T, so mismatch counts are the same as for the equivalent DNA sequence. The alignment still shows the saved U.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap pins are unchanged from v2026.9.46.
