# Lungfish 0.5.0-beta27

Previous release: v0.5.0-beta26

This beta expands the app’s reproducible alignment workflows, makes classifier
results available in the full BAM viewer, adds installable special rRNA
classification databases, and hardens provenance across import, extraction,
publication, and database-install operations.

## Share and derive alignment results with complete evidence

The alignment viewer now uses one shared action context for mapping and
classifier evidence. From the active BAM evidence, you can extract a selected
region or selected reads, choose an appropriate project or user destination,
and publish the result as a file or reference bundle. Source FASTQs are used
when their recorded evidence is available; otherwise the extraction is staged
from the captured BAM evidence. The same context supports evidence-only
consensus generation for a whole contig or an explicitly selected interval.

Each operation validates the captured evidence both before staging and before
publication. Publication is transactional: the final payload and its sidecar
provenance are installed together, prior destinations are restored on failure,
and completed provenance refers to the final stored files rather than temporary
staging locations. Cancellation, stale-viewer state, destination selection, and
failed external-tool invocations retain durable attempt records without
claiming outputs that were never published.

## Navigate classifier BAM evidence and sample identities

Classifier results can now open their evidence BAM or CRAM files in the same
full alignment viewer used for mapping results. The viewer keeps evidence
identity, explicit index selection, filters, read groups, reference snapshots,
and detached-result lifecycle state coherent while users inspect coverage,
reads, and metadata. Mapping and classifier views also retain unmatched sample
metadata tracks and expose resolved sample identities consistently in live
tables and the inspector.

## Install special rRNA classification databases

The metagenomics database controls and `lungfish-cli db` routing now expose
special rRNA database recipes alongside existing database choices. The managed
Metagenomics pack supplies the required Kraken2 and Bracken tools, and the
installer stages archive downloads and extraction before an atomic destination
promotion. Every completed, failed, or cancelled installation writes a
provenance receipt with recipe identity, command evidence, payload checksums,
final paths, and bounded diagnostics, so an imported or GUI-launched database
remains auditable.

## Stability and release maintenance

This release strengthens cancellation and timeout handling for alignment
processes, canonicalizes failure and cancellation provenance, and improves
fixture-level checks that released scientific outputs point to their final
stored payloads. Regression coverage now exercises the shared action context,
consensus and extraction transactions, BAM and CRAM evidence validation,
classifier viewer routing, special-database installation, and the associated
provenance policies.

The app, embedded command-line tool, Help Book, and managed-tool metadata now
report `0.5.0-beta27`. This remains a signed and notarized Apple Silicon beta
DMG, published through the Sparkle beta feed with the legacy alpha bridge so
older installations can discover the update.
