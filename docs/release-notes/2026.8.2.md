# Lungfish 2026.8.2

Channel: Preview

Previous versioned release: v2026.8.1

Stable baseline: None (bootstrap aggregation baseline: v0.5.0-beta29)

Dependency set: 2026.2

Lungfish 2026.8.2 replaces the withdrawn 2026.8.1 preview with a portable,
independently verified build. It carries the same dependency-update system and
dependency set 2026.2, with corrected release packaging and stricter artifact
validation.

## Corrected preview artifact

Independent verification of the 2026.8.1 DMG found that bundled micromamba
2.9.0 retained upstream conda builder paths beginning with
`/Users/runner/miniforge3/conda-bld/`. Those paths came from the upstream binary,
not from Lungfish user data, but they violated the release portability gate.
The gate had falsely passed because its recursive search honored the
repository's ignore rules and skipped apps under `build/`.

This release:

- rewrites generic `/Users/` prefixes in vendored Mach-O tools to the
  equal-length portable prefix `/build/` before signing;
- scans hidden and gitignored files in the complete packaged app;
- rebuilds, re-signs, re-notarizes, and repackages the app from the corrected
  tagged commit; and
- supersedes the 2026.8.1 preview. Users who installed 2026.8.1 should update
  to 2026.8.2.

The 2026.8.1 git tag remains immutable as part of the release ledger, while its
defective downloadable prerelease artifact is withdrawn after this replacement
has been independently verified.

## Dependency updates and workflows

The product changes introduced on this release train remain unchanged:

- Lungfish detects required and optional dependency updates from its bundled
  manifest and presents an **Update Tools** sheet with download estimates,
  progress, cancellation, deferral rules, and resumable receipts.
- Plugin Manager can check tools and apply supported managed-database updates.
- `lungfish-cli tools update` supports plan/apply, `--json`,
  `--required-only`, optional database inclusion, and exit status 10 when work
  is available.
- `lungfish-cli conda db install-managed` and `conda db update` share the same
  manifest-backed database paths as the app.
- Fresh Apple Silicon Metagenomics installs build Bracken 3.1 from a
  checksum-pinned source archive and pinned toolchain; working source-built
  installations are preserved.
- Kraken indexing, extraction scoping, taxonomy handling, parser diagnostics,
  interrupted database swaps, offline imports, and genotype workbook Python
  resolution include the correctness and recovery fixes described in the
  2026.8.1 historical notes.

Scientific provenance records dependency set 2026.2, resolved defaults,
commands, paths, checksums, sizes, runtime identity, exit status, wall time, and
useful stderr for the new dependency and scientific workflows.

**About Lungfish** and `lungfish-cli version --tools` read the shipped manifest
dynamically. They report dependency set `2026.2 (2026-08-18)`, micromamba
`2.9.0-0`, and the current managed and source-overlay pins, including Bracken
`3.1` where applicable.

## Release verification

The corrected release remains on the preview channel: the signed app polls
`sparkle-beta/appcast-beta.xml`, the versioned GitHub release is a prerelease,
and the legacy `sparkle-alpha` bridge advertises the same signed DMG. Preview
publication uses the normal main-push Fast gate and does not manually dispatch
the heavy stable-release board.
