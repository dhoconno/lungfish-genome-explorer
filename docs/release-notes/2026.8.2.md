# Lungfish 2026.8.2

Channel: Preview

Previous versioned release: v2026.8.1

Stable baseline: None (bootstrap aggregation baseline: v0.5.0-beta29)

Dependency set: 2026.2

## Unpublished preparation tag

`v2026.8.2` records a release-preparation commit but was never published as a
GitHub release or Sparkle update. Its pre-signing portability gate stopped the
build after detecting the standard `/private/tmp` runtime-directory root
constant in Lungfish's executables. No 2026.8.2 DMG was created, signed,
notarized, uploaded, or distributed.

The gate was narrowed to allow that exact root while continuing to reject
concrete paths beneath it via the `/private/tmp/` prefix. The tested correction
and the complete dependency set 2026.2 release train ship in 2026.8.3.

## Dependency versions

The dependency identities are unchanged from 2026.8.1 and are fully enumerated
in the 2026.8.3 replacement notes. This tag contains dependency set `2026.2`,
including micromamba `2.9.0-0`, Bracken source overlay `3.1`, and Sparkle
`2.9.6`.
