# Lungfish 2026.10.1

Channel: Preview

Previous versioned release: v2026.9.78

Stable baseline: v2026.9.78

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release makes the app and `lungfish-cli` read the same reads from a FASTQ bundle, records a command that reproduces each run, keeps each window's selections and settings in that window, and fixes several assembly, demultiplexing and launch defects.

## FASTQ bundles

- **Every file of a bundle is read.** An ONT run folder imports as several files by default. Dataset operations on such a bundle read only its first file, and a subset or trim result of it could not be opened. They now read every file in import order, and results made before this release open with the reads they recorded.
- **`lungfish-cli fastq` subcommands accept a `.lungfishfastq` bundle.** They refused one, so a command copied from the Operations panel failed. A virtual bundle is materialized first, and its 1,000-read preview is never treated as its reads.
- **`map`, `conda classify`, `assemble` and `fastq materialize` read a bundle as the app does.** Each now reads every file of a multi-file or paired bundle, where some read only the first file.
- **Demultiplexing a virtual bundle uses every read.** The exact-bare engine used only the bundle's 1,000-read preview, in the app and on the command line. Barcode bundles made from a multi-file bundle now report read counts and statistics over every file.

## Assembly

- **The files of one bundle assemble in one run.** A per-bundle batch of a paired or multi-file bundle started over and over without assembling anything. Flye and hifiasm now accept a bundle named by its files.
- **SKESA reads each unpaired file as its own input.** It read two unpaired files as the two mates of one pair.
- **Reassemble uses exactly the inputs of the original run.** For an assembly of a virtual subset it also added the whole source bundle and a copy of the subset. When an original input is gone, Reassemble names it instead of assembling the rest.
- **Reassemble pairs reads as its recorded command does,** so a paired bundle assembles as pairs and an interleaved file is read as interleaved.
- Reassemble no longer freezes the app while it records the checksums of large inputs.

## Operations and recorded commands

- **Copy Command gives a command that reproduces the run.** This now holds for FASTQ dataset operations, annotation edits, primer exports, Kraken2 batches, BAM filter and annotate, genome downloads and ONT sample splits, and provenance records the same command. A setting that no `lungfish-cli` option expresses records no command rather than a wrong one.
- **ONT Fluidigm Sample Split finishes.** It failed at its last step after writing the sample bundles.
- **Viral Recon accepts a reference bundle whose annotation is `.gff3`.** It failed parameter validation 20 seconds into the run. A Viral Recon run refused because its bundle was in use no longer starts anyway.
- **TaxTriage, PBAA clustering and other Nextflow launches use the app's own Java and Nextflow,** so they no longer depend on Java being installed on the Mac.
- Find ORFs keeps reverse frames, seven commands use the global `--threads` value, Extract Overlapping Reads works on coordinate regions, `esviritu detect` accepts a bundle and records its settings, and NVD import uses the app's own samtools.

## Windows

- **Each window keeps its own selections and settings.** With two windows open, selecting an annotation or read, switching an Inspector tab, changing a display setting, a sample filter or a genotype view in one window could change the other. Dropping a file on one window's sidebar imported it once per open window.
- Opening a bundle no longer raises an Auto Layout constraint conflict in the bundle view.

## Command line

- `lungfish-cli provision-tools` is removed. It was a developer tool that nothing used.
- The `fastq` subcommands' help says the input may be a FASTQ file or a `.lungfishfastq` bundle.
- `lungfish-cli fastq demultiplex --replace` keeps the earlier results when the run is refused. A mistyped input, kit, location or engine deleted them first.

## Under the hood

The work behind this release reorganized the code so that each operation registers in the Operations panel the same way, each window event passes through one filter, and large files hold one type each. Reference outputs for mapping, Kraken2 and EsViritu classification, genotype workbooks and the full command-line help were captured before the work began and still match, so scientific results change only where this list says so.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.78.
