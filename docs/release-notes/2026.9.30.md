# Lungfish 2026.9.30

Channel: Preview

Previous versioned release: v2026.9.29

Stable baseline: v2026.9.4

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## Online search selection

Online SRA/NCBI search results now support selecting all visible results and
clearing the selection in one action. Selection state remains deterministic as
results are loaded and refreshed, and the bulk-selection controls are covered
by focused UI assertions.

The 2026.2 managed dependency set and its existing tool, pack, pipeline,
database, and bootstrap pins are unchanged.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database,
and bootstrap pins are unchanged from v2026.9.29. The optional pack remains
Primer3 2.6.1 and PrimalScheme3-LGE 3.3.0+lge.2; coverage execution uses the
explicit lge.3 contract.
