# Lungfish 0.5.0-beta11

Previous release: v0.5.0-beta10

## Highlights

This beta packages the genotype-only miSeq viewport and Inspector improvements
for short amplicon MHC workflows, including provisional exon 2 novel sequence
rows, evidence artifacts, filtering, accessibility controls, and review
annotations.

Full-length ONT MHC workflows retain their existing viewport behavior while
continuing to expose the shared evidence and annotation infrastructure.

## Notes

This remains a beta prerelease. The release is packaged as a signed and
notarized Apple Silicon DMG and published to the Sparkle beta feed for testers.
