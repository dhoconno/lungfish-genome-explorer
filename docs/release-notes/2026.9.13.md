# Lungfish 2026.9.13

Channel: Preview

Previous versioned release: v2026.9.12

Stable baseline: v2026.9.4

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

## Multiple sequence alignment viewport

Sequence names are visible again beside the alignment. In 2026.9.12 the names gutter, the corner title, the column numbering and the viewer toolbar all rendered blank, although every control still worked when clicked. The pinned comparison row and its label painted their background across the whole canvas because macOS no longer clips a view's drawing to its bounds, and that fill erased everything drawn before it. Every part of the alignment canvas now clips its own drawing, and a regression test renders the viewer through the display pipeline to confirm the names, header, corner title and comparison row all carry ink.

## Dependency versions

Dependency set 2026.2 and managed tool version pins are unchanged.
