# Lungfish 0.5.0-beta26

Previous release: v0.5.0-beta25

This release makes contextual commands in the sequence viewer consistent wherever a genomic range can be selected. Previously, a selected interval offered the complete range menu only when the contextual click happened near the translation track. The sequence overview, BAM coverage and read areas, variants, annotations, and other parts of the same viewer could instead show a shorter menu, making “Zoom to Selected Region” seem to disappear depending on where the pointer happened to be.

## Selected-range commands are available throughout the viewer

When a range is selected, contextual clicks now expose the shared range actions across sequence, alignment, read, variant, and annotation targets. The menu includes copying the visible sequence, copying it as FASTA, extracting it, centering the view at the clicked genomic position, and the precisely named “Zoom to Selected Region” command. This makes the selection itself—not the particular track under the pointer—the source of the range actions.

The shared commands are composed with the actions that belong to the clicked content. A BAM track still offers “Show BAM in Finder”; an individual mapped read retains its aligned-FASTA and original-read extraction actions; variants retain their table and genotype commands; and annotations retain their copy, extraction, navigation, inspector, editing, and deletion commands. When no range is selected, right-clicking a read, variant, annotation, or alignment track now combines those specialized actions with the general viewer controls: Select All, Center View Here, Zoom to Fit, document inspection, and per-track or global translation visibility where applicable.

The menu composition now follows one route for right-click and Control-click handling. Separator cleanup prevents leading, trailing, or doubled dividers, and shared commands are inserted exactly once even when a clicked item has its own specialized menu. Annotation and document inspector commands also use distinct labels when both are present, removing ambiguity without changing what either action opens.

## Stability and release maintenance

Regression coverage constructs real AppKit menus and verifies their titles, selectors, targets, represented payloads, ordering, and separator structure. The tests cover selected and unselected sequence backgrounds, empty and populated alignment tracks, BAM reveal payloads, mapped reads, variants, annotations, translation controls, inspector labels, and the single-instance guarantee for “Zoom to Selected Region.”

This is an interface and navigation correction only. It does not alter sequence data, alignments, annotations, scientific calculations, exports, bundle contents, or reproducibility provenance. The app, embedded command-line tool, Help Book, and managed-tool metadata report `0.5.0-beta26`. The release remains a beta prerelease distributed as a signed and notarized Apple Silicon DMG, with the same narrative delivered through the Sparkle beta feed and the legacy alpha bridge.
