## PrimalScheme recovery controls in Advanced settings

PrimalScheme can now design a separate follow-up scheme for regions left uncovered by an existing combined panel. Select the original MSAs and a saved Lungfish primer analysis or native PrimalScheme output as the parent. Lungfish verifies the parent inputs and retains a snapshot with the new analysis. The follow-up primers belong in separate PCR reactions; the original pools are preserved. The pool count is configurable.

Optional candidate expansion searches for additional primer pairs around uncovered regions. Advanced settings expose the per-MSA anchor and pair-check limits, with defaults of 2,000 anchors and 1,000 pair checks. Coverage reports distinguish the original scheme, follow-up scheme, and their combined coverage after primer trimming. The primer list and ordering sheet contain only the new follow-up primers.

A second opt-in mode attempts bounded dimer salvage within a combined panel. It retains the strict legacy design and considers additional candidates using successively more permissive dimer scores. Users can adjust the score sequence and floor, interaction budgets, minimum coverage gain, and evaluation limit. These limits are computational heuristics, not experimentally established guarantees of amplification or freedom from primer dimers.

Ordinary independent and combined PrimalScheme designs retain legacy selection by default. Recovery options require uniform position weighting and no amplicon-count caps. Follow-up design and dimer salvage are separate modes.

## What the MHC evaluation showed

On the two-MSA Mamu-A1/Mamu-A2 evaluation fixture, the original two-pool legacy scheme covered 69.69% and 70.67% of the reference sequences after primer trimming. Adding a separate two-pool follow-up scheme raised combined coverage to 74.27% and 74.33%. Enabling bounded candidate expansion raised it to 81.29% and 75.86% with the default search limits.

These are computational coverage results for this fixture, not wet-lab amplification measurements. The default bounded dimer-salvage pass added no amplicons in this evaluation. Larger searches did not consistently improve both targets, and the designs did not reach 95% coverage.

## Reproducibility and command-line inspection

Saved recovery analyses retain native reports, execution provenance, input checksums, parent evidence, and paths to the final stored artifacts. Parent reuse checks all saved input rows, including non-reference alleles, while allowing an unchanged source MSA to be renamed. CLI inspection and experimental allele-aware controls provide additional access to native diagnostics; they do not change the GUI's legacy default.

## Dependency versions

The managed PrimalScheme3-LGE runtime is updated from 3.3.0+lge.2 to 3.3.0+lge.4 to provide the recovery workflows without a development checkout. A compatible local executable can still be selected in Advanced settings. The dependency set remains 2026.2; unrelated managed tool pins are unchanged.
