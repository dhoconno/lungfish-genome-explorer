# Lungfish 2026.9.61

Channel: Preview

Previous versioned release: v2026.9.60

Stable baseline: v2026.9.60

Dependency set: 2026.2

Preview builds are under rapid iterative development. Features may be incomplete, change quickly, or require additional feedback.

This release fixes problems found while recapturing the user manual's screenshots on 2026.9.59.

## Fixes

- **Provenance exports of a mapping result are usable again.** Exporting a minimap2 result as a Nextflow, Snakemake, shell, or Python script wrote only a "Replay unavailable" stub because the run ends with an in-app step that prepares the viewer. The export now replays the tool steps and notes the in-app step as not replayed.
- **A Flye run started from the window records its profile and why it was chosen.** The Inspector's Assembly Context now shows Profile and Profile Basis rows, such as Nano Raw chosen for reads below Q10.
- Running an analysis no longer leaves an empty Downloads folder in the project.
- Opening a primer analysis no longer widens the project window.
- The Type column of the Variants table and the GT and Zygosity columns of the Genotypes table are readable on a selected row.
- The assembly sheet's Curated extra arguments section lists only options it has controls for.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap versions are unchanged from v2026.9.60.
