# Lungfish 0.5.0-beta13

Previous release: v0.5.0-beta12

## Manual haplotype editor compatibility

This hotfix restores the manual haplotype assignment editor for genotype-only
results whose annotations were written by an earlier debug build. Those bundles
could show the haplotype header and Supported Alleles evidence while silently
hiding the assignment controls when a sample column was selected.

Lungfish now recognizes that earlier internal annotation layout, while still
rejecting links to files outside the result bundle. The editor loads existing
comments, review calls, and manual haplotype assignments normally. On the next
annotation edit, Lungfish updates the bundle to the current layout and retains
the earlier stored generation for traceability.

The compatibility behavior is covered at the bundle, annotation-store, and
viewport levels, including tests that confirm untrusted links remain blocked.

## Notes

This remains a beta prerelease. The release is packaged as a signed and
notarized Apple Silicon DMG and published to the Sparkle beta feed for testers.
