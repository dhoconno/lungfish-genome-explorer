# Lungfish 0.5.0-alpha32

Previous release: v0.5.0-alpha31

## Highlights

- Shows human-friendly GitHub release versions for GitHub-backed workflows in provenance and command records.
- Defaults TaxTriage result loading to the list-over-detail layout and selects the top alignment without requiring a manual layout change.
- Adds paged/lazy TaxTriage loading and a faster first-pass MiniBAM alignment view for large classifier results.
- Compacts retained Kraken2 per-read output to `classification.kraken.gz` plus a classified-read SQLite index, while preserving gzip fallback for unclassified extraction.
- Updates Kraken2 import/build-db/BLAST paths to understand compressed Kraken2 output and keep sidecars pointed at retained artifacts.

## Notes

- This release remains a prerelease build.
- Existing raw `classification.kraken` bundles remain readable; new Kraken2 pipeline/import/build-db outputs prefer the compact retained form.
