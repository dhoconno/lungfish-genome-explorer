# Lungfish 0.5.0-alpha27

Previous release: v0.5.0-alpha26

## Summary

This alpha is a focused follow-up to the genotype review changes in alpha26. It
keeps the weak haplotype support cue, but changes how it is drawn so the
haplotype identity remains clear. Instead of blending weak automated calls with
a warning color, Lungfish now draws the same haplotype color at 50% opacity.

The release also tightens current-workbook updates for MCM haplotyping. The
editable `current.xlsx` workbook does not contain DRB haplotype-call fields, so
DRB calls are no longer passed into the workbook update path. The update path is
now limited to the workbook-supported loci: MHC-A, MHC-B, MHC-DQ, and MHC-DP.

## Genotype Review

Weak automated haplotype calls are still flagged when they are supported by
less than 5% of reads at a locus or by fewer than 5 reads overall. The visual
signal is now transparency rather than a color shift. For example, a weak M2
call remains the M2 color, but appears at half opacity so reviewers can see that
it needs manual inspection without losing the haplotype label's color language.

Manual haplotype assignments continue to render at full opacity. This keeps a
reviewer's explicit decision visually separate from an automated low-support
call.

## Current Workbook Updates

Lungfish now filters haplotype calls before updating `current.xlsx`, not only
inside the workbook writer. That means the UI snapshot, workflow-generated AI
revision payload, and embedded workbook update script all agree about which
loci can be written.

This matters because DRB evidence can still be present and useful in the
genotype output, but the current workbook has no DRB call fields to receive it.
The Outline view can continue to show DRB evidence for review, while the
workbook update path writes only loci that have a defined destination in the
spreadsheet.

## Release Quality

The release adds focused tests for the 50% opacity tint, low-read weak-call
thresholds, manual full-opacity overrides, supported-locus filtering, AI
workbook update payloads, and the workbook writer's DRB exclusion. The full
Swift test suite was run before release.

## Notes

This remains a prerelease build for alpha testers.
