# Lungfish 0.5.0-beta10

Previous release: v0.5.0-beta9

## Highlights

Full-length ONT MHC genotyping now brings known alleles, putative novel
alleles, genomic extensions, and un-nameable clusters together in one
genotyping matrix. Candidate rows preserve a stable cluster identity, are
assigned provisional names from the closest reference sequence, and can be
shown separately by support class and tint.

The full-length workflow now publishes its indexed cohort BAM/BAI evidence,
candidate GenBank records, UTR-trimmed external FASTA exports, and complete
provenance. Candidate GenBank artifacts include cDNA-relative consequence
comments, lifted-over features, translations, supporting samples, and source
project information. Structural cDNA matching now identifies genuine genomic
extensions instead of treating a partially covered cDNA hit as a finished
known call.

The Excel handoff is simplified to a unified genotype pivot plus an unmatched
alleles sheet. Both use the same display names and biological locus ordering as
the Lungfish viewport, and unmatched rows include their trimmed nucleotide
sequence and putative translation.

Selecting one or more full-length MHC genotype rows now opens an immediate,
bounded sequence viewer. It defaults to the exact GenBank record and can show
the same selected records as FASTA or EMBL. Cell-only and column-only
selections intentionally leave the detail pane empty.

The sequence viewer now expands with the detail pane in both width and height,
so resizing the horizontal divider uses the complete available reading area.

## Stability

The MHC result publication path is hardened for network and ExFAT volumes,
retains reproducibility provenance through all materialized artifacts, and
isolates malformed candidate records without hiding valid candidates. The
genotype viewport no longer builds BAM/evidence/graphics detail on selection,
avoiding the prior unbounded memory growth.

## Notes

This remains a beta prerelease. The release is packaged as a signed and
notarized Apple Silicon DMG and published to the Sparkle beta feed for testers.
