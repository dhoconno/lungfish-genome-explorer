## Compressed single-sequence references

PrimalScheme now decodes a compressed `.lungfishref` single-sequence payload before strict FASTA validation, preventing the `aligned FASTA is not UTF-8` error caused by treating gzip bytes as raw UTF-8. The consumed UTF-8 FASTA artifact continues to apply U-to-T DNA normalization and N-to-gap missing-coverage normalization. The original compressed payload is preserved without modification, and gzip decompression is recorded in the workflow provenance.

## Dependency versions

Dependency set 2026.2 and all managed tool, optional pack, pipeline, database, and bootstrap pins are unchanged from v2026.9.25.
