# Lungfish 0.5.0-alpha9

Amplicon genotyping and 12S workflow hardening, with a focus on correctness, MHC reference bundles, and a consistent results experience across workflows.

## Amplicon genotyping (MHC/KIR)

- Fixed a data-loss defect in simultaneous multi-bundle Illumina genotyping where two input bundles whose names reduced to the same sample identifier could overwrite each other's staged reads. Sample identifiers and staged files are now disambiguated, with a guard that fails clearly rather than silently merging samples.
- Added full support for genotyping against a `.lungfishmhcref` reference bundle, which pairs the genotyping FASTA with the haplotype definitions specific to that FASTA. The `fastq genotype`, `fastq ont-genotype`, and `fastq ont-barcode-genotype` commands now accept a `.lungfishmhcref`, resolve its reference and paired definitions, and reject an explicit haplotype definition that is not present in the bundle.
- Added an editable "Minimum Reads" filter to the genotype results Inspector so low-abundance calls can be hidden, with the cohort reliability flag now adjustable instead of fixed.
- Moved the genotype viewport export onto the `lungfish-cli` path so exported workbooks carry canonical provenance.

## 12S amplicon matching

- Reference bundles now record a self-describing manifest and enrich every target with taxonomy, taxon group, taxid, and alternate matches from structured metadata.
- Verified end to end on real wastewater 12S data: matched reads classify into the expected vertebrate species with correct taxonomy and taxon group, and unresolved sequences are reviewed for chimeras.

## Consistent results experience

- 12S and genotype results now share the same controls for equivalent operations: one minimum-reads threshold model, in-viewport free-text search, and a pill-row idiom for include/exclude and boolean filters.
- Reference bundle formats are unified on one manifest convention with shared validation.
- Recorded provenance commands now consistently use `lungfish-cli`.

## Workflow Manager

- 12S Amplicon Matching is now opt-in. It is disabled by default and can be enabled in the Workflow Manager by users who need it. Existing choices are preserved.

## Fixes

- Replaced blocking modal calls in the 12S results view with non-blocking sheets.
- Corrected the canonical sample metadata parser so quoted fields containing the delimiter are no longer split incorrectly.
- Updated the hello-world workflow package templates so the output name is substituted correctly.
