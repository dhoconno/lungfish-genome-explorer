# Lungfish 2026.9.50

Channel: Stable

Previous versioned release: v2026.9.49

Stable baseline: v2026.9.28

Dependency set: 2026.2

This Stable release brings together the changes since 2026.9.28: more reliable read handling, clearer operation monitoring, improved result viewers, scientific table exports, and fixes to classification, variant, and genotype results.

## Changes that may require attention

- Reimport paired files imported with **Optimize storage** off in 2026.9.40; that release could discard the second file. Recreate paired-read processing results affected by the pairing bugs described in the 2026.9.41 notes.
- Reimport interleaved files with identical mate names if an earlier release optimized their storage. Earlier optimization could separate mates. An odd trailing read is now preserved, and read counts are checked before the original file is removed.
- Saved MHC haplotype analyses are recalculated with corrected calling rules. Existing calls may change, and ambiguous definitions are marked for review.
- Older reference downloads that contain U retain their original sequence. Download them again and rebuild dependent alignments if you need the current T-normalized nucleotide storage. Protein U and imported FASTQ reads are unchanged.
- An Excel export that previously failed its ExFAT integrity check remains incomplete and should be rerun.

## Operations and result viewers

- The Operations Center shows completion, warnings, failure, and cancellation clearly. Percentages and time estimates are shown when supported by meaningful progress evidence; other work shows its activity and elapsed time.
- Each operation exposes its latest log line, a resizable log drawer, the recorded command, adjustable log text, and a **Results** button when results are available. **Reviewing log history** and **Resume live log** distinguish reading older output from stopping an operation. Native primer workflows stream their output while running.
- Assembly results regain the Inspector's **View** tab. The contig list and detail pane can be arranged left/right or stacked without losing selection or filtering. The summary and search field stay below the window toolbar.
- Mapping layouts preserve divider positions, annotation drawers remain reachable in small windows, and metadata lists remember column visibility and order. Coverage displays sample only deep regions while keeping coverage, depth, and consensus calculations based on all reads.
- Sliders accept exact typed values. Annotation zoom, quality charts, tooltips, sequence drawing, project switching, and keyboard/VoiceOver access have received fixes.

## Read processing and data integrity

- Paired and mixed-read inputs retain their intended pairing through import, storage, mapping, classification, and compatible processing operations. Import pairing choices now take effect, and quality rounding is off by default.
- Orient Reads and other compatible operations preserve FASTA or FASTQ input format. Shared conversion handling restores FASTA after tools that temporarily require FASTQ, while retaining conversion provenance.
- Alignment, genotyping, and clustering use a derived bundle's transformed or selected reads instead of returning to its original input.
- Incomplete or invalid ENA downloads are rejected before import, with recovery through the SRA Toolkit. Online search supports bulk selection and importing lists of GenBank accessions.
- Import name collisions preserve both samples. Variant-track deletion preserves alignments, annotation edits persist, failed restores retain backups, and concurrent changes to a reference are blocked. Evidence files changed during an integrity check trigger a further check before cached alignments are accepted.

## Classification, variants, and scientific export

- Kraken 2 results reopen with the original taxonomy report, separate Bracken estimates, and retained or explicitly reconstructed provenance. Paired reads run as pairs, and extracted read bundles preserve pairing.
- BLAST verification uses taxonomy-aware verdicts and fair read sampling, retains results with the analysis, and reports missing responses. TaxTriage reads its current score report, restores reopened-result actions, and distinguishes partial failure from successful completion.
- EsViritu database installation and paired-input handling are corrected. Taxonomy charts now align drawn sectors with pointer targets and label their percentage denominators clearly.
- Variant calling respects selected thresholds and reference-appropriate ploidy. Multi-track inspection retains caller identity; consequence displays, iVar fields, annotation coordinates, and overlapping feature handling are improved.
- Annotation, variant, genotype, and sample tables export selected or matching rows as XLSX, CSV, TSV, or JSON with scientific provenance. Exports preserve filtering, sorting, and numeric values, support cancellation, and publish atomically. MiSeq Excel export works on ExFAT volumes.

## Genotyping and primer-analysis tools

- MHC results use consistent per-locus percentages, separate abundance from cohort-frequency filtering, retain equivalent reference identities, and flag uncertain calls. Haplotype definitions distinguish associated alleles from the diagnostic subset; editing preserves existing thresholds until explicitly changed.
- The MCM reference-preparation utility reconciles curated workbook memberships with FASTA identities while retaining original inputs and sequences.
- MiSeq exposes deterministic haplotyping and genotyping-only modes directly. Annotated references and interleaved inputs work correctly, and reference pickers omit archived source files.
- Olivar and varVAMP join the optional PCR Primer Design pack. Saved primer analyses share a result viewer and preserve input, command, parameter, and tool-version provenance. PrimalScheme adds recovery workflows and retained diagnostics; computational coverage remains distinct from experimental validation.
- varVAMP results explain coverage limitations and surface native warnings. Saved primer analyses made from RNA references open correctly.

## Projects, storage, and documentation

- Mapping paths remain portable when projects move. Dragging items between projects copies the whole result and explains any missing external sources. Closing projects releases writer locks, and quit/cancellation handling is more reliable.
- App and CLI storage identities are consistent. Installed channels share verified download caches, and **Reclaim Duplicate Space** can reduce redundant storage.
- **Help > Demo Projects** provides eight downloadable practice projects for the manual, with checksums, source information, and accessible controls. Manual illustrations and classification walkthroughs are restored and expanded.
- Attribution and public website/documentation links have been updated, and bundled third-party notices identify the shipped versions and licenses.
- The experimental Workflow Builder and the short-lived Kraken 2 workflow-template prototype have been removed. They are not part of this Stable release; existing scientific results remain available.

No additional dependency changes are introduced by the assembly layout fix or this Stable promotion.
