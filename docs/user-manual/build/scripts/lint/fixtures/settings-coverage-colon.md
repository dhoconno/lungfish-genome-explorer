## What it is

Lungfish Genome Explorer maps reads.

## Settings

**Threads.** Sets how many processor cores the mapper uses. Default 4. Raise it on a larger Mac.

**Extra arguments:.** Passes more options to the mapper. Default empty. Rarely changed.

**Memory mapping**. Reads the database from disk as it runs. Default off. Turn it on when memory is short.
