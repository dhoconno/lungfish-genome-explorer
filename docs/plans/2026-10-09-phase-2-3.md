## Scope

1. Characterization tests for the four genotype responsibilities, the export coordinator, review eligibility, matrix projection and haplotype-band disclosure.

## Expert decisions on the open findings (2026-10-09, second round)

The owner asked the expert panel to decide each open finding and to implement the decisions in this sub-phase. The panel was two science domain experts (bioinformatics, and MHC immunogenetics for nonhuman primate typing practice), the architect, QA and the UI and UX expert. Where the science experts differed, the rule that is exact for the common case and never inflates a percent was taken.

| Id | Decision |
|---|---|
| D1 (T2) | One roster function in LungfishIO feeds the matrix columns, prevalence and the count columns in the GUI and the Excel builder alike. It holds the run's samples, then call samples, then animals named by displayed candidate and interpreted un-nameable observations, then catalog animals. An animal named only by a haplotype analysis is left out. The matrix shows every roster animal as a column, so the export no longer refuses and the Filtered sheet keeps the rows the matrix keeps. |
| D2 (N8) | Calls of one animal at one source locus that name each other as tied and carry the same reads count once in the locus total, the analyzer's sample total and the observed-loci totals. Each tied reference keeps its full reads, with no split. The Inspector names the partners a tied call shares its reads with, so a tie no longer reads as a heterozygote. |
| N1 | The haplotype analyzer ignores a genotype row with zero passed reads, because it is not an observation. The matrix keeps the zero as an attested zero for review. |
| Calling rules | D2 and N1 change the calling rules, so `GenotypeHaplotypeAnalyzer.callingRulesVersion` moves from 3 to 4, following the precedent of 08e576129. The MiSeq goldens change only in that field and the digests that cover it, recaptured deliberately. |
| D3 | Disclose. When a bundle declares candidate artifacts that fail validation, the workbook's Percent basis row, the Inspector's candidate warning and the CLI exports say that locus percents and calls count known alleles only. Counting candidate reads past failed evidence files is deferred, because the app's own storage cleanup never prunes published evidence. |
| D4 | The shared catalog mapping gains one fallback. A catalog reference row that matches nothing else names the native row whose reference record carries the same allele, keyed by the record's own allele and locus, and only when exactly one native row carries it. Otherwise the row stands alone, with no refusal. |
| D5a (SF3) | The band shows an ambiguous call's tokens, for example `M4\|M7 • M1`, and spells out No haplotype and Not assayed like the existing Too many haplotypes. The dash means only that there is no value. |
| D5b (S2) | One occurrence per animal, locus and allele. Duplicate rows collapse where calls are loaded, keeping the most-read row, with a warning. Every surface and total then uses that row. Rows are never summed. |
| D5c (S3) | Both editor reload paths run the reconcile the controller already runs, so the review capability is republished. |
| D6 (F1) | Delete the dead CSV and TSV viewport path. Excel stays the one frozen GUI export. The CLI keeps `genotype export --view-projection`, so commands recorded before 24fe49f05 still replay. |
| SF4 | The filter context records threshold values exactly, as the metadata rows do. |
| SF6 | Only a single haplotype name gets a workbook colour. Error and ambiguity tokens get none. |
| Refusal wording | A remaining GUI export refusal reads in plain words. |

## Genotype follow-up (2026-10-09, third round)

The owner asked for N9 on a copy of a real full-length genotype-only bundle and for two Inspector items. The real bundle was `Ionis_and_Charles_River.lungfishgenotype` from experiment 32355, 96 libraries of 48 cynomolgus macaques with 1,810 calls on 471 IPD-MHC accessions, extracted from the project archive into the session scratchpad and never committed. It confirmed N9. Every call read 100 percent of its locus, and the CLI export had 471 per-accession locus columns. The bundle's record store named the allele and gene of all 471 accessions.

| Id | Decision |
|---|---|
| N9 locus | The bioinformatics and immunogenetics experts agreed. When a full-length bundle loads, each call takes its source locus from its reference record, the allele name cut at `*` and read by the existing locus parser, with `feature.gene` as the fallback. A1 to A6 pool as MHC-A, AG1 to AG6 as MHC-AG, B with its pseudogenes and B11L, B16, B17 and B22 as MHC-B, and I, J, G, E, F and K stay apart. These are the keys the candidate clusters, the reviewable row catalog and the amplicon path already use, so known and candidate reads share one total for the first time. The stamp is not encoded, applies only to the full-length kind and only where it differs. A call with no record keeps its old locus with a warning, and a record whose allele and gene disagree takes the allele with a warning. |
| D4 | The record-allele fallback uses the same rule, which fixes it for I, J, G, E, F and K alleles. |
| Older edits | Matrix reviews, comments and styles saved at an old per-reference locus are read, cleared and replaced at the gene locus. Other edits saved there are counted in a warning. |
| New runs | The record store is published before the run's own haplotype analysis, so a new run never computes on per-reference loci. |
| Calling rules | Version 4 to 5. The MiSeq genotype golden and four haplotyped MiSeq GUI captures changed only in that field and the digests that cover it. |
| CSV export | Review on real data found that the per-locus export kept one allele per locus once the loci were real. A full-length result with no analysis now writes every allele in `<locus> allele N` columns. On the real bundle 1,810 cells match the 1,810 unique calls. |
| Inspector | A Review flag row beside Shares reads with, the duplicate-row warning in the Genotype Display section for every bundle type, and every result warning shown as a plain sentence with its code as help. |

Science, QA and engineering reviews ran on the first candidate. The science review found the export loss and the QA review found that a legacy review could not be cleared, and both were fixed with red tests first before the final gate. On the real bundle the CLI export went from 943 columns to 43 allele columns over six gene groups.
