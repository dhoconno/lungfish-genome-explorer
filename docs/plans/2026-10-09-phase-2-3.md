# Phase 2.3, genotype characterization, type moves and the export coordinator (2026-10-09)

Status is active. Sub-phase 2.3 of `docs/plans/2026-10-02-architecture-program.md` (lane 2g), finding R6 of `docs/reports/2026-10-02-architecture-review/REVIEW.md`. Delete this file when the program plan closes.

## Scope

1. Characterization tests for the four genotype responsibilities, the export coordinator, review eligibility, matrix projection and haplotype-band disclosure.
2. The type-per-file moves that Phase 1 skipped in LungfishGenotypeUI.
3. The export coordinator extracted from `GenotypeResultViewController`.

The owner asked for maintainability, simplicity and correct science, without engineering for far-edge cases. Phase 4a does the rest of the genotype decomposition. The program decision on GEN tags is not needed, because no lane touches the analyzer notes that still carry them.

## What the design team found

Five experts (architect, QA and QC, bioinformatics, Swift and macOS, UI and UX) read the code at `7505b9e13` before any lane started.

| Finding | Consequence for the plan |
|---|---|
| The genotype goldens drive `lungfish-cli`, which does not link LungfishGenotypeUI, and the GUI Excel export never runs the CLI | The goldens cannot see any 2.3 change. Byte identity of the GUI capture is proven by new characterization tests with committed expected files, captured on unchanged code before any move. |
| Equal frozen captures imply equal workbooks, because the export service re-derives the snapshot from its captured inputs and refuses any difference | The tests stop at the frozen capture and need no Python. |
| Every asserted string in the source-text tests lives in code that stays | No source-text assertion breaks. Three absence guards move to a module-wide reader so they keep their meaning. |
| Private helper types are coupled to their primary type | Type moves follow the Phase 1 rule with no access widening. Private types stay with their user, `#if DEBUG` spans stay. |
| The export path re-reads live controller state after the settle step, the save panel and the export task | The coordinator reads the controller through one block of forwarders, so every moved line stays byte-identical. |

## Execution

Program branch `claude/phase-2-3` in the worktree `.claude/worktrees/phase-2-3`, so a session that starts on the primary checkout cannot disturb a gate. Lanes run in their own worktrees, branched from the program branch, and run only targeted tests (`docs/contracts/VERIFICATION-ORDER.md`). Every Swift command sets `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`. Lanes never edit `docs/architecture/MODULES.md` or the ratchet baselines. After each wave the manager commits the regenerated module map and the lowered baselines, then runs the unit tier once.

Model tiers follow the program plan. Fable writes the characterization tests and the extraction. Sonnet does the pure moves and the source-text retargeting, and stops at any judgment call. The Opus design experts review each lane before it merges.

## Findings outside the 2.3 code

The tests pin current behaviour, so a later fix shows up as a reviewed change to an expected file. The owner's rulings above send SF1, SF2 and S1 to lanes in this sub-phase.

| Id | Finding | Severity |
|---|---|---|
| SF1 | Full-length ONT runs apply haplotype dropout thresholds but do not record them in the stats file. The GUI then re-infers calls with no thresholds and the CLI with sidecar defaults (50 reads, 1% of the locus), so one bundle can show three call sets. The run argv does carry the threshold flags. | High, changes calls |
| SF2 | `genotype export --export-format csv` or `tsv` ignores analyst overrides and manual assignments, while the xlsx format applies them | High, misreports calls |
| S1 | Catalog-attested zeros never reach the matrix UI in real bundles, because catalog rows are keyed by `reference:<locus>:<allele>`, so Mark False Negative stays disabled while the Excel export treats the cell as reviewable | High, review workflow |
| S2 | Duplicate occurrences of one sample, locus and genotype show the highest-read occurrence in the cell but the first one in the heatmap and the detail pane | Medium |
| S3 | Reloading the manual haplotype editor does not republish the review capability | Medium |
| SF3 | The haplotype band shows an ambiguous call as a dash, the same as no call | Medium, display only |
