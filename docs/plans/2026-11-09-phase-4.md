## How a move is proved

QA's six items (`SCR/meeting/P4-R2-QA.md:110`) hold for every move. `verify_pure_move.py` prints `PURE-MOVE OK` on each move commit, and a widening is its own commit that passes `--access-only`. The science pins the brief names pass at base and head, and nothing under `Tests/Fixtures/golden` changes. `golden.py compare` holds the CLI help capture, and a lane that crosses a target names the record pins it ran. `test_set_diff.py` shows no GONE over the wave's records. A lane that adds a target or moves a `Bundle.module` user is proved by the packaged candidate's smoke. A new file over 800 lines fails, no baseline entry is added for an extracted file, and a rename of a baselined file keeps its number through `file-size.sh --renames` (R2-SIZE, 3 to 0). If no Preview ships, the pilot gets one unpublished `package preview` and smoke before it lands.
