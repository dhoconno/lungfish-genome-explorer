## Rows moved by 3.0

Phase 3.0 moves the open rows of the older plans into this section, one source a step (row BACKLOG-MOVE). Each row has one effect sentence taken from its own words and a severity. S1 is a false number, a silently wrong result, silent data loss or a crash of the app. S2 is a common task that fails, or a failure or refusal that shows no words. S3 is a rare task that fails, or words that mislead without changing a result. S4 is appearance only. A proposed S1 or S2 carries `(proposed)` until BIO or UX rules it. Field is BIO for anything that touches a scientific number and UX for the rest, and QA or ARCH for a process, test or tooling row that no user meets, which gets S4. Source gives the plan and line the row came from, then the record the plan cites, and a record name with no folder is in `reviews/` of `~/lungfish-phase-records/phase-2-14`. A row that two sources both held is one row whose Source names every origin. Rows that 3.0 already holds or that the tables above already list are not copied.
