# Backlog

Phase now: 5

This file is the one list of open backlog rows that decide a phase, in at most 80 KB. Under Results and data it holds every open S1, S2 and probe row, a probe row being one whose rating waits on a measurement. Then come the rows with Phase 5 or Phase 6 as their target phase. Each row gives its effect on results or users.
Every other open row lives in `docs/plans/backlog-later.tsv`, one row a line with the columns id, severity, field, effect, source, phase_filed and keep, and no agent reads that file whole. `scripts/checks/backlog.py` holds the caps and the rules, and the pre-push hook runs it. The Phase now line names the phase now, and the check applies the two-phase rule from it. The command `python3 scripts/checks/backlog.py list --phase 5` prints one phase, and `close <id> <commit>` removes a closed row. A closed row is deleted in the commit that closes it, and that commit is its record.
Inside a section the rows run S1, S2, S3, S4, then not rated, and by field within each rating. A row with no rating reads `not rated`.
Every row closed at the Phase 3.4 sort stays readable at `5a0d5f3be:docs/plans/BACKLOG.md` and `5a0d5f3be:docs/plans/BACKLOG-3.2.md`.
Every row closed at the Phase 4 sort stays readable at `6b6e0c0f3:docs/plans/BACKLOG.md`, among them the rows of the Later section whose own words called them done, fixed or closed.
Every row deleted as done when this file was split stays readable at `60c7e3e07:docs/plans/BACKLOG.md`.
