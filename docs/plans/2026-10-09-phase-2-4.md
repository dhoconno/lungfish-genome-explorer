## What the design team found

Three inventories and six expert memos read the code at `81e89a306` before any lane started.

| Finding | Consequence for the plan |
|---|---|
| Provenance has 183 distinct writer code paths. The program row's 25 `writeProvenance` copies are 14 percent of them | 2.4 converges the encoder and the legacy shapes tonight and freezes every other writer under a ratchet with a named destination |
| Every envelope byte passes `ProvenanceEnvelope.encode(to:)`, and the nested `legacyWorkflowRun` is one line there | Dropping the nested run needs one encoder line, not 183 call-site edits. Exactly four goldens carry the block |
| The eight compat keys are read by `ops stats`, 16 test files, the manual and every older app version that decodes a `WorkflowRun` | The compat keys stay until the schema version 2 bump in 2.6 |
| `cancelled` lives only in the nested run, and a Kraken2 run cancelled in Bracken preparation can record exit status 0 | Run status becomes a stored envelope field before the nested run goes |
| `ProvenanceRecorder.save(options:)` replaces the options wholesale, so the Kraken2 `readSetPlan` survives only in the nested run | The save merges the run's parameters into the options before the nested run goes |
| Eleven writers still write a bare `WorkflowRun` (10 `writeSidecar` calls, the offline pack, the container archive entry) | They write `run.canonicalEnvelope()` through `ProvenanceWriter` |
| Frozen legacy bytes exist only as 22 inline literals, and the one real old-writer file is read by no test | Real legacy bytes and today's soon-retired shapes are frozen with a host-independent facts projection before any writer changes |
| Selecting an older EsViritu or TaxTriage result writes into the project through the Inspector audit's backfills | The read-path calls go, so reading a project never writes to it |
| Stderr keeps its first 10,240 characters, while tools print errors, versions and summaries last | Stderr keeps the first 2,048 and the last 8,192 characters |
