# Hello World Nextflow Workflow

This package is a minimal Lungfish workflow template.

It has three steps:

1. Record the staged `.lungfishref` and `.lungfishfastq` input bundle paths.
2. Write a tiny FASTA file.
3. Wrap that FASTA as a `.lungfishref` output bundle.

The workflow is intended as an import smoke test and as a starting point for lab-authored Nextflow packages.
