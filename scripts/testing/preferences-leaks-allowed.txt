# Test files that still build a "<prefix>-<UUID>" UserDefaults suite by hand, so a tier may leave
# ~/Library/Preferences/<prefix>-<UUID>.plist behind for them.
#
# scripts/testing/preferences-leaks.py reads this list around the tests of every Swift gate, run by
# scripts/release/gate_evidence.py (decision H1 of Phase 2.9, lane Q10). A new UUID-named plist
# fails the gate unless its prefix is listed here, no file under Tests builds that prefix by hand, or
# a test passes that prefix to TestDefaultsSuite (another checkout wrote it). The list
# only shrinks. Move a file onto TestDefaultsSuite (Tests/Support/LungfishTestSupport) and delete
# its rows in the same commit, and `preferences-leaks.py lint` fails on a row whose file no longer
# builds its prefix by hand and on a test file that calls UserDefaults(suiteName:) and has no row.
# Never add a row. The prefix (none) is a suite named by a bare UUID.
#
# The list is empty. AppIdentityTests, the last file on it, removes the plist of every fork suite it
# makes (Phase 2.11 lane Q62), so a plist named org.example.test-<UUID> now fails the gate.
#
# One row per file: <prefix> <path from the repository root>.
