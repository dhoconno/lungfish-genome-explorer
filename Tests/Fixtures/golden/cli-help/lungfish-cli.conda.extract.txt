OVERVIEW: Extract reads by taxonomy from Kraken2 classification output

Filter FASTQ reads that were classified to specific taxa by Kraken2.
Requires the per-read output file (--output from kraken2) and the
source FASTQ(s). When --include-children is set, a kreport file is
needed to build the taxonomy tree for descendant lookup.

USAGE: lungfish-cli conda extract --kraken-output <kraken-output> --source <source> ... --output <output> ... --taxid <taxid> ... [--include-children] [--kreport <kreport>] [--no-read-pairs]

OPTIONS:
  --kraken-output <kraken-output>
                          Kraken2 per-read output file (.kraken)
  --source <source>       Source FASTQ file(s). Repeat for paired-end.
  --output <output>       Output FASTQ file(s). Must match source count.
  --taxid <taxid>         Taxonomy ID(s) to extract (comma-separated or
                          repeated)
  --include-children      Include reads classified to descendant taxa
  --kreport <kreport>     Kreport file for taxonomy tree (required with
                          --include-children)
  --no-read-pairs         Extract only exact read IDs (don't pair /1 and /2
                          mates)
  --version               Show the version.
  -h, --help              Show help information.
