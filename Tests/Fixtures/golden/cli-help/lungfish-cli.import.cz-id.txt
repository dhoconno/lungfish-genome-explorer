OVERVIEW: Import hosted CZ-ID classification results into a project

USAGE: lungfish-cli import cz-id <input-path> --project <project> --sample-name <sample-name> [--metadata <metadata>] [--non-host-fastq <non-host-fastq>]

ARGUMENTS:
  <input-path>            Path to a CZ-ID taxon report TSV, ZIP archive, or
                          extracted export folder

OPTIONS:
  --project <project>     Lungfish project directory to import into
  --sample-name <sample-name>
                          Sample name for the imported .lungfishtax bundle
  --metadata <metadata>   Optional CZ-ID metadata sidecar path to record in
                          provenance
  --non-host-fastq <non-host-fastq>
                          Optional non-host FASTQ path to record in provenance
  --version               Show the version.
  -h, --help              Show help information.
