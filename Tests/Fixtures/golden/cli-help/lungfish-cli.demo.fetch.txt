OVERVIEW: Download, verify and install a demo project, then print its path

The archive is checked against the byte count and SHA-256 in the demo
project list before anything is unpacked. It is unpacked into a hidden
staging folder and moved into place only when complete, so a failed or
cancelled fetch never leaves a half-extracted project behind.

USAGE: lungfish-cli demo fetch <id> [--force] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>] [--dest <dest>]

ARGUMENTS:
  <id>                    Demo project id (see 'demo list')

OPTIONS:
  --force                 Replace an existing copy with a fresh one (the old
                          copy goes to the Trash)
  --format <format>       Output format: text, json (default: text) (values:
                          text, json; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --dest <dest>           Folder that holds installed demo projects (default:
                          ~/Documents/LGE Demo Projects)
  --version               Show the version.
  -h, --help              Show help information.
