OVERVIEW: Fetch sequence from NCBI by accession

Download sequences from NCBI GenBank/RefSeq databases.

With --bundle each accession becomes a .lungfishref bundle in --output-dir,
built as the app's NCBI browser builds a nucleotide or virus record. The one
sequence is named by the accession with its version. With --format json the
command prints CLIEvent lines on standard output and its human text on
standard error. SIGTERM stops the run, removes the bundle it was building
and exits 125. Without --bundle, --format json prints the same lines for a run
that saves its records with --save-to, and refuses to run without --save-to,
because the records would share standard output with the events. The NCBI key
comes from --api-key or from the NCBI_API_KEY environment variable.

Examples:
  lungfish-cli fetch ncbi NC_045512.2 MN908947.3 --bundle --output-dir
./bundles
  lungfish-cli fetch ncbi NC_002549 --save-to ebola.gb
  lungfish-cli fetch ncbi NC_002549 --fetch-format fasta --save-to ebola.fa
  lungfish-cli fetch ncbi MN908947.3 --fetch-format gff3 --save-to
MN908947.3.gff3
  lungfish-cli fetch ncbi MN908947 NM_000546 --save-to sequences.gb

USAGE: lungfish-cli fetch ncbi [<options>] <accessions> ...

ARGUMENTS:
  <accessions>            Accession number(s)

OPTIONS:
  --db <db>               Database: nucleotide, protein (default: nucleotide)
                          (default: nucleotide)
  --fetch-format <fetch-format>
                          Fetch format: genbank, fasta, gff3, xml (default:
                          genbank) (default: genbank)
  --save-to <save-to>     Output file path
  --api-key <api-key>     NCBI API key for higher rate limits
  --no-retry              Do not retry HTTP 429 rate-limit responses
  --bundle                Build a .lungfishref bundle for each accession
                          instead of saving one file
  --output-dir <output-dir>
                          With --bundle, the folder for the bundles (default:
                          current directory)
  --no-gff3               With --bundle, fetch no GFF3 and take the annotations
                          from the GenBank record
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
