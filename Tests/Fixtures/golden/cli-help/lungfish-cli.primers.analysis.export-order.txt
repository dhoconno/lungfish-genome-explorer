OVERVIEW: Export a primer order (workbooks, CSV and order.json) from a saved
analysis

Writes the same order the Inspector's View tab exports: order.json,
ordering.csv, primer-order.xlsx, template.xlsx and, for pooled orders,
IDT-oPools.xlsx. The default scope follows the analysis: candidate-pairs for
Primer3, selected-assays for Olivar and varVAMP, displayed for PrimalScheme.
Each scope belongs to one engine and is refused for the others rather than
falling back: displayed needs PrimalScheme's display filters, which Primer3 and
varVAMP qPCR analyses do not have, so name selected-assays, all-reported-assays
or candidate-pairs for those.

USAGE: lungfish-cli primers analysis export-order [<options>] <bundle-path> --output <output>

ARGUMENTS:
  <bundle-path>           Path to the saved .lungfishprimeranalysis bundle.

OPTIONS:
  --output <output>       New order directory. It must not exist; its parent
                          must.
  --scope <scope>         Which saved oligos to order: candidate-pairs (Primer3
                          only), selected-assays or all-reported-assays (Olivar
                          and varVAMP only), displayed (PrimalScheme only). A
                          scope the analysis engine does not have is refused
                          with the scopes it does offer. (values:
                          candidate-pairs, selected-assays,
                          all-reported-assays, displayed)
  --candidate-pair-id <candidate-pair-id>
                          Primer3 candidate pair UUID to include (repeatable;
                          default all pairs).
  --name <name>           Order name (default "<analysis name> order").
  --requested-by <requested-by>
                          Who requested the order.
  --project <project>     Project the order belongs to.
  --order-reference <order-reference>
                          Purchase or order reference.
  --notes <notes>         Free-text order notes.
  --hide-primer <hide-primer>
                          PrimalScheme view option. A primer ID to leave out of
                          the order (repeatable).
  --hide-pool <hide-pool> PrimalScheme view option. A pool ID to leave out, as
                          <result UUID>::pool::<number or none> (repeatable).
  --hide-forward          PrimalScheme view option. Leave out forward primers.
  --hide-reverse          PrimalScheme view option. Leave out reverse primers.
  --hide-amplicons        PrimalScheme view option. Record the amplicons as
                          hidden.
  --hide-identity-dots    PrimalScheme view option. Record the identity dots as
                          hidden.
  --hide-unassessed       PrimalScheme view option. With
                          --filter-compatibility, leave out primers whose MSA
                          match cannot be assessed.
  --filter-compatibility  PrimalScheme view option. Keep only the primers whose
                          MSA match is at least --min-compatibility.
  --min-compatibility <min-compatibility>
                          PrimalScheme view option. Minimum MSA match
                          percentage, 0 to 100 (default 0).
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
