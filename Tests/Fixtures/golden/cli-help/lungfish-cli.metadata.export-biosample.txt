OVERVIEW: Export folder metadata as NCBI BioSample submission TSV

Reads metadata from all .lungfishfastq bundles in a folder and outputs
an NCBI BioSample-compatible TSV file. This format can be submitted
directly to NCBI's BioSample submission portal.

Examples:
  lungfish-cli metadata export-biosample ./RunFolder
  lungfish-cli metadata export-biosample ./RunFolder > biosample.tsv
  lungfish-cli metadata export-biosample ./RunFolder --package environmental

USAGE: lungfish-cli metadata export-biosample <folder-path> [--package <package>] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <folder-path>           Path to the folder containing .lungfishfastq bundles

OPTIONS:
  --package <package>     BioSample package: clinical (default) or
                          environmental (default: clinical)
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
