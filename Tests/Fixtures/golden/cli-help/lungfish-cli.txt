OVERVIEW: Lungfish Genome Explorer CLI - Bioinformatics tools for sequence
analysis

The `lungfish-cli` command provides headless access to the Lungfish Genome
Explorer's
bioinformatics capabilities. Use it for scripting, automation, pipeline
integration, and debugging workflows.

Nextflow pipelines (Viral Recon, TaxTriage) run their tool containers
through Docker Desktop (-profile docker). Run `lungfish-cli debug container`
to check that the Docker daemon is reachable before launching one.

For more information, see: https://github.com/dhoconno/lungfish-genome-explorer

USAGE: lungfish-cli [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>] <subcommand>

OPTIONS:
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  version                 Print the Lungfish version and bundled tool reference
  convert                 Convert between sequence file formats
  analyze                 Analyze sequences and generate statistics
  translate               Translate DNA/RNA sequences to protein
  sequence                Run CLI-backed operations on reference bundle
                          sequences
  search                  Search for patterns in sequences
  universal-search        Universal search across datasets and analyses in a
                          project
  extract                 Extract subsequences or reads from genomic files
  fastq                   FASTQ read processing and quality control
  workflow                Execute and manage bioinformatics workflows
  run-headless            Run a workflow quietly without the GUI
  fetch                   Fetch sequences from remote databases
  bundle                  Manage reference genome bundles (.lungfishref)
  project                 Manage shared project locks and bundle migrations
  provision-tools         Provision the bundled micromamba bootstrap tool
  tools                   Inspect and update managed third-party tools
  conda                   Manage bioconda tool plugins via micromamba
  blast                   BLAST verification of classified reads
  esviritu                Run EsViritu viral metagenomics detection on FASTQ
                          files
  taxtriage               Run TaxTriage metagenomic classification pipeline
  align                   Create native multiple sequence alignment bundles
  msa                     Inspect and run multiple sequence alignment actions
  tree                    Infer and transform phylogenetic tree bundles
  assemble                Run de novo genome assembly with the managed assembly
                          pack
  orient                  Orient FASTQ reads relative to a reference sequence
  map                     Map sequence inputs to a reference genome with
                          minimap2, BWA-MEM2, Bowtie2, or BBMap
  import                  Import files into a Lungfish project
  import-fastq            Batch-import sequencing reads into a Lungfish project
  ops                     Inspect completed operation history and resource usage
  provenance              Inspect provenance recorded in Lungfish bundles
  bam                     Operate on bundle-owned BAM alignment tracks
  variants                Call viral variants from a bundle-owned alignment
                          track
  gatk                    Construct GATK4 commands for germline variant
                          workflows
  nao-mgs                 Import and view NAO-MGS metagenomic surveillance
                          results
  freyja                  Construct and run Freyja wastewater lineage demixing
                          plans
  nvd                     Import and view NVD classification results
  cz-id                   Import and view CZ-ID classification results
  metadata                Manage FASTQ sample metadata
  haplotypes              Manage ONT genotyping haplotype definition sets
  build-db                Build SQLite databases from classifier results
  markdup                 Mark PCR duplicates in BAM files using samtools
                          markdup
  primers                 Build and inspect primer-scheme and analysis bundles
  genotype                Inspect and annotate ONT genotype result bundles
  storage                 Inspect managed storage roots and reclaim duplicate
                          space
  demo                    List, describe and download ready-to-analyse demo
                          projects
  debug                   Debugging and troubleshooting tools

  See 'lungfish-cli help <subcommand>' for detailed help.
