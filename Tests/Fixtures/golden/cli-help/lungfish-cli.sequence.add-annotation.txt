OVERVIEW: Add one annotation to the manual annotation track of a reference
bundle.

USAGE: lungfish-cli sequence add-annotation [<options>] <bundle> --chromosome <chromosome> --start <start> --end <end> --name <name> --type <type>

ARGUMENTS:
  <bundle>                Reference bundle to update

OPTIONS:
  --chromosome <chromosome>
                          Sequence or chromosome the annotation lies on.
  --start <start>         0-based inclusive start coordinate.
  --end <end>             0-based exclusive end coordinate.
  --name <name>           Feature name.
  --type <type>           Feature type (GenBank/GFF3-style, e.g. gene, CDS).
  --strand <strand>       Strand: +, -, or . for unknown. (default: .)
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
