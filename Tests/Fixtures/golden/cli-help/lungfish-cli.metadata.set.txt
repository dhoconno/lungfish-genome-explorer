OVERVIEW: Set a metadata field on a FASTQ bundle

Sets or updates a single metadata field in a .lungfishfastq bundle's
metadata.csv file. Creates the file if it doesn't exist.

Field names use PHA4GE/NCBI BioSample conventions (snake_case).
Common fields: sample_name, sample_type, collection_date, geo_loc_name,
host, sample_role, patient_id, run_id, batch_id.

Examples:
  lungfish-cli metadata set Sample.lungfishfastq --field sample_type --value
"Blood"
  lungfish-cli metadata set Sample.lungfishfastq --field sample_role --value
negative_control
  lungfish-cli metadata set Sample.lungfishfastq --field custom_notes --value
"Re-extracted"

USAGE: lungfish-cli metadata set <bundle-path> --field <field> --value <value> [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <bundle-path>           Path to the .lungfishfastq bundle

OPTIONS:
  --field <field>         Metadata field name (e.g., sample_type,
                          collection_date)
  --value <value>         Value to set for the field
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
