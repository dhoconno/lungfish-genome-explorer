OVERVIEW: Install a tool or plugin pack from bioconda

USAGE: lungfish-cli conda install [<options>] [<packages> ...]

ARGUMENTS:
  <packages>              Package name(s) to install (e.g., 'samtools'
                          'bwa-mem2')

OPTIONS:
  -e, --env <env>         Environment name (default: package name)
  --pack                  Install a plugin pack instead of individual packages
  --offline               Install environments from an offline conda pack bundle
  --from-bundle <from-bundle>
                          Offline conda pack directory, .tar, .tgz, or .tar.gz
                          archive
  --from-lockfile <from-lockfile>
                          Unsupported exact reconstruction input; requested
                          specifications cannot be installed as resolved locks
  --conda-root <conda-root>
                          Conda root to install into when using --offline or
                          --from-lockfile (default: managed storage conda root)
  --overwrite             Replace existing environments when using --offline
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
