OVERVIEW: Import and view CZ-ID classification results

Import existing CZ-ID taxon reports (CSV or TSV) as Lungfish classification
results. This command does not run CZ-ID or send it data.

USAGE: lungfish-cli cz-id <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  import                  Import a CZ-ID taxon report (CSV or TSV) into a
                          Lungfish result directory
  summary (default)       Summarize a CZ-ID taxon report (CSV or TSV)

  See 'lungfish-cli help cz-id <subcommand>' for detailed help.
