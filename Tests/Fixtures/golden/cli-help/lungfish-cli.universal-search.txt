OVERVIEW: Universal search across datasets and analyses in a project

Queries the project-scoped universal search index for FASTQ datasets,
reference/VCF metadata, classification results, EsViritu detections,
and flattened JSON manifests.

Examples:
  lungfish-cli universal-search ./Project.lungfish --query "type:fastq_dataset
role:air_sample date>=<TIMESTAMP>"
  lungfish-cli universal-search ./Project.lungfish --query "virus:HKU1" --stats
  lungfish-cli universal-search ./Project.lungfish --query "sample:patient42"
--reindex --format json

USAGE: lungfish-cli universal-search [<options>] <project-path>

ARGUMENTS:
  <project-path>          Path to the project directory (.lungfish)

OPTIONS:
  --query <query>         Universal search query text
  --limit <limit>         Maximum number of results (default: 200) (default:
                          200)
  --reindex               Force index rebuild before querying
  --stats                 Include indexing/query timing and entity-count
                          diagnostics
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
