OVERVIEW: Translate FASTQ reads to protein FASTA

USAGE: lungfish-cli fastq translate <input> [--frame <frame>] [--table <table>] --output <output> [--force] [--compress]

ARGUMENTS:
  <input>                 Input FASTQ file or .lungfishfastq bundle

OPTIONS:
  --frame <frame>         Reading frame: 1-3 forward, 4-6 reverse (default: 1)
                          (default: 1)
  --table <table>         Genetic code table ID (default: 1) (default: 1)
  -o, --output <output>   Output file path (required)
  --force                 Overwrite existing output file
  --compress              Compress output with gzip
  --version               Show the version.
  -h, --help              Show help information.
