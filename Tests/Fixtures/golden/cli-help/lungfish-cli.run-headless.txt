OVERVIEW: Run a workflow quietly without the GUI

Thin alias for `lungfish-cli workflow run --quiet <workflow> ...`.
Use `lungfish-cli workflow run --help` for the full workflow run option set.

USAGE: lungfish-cli run-headless <workflow> [<workflow-run-arguments> ...]

ARGUMENTS:
  <workflow>              Workflow file (*.nf, Snakefile) or supported nf-core
                          workflow to pass to workflow run
  <workflow-run-arguments>
                          Additional workflow run options passed through after
                          the workflow argument

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.
