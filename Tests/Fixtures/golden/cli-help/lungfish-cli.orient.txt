OVERVIEW: Orient FASTQ reads relative to a reference sequence

Determines the strand orientation of each read relative to a
reference FASTA using vsearch. Reads on the minus strand are
reverse-complemented to match the reference orientation. Essential
for amplicon data with known primer orientation.

USAGE: lungfish-cli orient [<options>] <fastq-file> --reference <reference>

ARGUMENTS:
  <fastq-file>            Input FASTQ file

OPTIONS:
  --reference <reference> Reference FASTA file
  --word-length <word-length>
                          K-mer word length for matching (3-15, default: 12)
                          (default: 12)
  --mask <mask>           Low-complexity masking mode: dust, none (default:
                          dust) (default: dust)
  --save-unoriented       Save unoriented reads to a separate file
  --extra-args <extra-args>
                          Additional vsearch arguments passed verbatim
  -o, --output-dir <output-dir>
                          Output directory (default: current directory)
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
