OVERVIEW: Convert between sequence file formats

Convert sequences between FASTA, GenBank, GFF3, and other formats.
Format is auto-detected from input file extension or can be specified.
Input and output must be different files; in-place, symlink and hard-link
aliases are rejected.

Examples:
  lungfish-cli convert input.gb --to output.fa --to-format fasta
  lungfish-cli convert input.fasta --to output.gb --to-format genbank

USAGE: lungfish-cli convert [<options>] <input> --to <to>

ARGUMENTS:
  <input>                 Input file path

OPTIONS:
  --to-format <to-format> Output format: fasta, genbank, gff3, fastq (default:
                          fasta)
  --to <to>               Output file path (required)
  --include-annotations   Include annotations in output (if supported)
  --force                 Overwrite existing output file
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
