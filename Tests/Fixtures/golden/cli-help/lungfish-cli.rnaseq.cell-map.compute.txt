OVERVIEW: Compute a UMAP and Leiden clusters of a single-cell result as a cell
map

Runs LGE's pinned Scanpy route on the result's matrices with exact nearest
neighbours, then checks its table and writes a new cell map beside the result.
A run predicted to need more than 40% of this Mac's memory is refused before it
starts.

USAGE: lungfish-cli rnaseq cell-map compute <result-path> [--seed <seed>] --output <output> [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <result-path>           A single-cell .lungfishrnaseq result

OPTIONS:
  --seed <seed>           The seed of the PCA, the neighbours, Leiden and UMAP.
                          Only 0 is offered (default: 0)
  --output <output>       The new .lungfishrnaseq folder to write. It must not
                          exist
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
