OVERVIEW: Install conda environments from an offline pack

USAGE: lungfish-cli conda offline-install <pack-directory> [--conda-root <conda-root>] [--overwrite]

ARGUMENTS:
  <pack-directory>        Path to an offline pack directory created by 'conda
                          offline-export'

OPTIONS:
  --conda-root <conda-root>
                          Conda root to install into (default: managed storage
                          conda root)
  --overwrite             Replace existing environments with matching names
  --version               Show the version.
  -h, --help              Show help information.
