OVERVIEW: Import folder-level metadata from a CSV file

Reads a CSV file and writes it as samples.csv into the specified folder.
Also syncs metadata to per-bundle metadata.csv files for bundles whose
sample_name matches a bundle directory name.

The CSV must have a header row. The `sample_name` column is used to
match rows to .lungfishfastq bundles in the folder.

Examples:
  lungfish-cli metadata import ./RunFolder samplesheet.csv
  lungfish-cli metadata import ./RunFolder samplesheet.csv --sync-bundles

USAGE: lungfish-cli metadata import <folder-path> <csv-path> [--sync-bundles] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <folder-path>           Path to the folder containing .lungfishfastq bundles
  <csv-path>              Path to the CSV file to import

OPTIONS:
  --sync-bundles          Also write per-bundle metadata.csv files
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
