OVERVIEW: Detect and remove ribosomal RNA sequences with Deacon and BBMap
ribokmers

The global --threads option sets the thread count.

USAGE: lungfish-cli fastq deacon-ribo <inputs> ... [--retain <retain>] [--database-id <database-id>] [--absolute-threshold <absolute-threshold>] [--relative-threshold <relative-threshold>] [--pairing <pairing>] --output <output>

ARGUMENTS:
  <inputs>                Input FASTA/FASTQ file or .lungfishfastq bundle, or
                          paired R1/R2 FASTQ files

OPTIONS:
  --retain <retain>       Read classes to retain: norrna, rrna, or both
                          (default: norrna)
  --database-id <database-id>
                          Managed Deacon database ID (default: deacon-ribokmers)
  --absolute-threshold <absolute-threshold>
                          Minimum absolute minimizer hits for an rRNA match
                          (default: 1)
  --relative-threshold <relative-threshold>
                          Minimum relative minimizer-hit proportion for an rRNA
                          match (default: 0.0)
  --pairing <pairing>     How to treat the input's records: interleaved
                          (adjacent records are mates and are kept or dropped
                          together), single, or auto (values: interleaved,
                          single, auto; default: auto)
        auto reads the pairingMode recorded by the enclosing .lungfishfastq
        bundle, then inspects read names. Mates with identical names, /1 /2
        suffixes, or Casava descriptions are all recognised.
  -o, --output <output>   Output directory
  --version               Show the version.
  -h, --help              Show help information.
