OVERVIEW: Export installed conda environments for offline transfer

USAGE: lungfish-cli conda offline-export --pack <pack> --output <output> [--conda-root <conda-root>]

OPTIONS:
  --pack <pack>           Built-in tool pack ID to export
  -o, --output <output>   Directory where the offline pack directory will be
                          written
  --conda-root <conda-root>
                          Conda root to export from (default: managed storage
                          conda root)
  --version               Show the version.
  -h, --help              Show help information.
