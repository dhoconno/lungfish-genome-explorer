OVERVIEW: Record the STAR index that a run on a Linux machine built

Reads run-record.json in the result folder, which must read succeeded and name
each index file as a staged output, and writes the index record under the
storage root: the set id, the key, the tool, and each file's staging path,
bytes and SHA-256, all from the run record and none from the plan. A later plan
finds the record by set id and key. The index files stay in the staging folder
on the Linux machine, and nothing here copies one.

USAGE: lungfish-cli rnaseq index-adopt [<options>] <result-path> --set <set> --staging-folder <staging-folder> --batch <batch>

ARGUMENTS:
  <result-path>           The folder the job returned its files to, which holds
                          run-record.json

OPTIONS:
  --set <set>             The id of the reference set the index was built from,
                          or the path of its folder
  --staging-folder <staging-folder>
                          The absolute path of the staging folder on the Linux
                          machine, as the plan was written with
  --batch <batch>         The name of the plan folder, which names the batch in
                          the staging folder
  --sample <sample>       The sample name of the job (default: index) (default:
                          index)
  --storage-root <storage-root>
                          Managed storage root to write the record under
                          (default: the configured location)
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
