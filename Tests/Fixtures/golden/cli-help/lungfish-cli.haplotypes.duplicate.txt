OVERVIEW: Duplicate a project definition into the project scope

USAGE: lungfish-cli haplotypes duplicate <definition-id> [--project <project>] [--assay <assay>] [--source-scope <source-scope>] [--target-scope <target-scope>] [--new-definition-id <new-definition-id>] [--change-note <change-note>]

ARGUMENTS:
  <definition-id>         Definition set id to duplicate

OPTIONS:
  --project <project>     Project root for project-scoped definitions
  --assay <assay>         Assay/amplicon id used to disambiguate duplicate
                          definition ids
  --source-scope <source-scope>
                          project (the only supported scope)
  --target-scope <target-scope>
                          project (the only supported scope) (default: project)
  --new-definition-id <new-definition-id>
                          Optional id for the duplicate; omit to
                          override/shadow the source id
  --change-note <change-note>
                          Human-readable provenance note for this duplication
  --version               Show the version.
  -h, --help              Show help information.
