OVERVIEW: Import a standalone reference sequence file as a .lungfishref bundle

USAGE: lungfish-cli import fasta <input-file> [--output-dir <output-dir>] [--name <name>]

ARGUMENTS:
  <input-file>            Path to the input reference (.fa/.fasta/.gb/.embl,
                          optionally .gz/.bgz/.bz2/.xz/.zst)

OPTIONS:
  -o, --output-dir <output-dir>
                          Output project directory (default: current directory)
  --name <name>           Display name for the reference (default: filename)
  --version               Show the version.
  -h, --help              Show help information.
