OVERVIEW: Search FASTQ reads by ID or description field

USAGE: lungfish-cli fastq search-text <input> --output <output> [--force] --query <query> [--field <field>] [--regex] [--pairing <pairing>]

ARGUMENTS:
  <input>                 Input FASTQ file or .lungfishfastq bundle

OPTIONS:
  -o, --output <output>   Output file path (required)
  --force                 Overwrite existing output file
  --query <query>         Search query string
  --field <field>         Field to search: "id" or "description" (default: id)
  --regex                 Treat query as a regular expression
  --pairing <pairing>     How to treat the input's records: interleaved
                          (adjacent records are mates and are kept or dropped
                          together), single, or auto (values: interleaved,
                          single, auto; default: auto)
        auto reads the pairingMode recorded by the enclosing .lungfishfastq
        bundle, then inspects read names. Mates with identical names, /1 /2
        suffixes, or Casava descriptions are all recognised.
  --version               Show the version.
  -h, --help              Show help information.
