OVERVIEW: Import a haplotype definition JSON file

USAGE: lungfish-cli haplotypes import <input> [--scope <scope>] [--project <project>] [--change-note <change-note>]

ARGUMENTS:
  <input>                 Definition JSON file to import

OPTIONS:
  --scope <scope>         project (the only supported scope) (default: project)
  --project <project>     Project root for project-scoped definitions
  --change-note <change-note>
                          Human-readable provenance note for this import
  --version               Show the version.
  -h, --help              Show help information.
