OVERVIEW: Import a CSV or TSV file of sample metadata into the variant
databases of a reference bundle.

USAGE: lungfish-cli variants import-sample-metadata <bundle> <metadata-file> [--metadata-format <metadata-format>] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <bundle>                Reference bundle to edit
  <metadata-file>         CSV or TSV file of sample metadata. Its first column
                          names the sample.

OPTIONS:
  --metadata-format <metadata-format>
                          File format, csv or tsv. Taken from the file
                          extension when omitted (csv, else tsv).
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
