OVERVIEW: Scout barcode assignments before FASTQ demultiplexing

Counts the barcodes of a kit in the first reads of a file and writes a
scout-result.json file with per-barcode hit counts and suggested
accept/reject dispositions. For Illumina and Element kits it reads the
index that bcl2fastq or BCL Convert wrote in each read name and accepts
a barcode only above its chance bound. Other kits are searched in the
read bases. Ultima and MGI kits, and a file whose read names hold no
index, are refused with words that say so.

USAGE: lungfish-cli fastq scout <input> --kit <kit> --output <output> [--read-limit <read-limit>] [--accept-threshold <accept-threshold>] [--reject-threshold <reject-threshold>] [--error-rate <error-rate>] [--overlap <overlap>] [--source-platform <source-platform>] [--no-indels]

ARGUMENTS:
  <input>                 Input FASTQ file or .lungfishfastq bundle

OPTIONS:
  --kit <kit>             Barcode kit: truseq-single-a, truseq-single-b,
                          truseq-ht-dual, nextera-xt-v2, idt-ud-indexes,
                          fluidigm-access-array, pacbio-sequel-16-v3,
                          pacbio-sequel-96-v2, pacbio-sequel-384-v1,
                          m13-universal-primers, ont-nbd104, ont-nbd114,
                          ont-nbd104-114, ont-nbd114-96, ont-pbc096,
                          ont-rbk004, ont-rbk114-24, ont-rbk114-96,
                          ont-16s114-24, ont-rab204-214, or path to custom
                          CSV/TSV/text barcode definition. Custom definitions
                          can be CSV, TSV, or whitespace text with columns
                          id,sequence[,secondary_sequence][,sample_name]; a
                          header line may name the columns instead
                          (id,sequence,sample_name). Example:
                          FLD0001<TAB>GTATCGTCGT.
  -o, --output <output>   Output scout-result.json path
  --read-limit <read-limit>
                          Maximum reads to scan (default: 10000)
  --accept-threshold <accept-threshold>
                          Minimum hits to auto-accept a barcode found in the
                          read bases (a count from the read-name index is
                          accepted above its chance bound) (default: 10)
  --reject-threshold <reject-threshold>
                          Maximum hits to auto-reject a barcode found in the
                          read bases (default: 3)
  --error-rate <error-rate>
                          Override barcode matching error rate (read-base
                          search only)
  --overlap <overlap>     Override minimum barcode overlap (read-base search
                          only)
  --source-platform <source-platform>
                          Source platform: illumina, ont, pacbio, element,
                          ultima, mgi
  --no-indels             Disallow indels in barcode matching (read-base search
                          only)
  --version               Show the version.
  -h, --help              Show help information.
