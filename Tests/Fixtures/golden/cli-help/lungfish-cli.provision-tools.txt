OVERVIEW: Provision the bundled micromamba bootstrap tool

Provisions the bundled micromamba bootstrap binary used by Lungfish.

This copies the version pinned in the application resources into the
bundled tools output directory so conda-based workflows can bootstrap
their own environments consistently.

USAGE: lungfish-cli provision-tools <options>

OPTIONS:
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --arch <arch>           Target architecture (arm64, x86_64, or current)
                          (default: current)
  --force-rebuild         Force rebuild even if tools are already installed
  --list-tools            List the bundled bootstrap tool without provisioning
  --status                Check installation status of the bundled bootstrap
                          tool
  --version               Show the version.
  -h, --help              Show help information.
