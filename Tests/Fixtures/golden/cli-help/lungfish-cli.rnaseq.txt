OVERVIEW: Build RNA-seq reference sets and count RNA-seq reads

USAGE: lungfish-cli rnaseq <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  reference-set           Build a reference set from a genome, an annotation
                          and extra sequences
  index                   Build or reuse the salmon index of a reference set
  install-reference       Download a reference set, build it and build its
                          salmon index
  quant                   Count bulk RNA-seq reads in a project with salmon
  export                  Export RNA-seq counts for DESeq2, edgeR and limma
  pseudobulk              Sum a single-cell result's UMIs by sample and label
  quality                 Print the quality numbers and the sample correlation
                          of a bulk RNA-seq result
  index-plan              Write a plan folder that builds the STAR index of a
                          reference set on a Linux machine
  index-adopt             Record the STAR index that a run on a Linux machine
                          built
  solo-plan               Write a plan folder that counts 10x libraries with
                          STARsolo on a Linux machine
  cell-map                Make cell maps of a single-cell result

  See 'lungfish-cli help rnaseq <subcommand>' for detailed help.
