OVERVIEW: Download FASTQ files from SRA

USAGE: lungfish-cli fetch sra download [<options>] <accession>

ARGUMENTS:
  <accession>             SRA run accession (e.g., SRR11140748)

OPTIONS:
  --output-dir <output-dir>
                          Output directory for FASTQ files (default: .)
  --use-toolkit           Fetch with the SRA Toolkit only, with no fallback to
                          ENA (requires prefetch/fasterq-dump)
  --prefer-source <source>
                          Archive to try first (default: ena). ENA serves ready
                          FASTQ files. NCBI needs the SRA Toolkit to convert
                          its archive, which takes longer, but it can be faster
                          when ENA is slow. When the preferred source fails,
                          the other one is tried. (values: ena, ncbi)
  --bundle                Import the run into a .lungfishfastq bundle of
                          --project, as the app's SRA row does
        The run is downloaded, imported with the import settings below and
        published into <project>/Imports/ by a rename, with a provenance
        record. SIGTERM removes what the run staged and exits 125.
  -p, --project <project> Path to the .lungfish project directory the bundle
                          imports into (with --bundle)
  --platform <platform>   Sequencing platform: auto, illumina, ont, pacbio,
                          element, mgi, ultima, unknown (default: auto)
        auto infers each sample's platform from its read headers (and a BAM
        file's @RG PL) and prints the evidence. Reads whose platform cannot be
        inferred are recorded as unknown, never as Illumina. A given value is
        recorded as given, even when the reads suggest another platform.
  --pairing <pairing>     Read pairing: auto, single, paired, interleaved
                          (default: auto)
        auto and paired match R1/R2 files by name, inside one folder first.
        Mates in two folders pair only when no other listed file has either
        name. When one does, a warning names the files. They also join a run's
        file named for the run alone, such as SRR1.fastq beside SRR1_1.fastq
        and SRR1_2.fastq, to that pair as unpaired reads, by the same folder
        rule, when the first reads of the pair are named as mates, the first
        read of that file is not from their fragment, and no two adjacent reads
        among the first 1,000 of that file are mates. Otherwise the import
        skips that file and a warning says why. The import fails the sample
        when two adjacent reads later in that file are mates. For any other
        file with no mate file, they read its records and record interleaved
        mates when every record is followed by its mate, otherwise single-end.
        single imports every file as its own single-end sample, even when a
        mate is detected. interleaved imports every file on its own and records
        it as interleaved mates.
  --quality-binning <quality-binning>
                          Quality binning: fiveStep (8 quality levels),
                          illumina4 (7 quality levels), eightLevel (~21 quality
                          levels), none
        An import bins quality scores with fiveStep on every platform unless
        this option or the recipe names another value. fiveStep stores scores
        in steps of five, so every Q10, Q20 and Q30 count stays as sequenced. A
        score can move by up to 2 inside its step, and the last step stores
        every score from Q35 up as Q37. illumina4 stores called Q0 to Q10 as 8
        and Q18 and Q19 as 22, and is kept to replay older imports. Binning
        saves space and is lossy. The original scores cannot be recovered once
        the original files are removed. Pass --quality-binning none to keep
        every score as the sequencer gave it.
  --compression <compression>
                          Compression level: fast, balanced, maximum (default:
                          balanced)
  --recipe <recipe>       Processing recipe: illumina-amplicon-merge,
                          illumina-paired-cleanup, vsp2-target-enrichment,
                          wastewater-metagenomics, vsp2, wgs, hifi, or none
                          (default: none)
        illumina-amplicon-merge: Illumina Amplicon Merge
        illumina-paired-cleanup: Illumina paired-end cleanup (Remove duplicate
        reads on, Remove ribosomal RNA reads off)
        vsp2-target-enrichment: VSP2 target enrichment, a preset of
        illumina-paired-cleanup (Remove duplicate reads on, Remove ribosomal
        RNA reads off)
        wastewater-metagenomics: Wastewater metagenomics, a preset of
        illumina-paired-cleanup (Remove duplicate reads on, Remove ribosomal
        RNA reads on)
        vsp2: alias of vsp2-target-enrichment
        wgs: the built-in Illumina whole-genome recipe
        hifi: the built-in PacBio HiFi recipe
  --remove-duplicates/--no-remove-duplicates
                          Remove duplicate reads. Replaces the recipe's setting.
  --remove-ribosomal-rna/--no-remove-ribosomal-rna
                          Remove ribosomal RNA reads. Replaces the recipe's
                          setting.
        Removal is final for a stored import. Only a reimport from the raw
        files brings the removed reads back.
  --no-optimize-storage   Skip read reordering for storage optimization
  --clumping-tool <clumping-tool>
                          Storage optimization tool: auto, bbtools,
                          trim-galore, none (default: platform-specific)
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
