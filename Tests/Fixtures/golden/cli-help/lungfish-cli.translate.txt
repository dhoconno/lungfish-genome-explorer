OVERVIEW: Translate DNA/RNA sequences to protein

Translate nucleotide sequences from a FASTA file into protein sequences
using the standard or alternative genetic codes.

Reading frames 1-3 are forward strand, 4-6 are reverse complement
(frames -1, -2, -3). By default, all 6 frames are translated.

Examples:
  lungfish-cli translate input.fasta
  lungfish-cli translate input.fasta --frame 1
  lungfish-cli translate input.fasta --frame 1 --table 2 -o proteins.fasta
  lungfish-cli translate input.fasta --all-frames --stop-as-asterisk

USAGE: lungfish-cli translate [<options>] <input>

ARGUMENTS:
  <input>                 Input file (FASTA format)

OPTIONS:
  -f, --frame <frame>     Reading frame: 1-3 (forward), 4-6 (reverse). Default:
                          all 6 frames
  --table <table>         Genetic code table ID (1=standard, 2=vertebrate mito,
                          3=yeast mito, 11=bacterial) (default: 1)
  -o, --output <output>   Output file path (default: stdout)
  --trim-to-stop          Stop translation at the first stop codon
  --no-stop-asterisk      Omit stop codon asterisks from output
  --longest-orf           Output only the longest open reading frame per
                          sequence per frame
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
