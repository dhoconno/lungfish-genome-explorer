OVERVIEW: Create a consensus sequence from a .lungfishmsa bundle

USAGE: lungfish-cli msa consensus [<options>] <bundle-path> --output <output>

ARGUMENTS:
  <bundle-path>           Input .lungfishmsa bundle

OPTIONS:
  --output-kind <output-kind>
                          Output kind: fasta or reference (default: fasta)
  --output <output>       Output FASTA path or .lungfishref bundle path
  --name <name>           Consensus FASTA record name
  --rows <rows>           Optional comma-separated row IDs or display names
  --threshold <threshold> Minimum non-gap residue fraction required for a
                          consensus base (default: 0.6)
  --gap-policy <gap-policy>
                          Gap policy: omit or include (default: omit)
  --force                 Overwrite an existing output file
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
