OVERVIEW: Build a reference set from a genome, an annotation and extra
sequences

Lungfish copies each file into the set, checks its sha256, writes the
transcript FASTA with gffread and
the gene and transcript tables, and names the set by its content. A set of the
same content is reused.
An extra is "<kind>,<name>,<fasta>[,<annotation>]", where kind is virus,
bacterium or spike-in. The
annotation of an extra needs --layout deposit.

USAGE: lungfish-cli rnaseq reference-set [<options>] --genome <genome> --annotation <annotation>

OPTIONS:
  --genome <genome>       Genome FASTA, plain or gzip, or a .lungfishref
                          reference bundle
  --annotation <annotation>
                          GTF annotation of the genome, plain or gzip
  --default <default>     A named default set whose checksums the files must
                          equal, such as rhesus/ensembl-100
  --name <name>           Display name of the set
  --species <species>     Species, such as "Macaca mulatta"
  --assembly <assembly>   Assembly name, such as Mmul_10
  --assembly-accession <assembly-accession>
                          Assembly accession
  --annotation-source <annotation-source>
                          Annotation source, such as Ensembl or RefSeq
  --annotation-release <annotation-release>
                          Annotation release, such as 100
  --extra <extra>         An extra sequence as
                          <kind>,<name>,<fasta>[,<annotation>], in the order
                          given
  --layout <layout>       lge (the default) or deposit (default: lge)
  --study <study>         The study whose deposit the deposit layout reproduces
  --mitochondrial-contig <mitochondrial-contig>
                          A mitochondrial contig, when the files do not name it
  --assembly-report <assembly-report>
                          NCBI assembly report that types the mitochondrion
  --storage-root <storage-root>
                          Managed storage root (default: the configured
                          location)
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
