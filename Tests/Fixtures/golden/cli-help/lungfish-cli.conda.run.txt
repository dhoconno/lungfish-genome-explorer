OVERVIEW: Run a tool from a conda environment

USAGE: lungfish-cli conda run [--env <env>] <tool-and-args> ...

ARGUMENTS:
  <tool-and-args>         Tool name followed by its arguments

OPTIONS:
  -e, --env <env>         Environment name (default: tool name)
  --version               Show the version.
  -h, --help              Show help information.
