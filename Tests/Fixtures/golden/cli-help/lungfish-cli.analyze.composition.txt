OVERVIEW: Calculate detailed nucleotide/amino acid composition

Calculate detailed composition statistics including:
- Per-base/residue counts and percentages
- Purine/pyrimidine ratios (nucleotides)
- GC/AT skew (nucleotides)
- Codon usage table (nucleotides, --codons)
- Dinucleotide frequencies (nucleotides, --dinucleotides)

Positional counts reset at every record boundary. Codons use frame +1
of each record; incomplete terminal codons and windows containing
ambiguous symbols are excluded from frequency denominators.

Examples:
  lungfish-cli analyze composition genome.fasta
  lungfish-cli analyze composition coding.fasta --codons
  lungfish-cli analyze composition genome.fasta --dinucleotides
  lungfish-cli analyze composition protein.faa --alphabet protein

USAGE: lungfish-cli analyze composition [<options>] <input>

ARGUMENTS:
  <input>                 Input file path

OPTIONS:
  --codons                Show codon usage table (nucleotide sequences only)
  --dinucleotides         Show dinucleotide frequencies (nucleotide sequences
                          only)
  --alphabet <alphabet>   Sequence alphabet: dna, rna, protein (default:
                          auto-detect from file extension)
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
