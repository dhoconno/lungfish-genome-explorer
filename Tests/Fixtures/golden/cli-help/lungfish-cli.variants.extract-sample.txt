OVERVIEW: Extract one sample's variant calls from a bundle variant database

USAGE: lungfish-cli variants extract-sample <bundle-path> --sample <sample> --output <output>

ARGUMENTS:
  <bundle-path>           Path to a .lungfishref bundle with a variant database

OPTIONS:
  --sample <sample>       Sample name to extract
  -o, --output <output>   Output VCF path
  --version               Show the version.
  -h, --help              Show help information.
