OVERVIEW: Download genomes from NCBI and create indexed bundles

Downloads each genome from NCBI, with its FASTA sequence and GFF3
annotations, and builds one .lungfishref bundle for each accession.

Assembly accessions (GCF_/GCA_) are resolved through the assembly
database and built as the app's genome download builds them, in a
bundle named '<organism> - <assembly name>'. Any other accession is
fetched from nucleotide as its FASTA and GFF3, which is the exact
record requested, in a bundle named by the accession with its
version, the name of its sequence. --name names the bundle of one
accession instead.

A bundle is built in a scratch folder, the project's .tmp folder
inside a project, and then moved into --output-dir. A bundle never
replaces another. The next free name adds _1, _2 and so on. An
assembly bundle holds a provenance record that names every file
fetched with its digest and size.

--into-bundle adds the genome and annotations of one accession to an
existing .lungfishref bundle, such as a bundle imported from a VCF
with no reference, and keeps its variants and tracks.

With --format json the command prints CLIEvent lines on standard
output and its human text on standard error, and its complete event
names each bundle. SIGTERM stops the run, removes the bundle it was
building and exits 125. The NCBI key comes from --api-key or from
the NCBI_API_KEY environment variable.

The bundle contains:
- Compressed, indexed FASTA (bgzip + samtools faidx)
- SQLite annotation database (converted from GFF3)
- Manifest with metadata

Examples:
  lungfish-cli fetch genome GCF_003047895.1 --output-dir ./genomes
  lungfish-cli fetch genome GCF_003047895.1 GCF_000001405.40 --output-dir
./genomes
  lungfish-cli fetch genome MN908947.3 --output-dir ./genomes
  lungfish-cli fetch genome GCF_000001405.40 --name "Human GRCh38" --output-dir
./
  lungfish-cli fetch genome GCF_003047895.1 --fasta-only --output-dir ./
  lungfish-cli fetch genome NC_045512.2 --into-bundle ./variants.lungfishref

USAGE: lungfish-cli fetch genome [<options>] <accessions> ...

ARGUMENTS:
  <accessions>            Assembly (GCF_003047895.1) or nucleotide (MN908947.3)
                          accessions, one bundle each

OPTIONS:
  --output-dir <output-dir>
                          Output directory for the bundles (default: current
                          directory) (default: .)
  --name <name>           Bundle name for one accession (default: derived from
                          the assembly or record)
  --into-bundle <into-bundle>
                          Add the genome and annotations of one accession to
                          this existing .lungfishref bundle
  --fasta-only            Download only the FASTA sequence (no annotations, no
                          bundle)
  --no-bundle             Download files but don't create a .lungfishref bundle
  --api-key <api-key>     NCBI API key for higher rate limits (default: the
                          NCBI_API_KEY environment variable)
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
