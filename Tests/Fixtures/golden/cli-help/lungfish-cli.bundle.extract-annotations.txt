OVERVIEW: Extract annotation feature sequences into a new .lungfishref bundle

USAGE: lungfish-cli bundle extract-annotations --bundle <bundle> --track <track> --output-bundle <output-bundle> [--feature-type <feature-type>] [--name-prefix <name-prefix>] [--replace]

OPTIONS:
  --bundle <bundle>       Source .lungfishref bundle containing sequence and
                          annotations
  --track <track>         Annotation track id or name to extract from
  --output-bundle <output-bundle>
                          Output .lungfishref bundle path
  --feature-type <feature-type>
                          Feature type to extract (default: gene)
  --name-prefix <name-prefix>
                          Only extract features whose name or gene name starts
                          with this prefix
  --replace               Replace an existing output bundle
  --version               Show the version.
  -h, --help              Show help information.
