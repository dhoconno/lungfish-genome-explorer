OVERVIEW: Extract annotation feature sequences into a new .lungfishref bundle

USAGE: lungfish-cli bundle extract-annotations [<options>] --bundle <bundle> --track <track> --output-bundle <output-bundle>

OPTIONS:
  --bundle <bundle>       Source .lungfishref bundle containing sequence and
                          annotations
  --track <track>         Annotation track id or name to extract from
  --output-bundle <output-bundle>
                          Output .lungfishref bundle path
  --feature-type <feature-type>
                          Feature type to extract (default: gene) (default:
                          gene)
  --name-prefix <name-prefix>
                          Only extract features whose name or gene name starts
                          with this prefix
  --replace               Replace an existing output bundle
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
