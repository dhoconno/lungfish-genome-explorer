OVERVIEW: Import an external application export into native Lungfish project
collections

Kinds: clc-workbench, dnastar-lasergene, benchling-bulk,
sequence-design-library, alignment-tree, sequencing-platform-run-folder,
phylogenetics-result-set, qiime2-archive, igv-session-track-set

USAGE: lungfish-cli import application-export [<options>] <kind> <source-path> --project <project>

ARGUMENTS:
  <kind>                  Application export kind
  <source-path>           Path to an application export archive, folder, or file

OPTIONS:
  --project <project>     Lungfish project directory to import into
  --collection-name <collection-name>
                          Optional collection base name
  --no-preserve-raw-source
                          Do not copy the original export into the collection
  --no-import-references  Preserve standalone references instead of converting
                          them to .lungfishref bundles
  --no-preserve-unsupported
                          Skip unsupported artifacts instead of preserving them
                          as binary files
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
