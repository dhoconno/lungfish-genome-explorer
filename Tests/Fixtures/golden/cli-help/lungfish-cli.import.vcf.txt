OVERVIEW: Import a VCF variant file

USAGE: lungfish-cli import vcf [<options>] <input-file>

ARGUMENTS:
  <input-file>            Path to the VCF or VCF.GZ file

OPTIONS:
  -o, --output-dir <output-dir>
                          Output project directory, or an existing .lungfishref
                          bundle to attach the variants to (default: current
                          directory)
  --name <name>           Display name for the variant track when attaching to
                          a .lungfishref bundle (default: filename)
  --import-profile <import-profile>
                          Variant database import profile when attaching to a
                          .lungfishref bundle: auto, low-memory, fast,
                          ultra-low-memory (default: auto) (values: auto,
                          low-memory, fast, ultra-low-memory)
  --replace <replace>     Replace the existing variant track with this id
                          instead of adding a new track.
        Without --replace, a VCF whose file name matches an existing track is
        added under a new id (calls, calls-2, calls-3, ...); nothing is
        overwritten. Use `bundle list <bundle> --tracks` to see track ids.
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
