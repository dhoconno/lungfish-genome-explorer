OVERVIEW: Find open reading frames and add them as a new annotation track

USAGE: lungfish-cli sequence annotate-orfs [<options>] <bundle>

ARGUMENTS:
  <bundle>                Reference bundle to update

OPTIONS:
  --sequence <sequence>   Sequence/chromosome name. Defaults to the first
                          sequence in the bundle.
  --start <start>         0-based inclusive start coordinate. Defaults to 0.
  --end <end>             0-based exclusive end coordinate. Defaults to the
                          sequence length.
  --frames <frames>       Comma-separated reading frames, e.g.
                          +1,+2,+3,-1,-2,-3. (default: +1,+2,+3,-1,-2,-3)
  --table <table>         NCBI genetic code table ID. (default: 1)
  --min-length <min-length>
                          Minimum ORF length in nucleotides. (default: 100)
  --include-partial       Include ORFs that run off the selected range.
  --allow-alternative-starts
                          Allow alternative starts for the selected genetic
                          code.
  --track-id <track-id>   Annotation track ID. Defaults to a workflow-provided
                          ID.
  --track-name <track-name>
                          Annotation track display name.
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
