OVERVIEW: Import Kraken2 classification results

USAGE: lungfish-cli import kraken2 <kreport-file> [--output <output>] [--name <name>] [--output-dir <output-dir>]

ARGUMENTS:
  <kreport-file>          Path to the Kraken2 kreport file

OPTIONS:
  --output <output>       Path to the Kraken2 per-read output file
  --name <name>           Optional imported result name (used in output
                          directory)
  -o, --output-dir <output-dir>
                          Output project directory (default: current directory)
  --version               Show the version.
  -h, --help              Show help information.
