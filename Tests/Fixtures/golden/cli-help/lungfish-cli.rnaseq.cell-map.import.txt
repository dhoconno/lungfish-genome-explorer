OVERVIEW: Import a single-cell result's embeddings and cell labels as a cell
map

Reads LGE's table or 10x's projection.csv and clusters.csv, matches each
barcode to a cell of the result as given, and writes a new cell map beside the
result. Cells with no coordinates are counted, and the given files are kept.

USAGE: lungfish-cli rnaseq cell-map import [<options>] <result-path> --output <output>

ARGUMENTS:
  <result-path>           A single-cell .lungfishrnaseq result

OPTIONS:
  --coordinates <coordinates>
                          LGE's table or one of 10x's projection.csv files.
                          Repeat for more
  --clusters <clusters>   One of 10x's clusters.csv files. Repeat for more
  --label-column <label-column>
                          A column of LGE's table that holds labels. Repeat for
                          more
  --method <method>       The method of one embedding, as <embedding>=<name>,
                          such as umap=UMAP. Repeat for more
  --barcode-suffix <barcode-suffix>
                          Drop -1 from each given barcode that ends in it, or
                          add -1 to each, before matching (values: drop, add)
  --skip-barcodes-not-held
                          Leave out the given barcodes that the result does not
                          hold, and count them
  --other-counts          The embedding was computed on counts other than the
                          result's
  --tool <tool>           The tool that made the files, as you state it
  --tool-version <tool-version>
                          The version of that tool, as you state it
  --output <output>       The new .lungfishrnaseq folder to write. It must not
                          exist
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
