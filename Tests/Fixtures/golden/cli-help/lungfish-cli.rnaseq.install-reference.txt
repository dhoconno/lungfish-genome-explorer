OVERVIEW: Download a reference set, build it and build its salmon index

Lungfish checks that this Mac has the memory and free disk the salmon index
needs, downloads the set's genome and GTF into the storage folder, checks each
file's sha256 against the named set, builds the set as rnaseq reference-set
--default does and builds its index at k 31 with the genome as decoys, as
rnaseq index does. When the set has a served index for this Mac's salmon,
Lungfish downloads that index and checks its sha256 instead of building it,
which needs only the memory of a count. --build-index builds it here instead.
The downloads are kept, and a second run downloads and builds nothing. The sets
are human/gencode-50, mouse/gencode-M39, rhesus/ensembl-116 and
cynomolgus/refseq-GCF_037993035.2.

USAGE: lungfish-cli rnaseq install-reference --default <default> [--storage-root <storage-root>] [--build-index] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

OPTIONS:
  --default <default>     The named set to install: human/gencode-50,
                          mouse/gencode-M39, rhesus/ensembl-116 or
                          cynomolgus/refseq-GCF_037993035.2
  --storage-root <storage-root>
                          Managed storage root (default: the configured
                          location)
  --build-index           Build the salmon index on this Mac even when a served
                          one matches
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
