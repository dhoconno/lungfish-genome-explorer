OVERVIEW: Add an annotation from aligned MSA columns

USAGE: lungfish-cli msa annotate add [<options>] <bundle-path> --row <row> --columns <columns> --name <name> --type <type>

ARGUMENTS:
  <bundle-path>           Input .lungfishmsa bundle to update

OPTIONS:
  --row <row>             Row ID, display name, or source name
  --columns <columns>     1-based aligned column ranges, e.g. 10-40,55
  --name <name>           Annotation name
  --type <type>           Annotation type, e.g. gene, CDS, motif
  --strand <strand>       Annotation strand: +, -, or . (default: .)
  --note <note>           Optional annotation note
  --qualifier <qualifier> Repeatable key=value qualifier
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
