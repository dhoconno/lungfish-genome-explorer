OVERVIEW: Remove a derived alignment track and its files from a bundle

Removes a track that bam filter derived, with its BAM, index, statistics
database and their records. A source alignment cannot be removed. The record of
the removal names each removed file with its digest and is written to
provenance/removals/<track>.lungfish-provenance.json in the bundle before any
file goes.

USAGE: lungfish-cli bam remove-track --bundle <bundle> --track <track> [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

OPTIONS:
  --bundle <bundle>       Path to the reference bundle (.lungfishref)
  --track <track>         ID of the derived alignment track to remove
  --format <format>       Output format (values: text, json; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
