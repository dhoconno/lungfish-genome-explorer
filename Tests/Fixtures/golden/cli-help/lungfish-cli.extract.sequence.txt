OVERVIEW: Extract subsequences from FASTA files

Extract a subsequence from a FASTA file by specifying a region in the
format chr:start-end (1-based, inclusive coordinates, matching samtools
faidx convention). Output is in FASTA format.

When the input contains multiple sequences, specify the sequence name
as the chromosome. If omitted and the file contains a single sequence,
that sequence is used.

Examples:
  lungfish-cli extract sequence genome.fasta chr1:1000-2000
  lungfish-cli extract sequence genome.fasta chr1:1000-2000
--reverse-complement
  lungfish-cli extract sequence genome.fasta chr1:1-500 --flank 100
  lungfish-cli extract sequence genome.fasta seq1:1-100 -o region.fasta

USAGE: lungfish-cli extract sequence [<options>] <input> <region>

ARGUMENTS:
  <input>                 Input file (FASTA format)
  <region>                Region to extract (format: name:start-end, 1-based
                          inclusive)

OPTIONS:
  --reverse-complement    Reverse complement the extracted sequence
  --flank <flank>         Add N bases of flanking sequence on each side
                          (default: 0)
  --flank-5 <flank-5>     Add N bases of 5' (upstream) flanking sequence
  --flank-3 <flank-3>     Add N bases of 3' (downstream) flanking sequence
  -o, --output <output>   Output file path (default: stdout)
  --line-width <line-width>
                          FASTA line width (default: 70) (default: 70)
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
