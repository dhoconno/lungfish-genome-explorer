OVERVIEW: Extract subsequences from FASTA files

Extract a subsequence from a FASTA file by specifying a region in the
format chr:start-end (1-based, inclusive coordinates, matching samtools
faidx convention). Output is in FASTA format.

When the input contains multiple sequences, specify the sequence name
as the chromosome. If omitted and the file contains a single sequence,
that sequence is used.

With --bundle the input is a .lungfishref bundle, and -o names the new
.lungfishref, which keeps the annotation and variant tracks in the region.
Without --bundle, -o <name>.lungfishref builds a bundle of the FASTA's region
or feature, and --source-document names the file the FASTA was written from.
A GenBank document's annotations are not carried, and the record says so.

With --format json, standard output holds event lines: one start line,
progress lines with --bundle, and one complete or failed line. The text
goes to standard error, and -o is required.

Examples:
  lungfish-cli extract sequence genome.fasta chr1:1000-2000
  lungfish-cli extract sequence genome.fasta chr1:1000-2000
--reverse-complement
  lungfish-cli extract sequence genome.fasta chr1:1-500 --flank 100
  lungfish-cli extract sequence genome.fasta seq1:1-100 -o region.fasta
  lungfish-cli extract sequence genome.lungfishref chr1:1000-2000 --bundle -o
region.lungfishref

USAGE: lungfish-cli extract sequence [<options>] <input> <region>

ARGUMENTS:
  <input>                 Input file (FASTA format)
  <region>                Region to extract (format: name:start-end, 1-based
                          inclusive)

OPTIONS:
  --reverse-complement    Reverse complement the extracted sequence
  --flank <flank>         Add N bases of flanking sequence on each side
                          (default: 0)
  --flank-5 <flank-5>     Add N bases of 5' (upstream) flanking sequence
  --flank-3 <flank-3>     Add N bases of 3' (downstream) flanking sequence
  -o, --output <output>   Output file path (default: stdout). Required with
                          --format json
  --line-width <line-width>
                          FASTA line width (default: 70)
  --bundle                Build a reference bundle of the region from a
                          .lungfishref input, keeping its annotation and
                          variant tracks in the region. Needs -o
                          <name>.lungfishref
  --name <name>           With --bundle or a .lungfishref output, the bundle's
                          name the record keeps (default: the region or the
                          feature name)
  --source-document <source-document>
                          With a FASTA input and a .lungfishref output, the
                          document the FASTA was written from, which the record
                          names
  --samples <samples>     With --bundle, keep the variant calls of this sample.
                          Give it once for each sample to keep. A name may hold
                          commas, dots and spaces
  --no-samples            With --bundle, keep the variant calls of no sample
  --next-free-name        With --bundle or a .lungfishref output, when a bundle
                          holds the name -o gives, publish under the next free
                          name (_1, _2 and so on) and replace nothing
  --feature-name <feature-name>
                          With --bundle or a .lungfishref output, extract this
                          feature, whose parts the region lists in order as
                          name:start-end,start-end
  --feature-type <feature-type>
                          With --feature-name, the feature's type, such as
                          gene, CDS or mRNA (default: region)
  --strand <strand>       With --feature-name, the feature's strand, + or -
  --concatenate-exons     With --feature-name, join the feature's parts into
                          one sequence
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
