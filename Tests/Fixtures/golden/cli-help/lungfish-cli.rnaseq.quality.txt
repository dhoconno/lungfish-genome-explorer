OVERVIEW: Print the quality numbers and the sample correlation of a bulk
RNA-seq result

Checks each file of the result against the sha256 its manifest lists, then
prints one table and writes nothing. --table samples gives each sample's
library size, mapping rate and library type, and the shares on rRNA genes and
not-host features. The globin share reads Not recorded, since LGE names no
globin genes yet. --table correlation gives Pearson r of log2(CPM + 1) between
the samples, on the features that the manifest does not list under notHost.
--format tsv prints the table alone, json one document, and text a line that
names the table first.

USAGE: lungfish-cli rnaseq quality <result-path> [--table <table>] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

ARGUMENTS:
  <result-path>           A bulk .lungfishrnaseq result

OPTIONS:
  --table <table>         The table to print (values: samples, correlation;
                          default: samples)
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
