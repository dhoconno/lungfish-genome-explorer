OVERVIEW: Construct GATK BaseRecalibrator and ApplyBQSR commands

USAGE: lungfish-cli gatk bqsr [--execute] [--dry-run] --reference <reference> --bam <bam> [--known-sites <known-sites> ...] --recal-table <recal-table> --output <output> [--intervals <intervals>] [--create-output-bam-index <create-output-bam-index>] [--extra-args <extra-args>]

OPTIONS:
  --execute               Run GATK and write final-location provenance.
  --dry-run               Print the GATK command preview without running it.
  --reference <reference> Reference FASTA path
  --bam <bam>             Input BAM path
  --known-sites <known-sites>
                          Known-sites VCF path. Repeat for dbSNP, Mills, or
                          cohort resources.
  --recal-table <recal-table>
                          Output recalibration table path
  --output <output>       Output recalibrated BAM path
  --intervals <intervals> Optional intervals BED/list/contig path
  --create-output-bam-index <create-output-bam-index>
                          Whether ApplyBQSR should create a BAM index (default:
                          true)
  --extra-args <extra-args>
                          Additional GATK arguments appended to both BQSR
                          commands
  --version               Show the version.
  -h, --help              Show help information.
