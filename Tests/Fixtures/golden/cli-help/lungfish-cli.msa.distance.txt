OVERVIEW: Compute identity or distance matrices from a .lungfishmsa bundle

Gaps and ambiguous characters are missing data. A nucleotide site compares only
when both characters are A, C, G, T or U. A protein site skips X, B, Z, J, ?
and *. The alphabet comes from the bundle manifest. A cell with no comparable
sites is written as nan, and a saturated corrected distance is written as inf.

USAGE: lungfish-cli msa distance [<options>] <bundle-path> --output <output>

ARGUMENTS:
  <bundle-path>           Input .lungfishmsa bundle

OPTIONS:
  --model <model>         Distance model: identity, p-distance, jc69 or k2p for
                          nucleotides, identity, p-distance or poisson for
                          protein (default: identity)
  --gaps <gaps>           Gap and ambiguity deletion: pairwise (each pair skips
                          its own missing sites) or complete (skip every column
                          with a missing site in any selected row) (default:
                          pairwise)
  --order <order>         Row and column order: alignment or average-linkage
                          (UPGMA leaf order on p-distance) (default: alignment)
  --output <output>       Output TSV matrix path
  --rows <rows>           Optional comma-separated row IDs or display names
  --columns <columns>     Optional 1-based aligned column ranges, e.g. 10-40,55
  --force                 Overwrite an existing output file
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
