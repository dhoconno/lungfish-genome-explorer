OVERVIEW: Delete annotation rows from a reference bundle annotation track

USAGE: lungfish-cli sequence delete-annotations <bundle> --track-id <track-id> [--row-id <row-id> ...]

ARGUMENTS:
  <bundle>                Reference bundle to update

OPTIONS:
  --track-id <track-id>   Annotation track ID containing the rows.
  --row-id <row-id>       Annotation database row ID to delete. Repeat or pass
                          multiple values.
  --version               Show the version.
  -h, --help              Show help information.
