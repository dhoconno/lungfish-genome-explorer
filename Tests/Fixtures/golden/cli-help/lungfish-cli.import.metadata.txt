OVERVIEW: Import sample metadata CSV/TSV into a result bundle

The global --threads option sets the thread count.

USAGE: lungfish-cli import metadata <input-path> --bundle <bundle>

ARGUMENTS:
  <input-path>            Path to the metadata CSV or TSV file

OPTIONS:
  -b, --bundle <bundle>   Path to the result bundle directory (e.g., naomgs-*,
                          kraken2-*)
  --version               Show the version.
  -h, --help              Show help information.
