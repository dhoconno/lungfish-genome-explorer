OVERVIEW: Import TaxTriage classification results

USAGE: lungfish-cli import taxtriage <input-path> [--output-dir <output-dir>] [--name <name>]

ARGUMENTS:
  <input-path>            Path to the TaxTriage results directory

OPTIONS:
  -o, --output-dir <output-dir>
                          Output project directory (default: current directory)
  --name <name>           Optional imported result name (used in output
                          directory)
  --version               Show the version.
  -h, --help              Show help information.
