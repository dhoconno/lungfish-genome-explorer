OVERVIEW: Import a BAM or CRAM alignment file

USAGE: lungfish-cli import bam <input-file> [--output-dir <output-dir>] [--name <name>]

ARGUMENTS:
  <input-file>            Path to the BAM or CRAM file

OPTIONS:
  -o, --output-dir <output-dir>
                          Output project directory (default: current directory)
  --name <name>           Display name for the alignment track (default:
                          filename)
  --version               Show the version.
  -h, --help              Show help information.
