OVERVIEW: Write a sample metadata template of a bundle's variant samples as TSV
or CSV with provenance

USAGE: lungfish-cli variants export sample-template [<options>] <bundle-path> --output-format <output-format> --output <output>

ARGUMENTS:
  <bundle-path>           The reference bundle whose variant tracks hold the
                          samples

OPTIONS:
  --metadata-column <metadata-column>
                          A sample metadata column to add, by name. Repeat for
                          more. Values come from the result's metadata
  --output-format <output-format>
                          The file format to write (values: csv, tsv)
  -o, --output <output>   The file to write. An existing file is refused
                          without --force
  --force                 Overwrite an existing output file
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
