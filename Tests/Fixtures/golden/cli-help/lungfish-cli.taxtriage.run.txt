OVERVIEW: Execute TaxTriage classification on FASTQ files

USAGE: lungfish-cli taxtriage run [<options>] --output <output>

OPTIONS:
  --input <input>         Input FASTQ file (R1 or single-end)
  --input2 <input2>       Second FASTQ file (R2 for paired-end)
  --recursive             When --input is a directory, include eligible FASTQ
                          files in subfolders
  --sample <sample>       Sample identifier (required with --input)
  --samplesheet <samplesheet>
                          Path to a TaxTriage samplesheet CSV (alternative to
                          --input)
  --platform <platform>   Sequencing platform: illumina, oxford, pacbio
                          (default: illumina) (values: illumina, oxford,
                          pacbio; default: illumina)
  -o, --output <output>   Output directory for results
  --db <db>               Path to existing Kraken2 database
  --confidence <confidence>
                          Kraken2 confidence threshold (default: 0.2) (default:
                          0.2)
  --top-hits <top-hits>   Number of top hits to report (default: 10) (default:
                          10)
  --rank <rank>           Taxonomic rank: D,P,C,O,F,G,S (default: S) (default:
                          S)
  --skip-assembly         Skip genome assembly steps (default: true)
  --no-skip-assembly      Enable genome assembly steps
  --skip-krona            Skip Krona visualization generation
  --remove-taxids <ids>   NCBI taxids to exclude as host before TaxTriage picks
                          references, separated by spaces or commas (e.g. 9606
                          for human). Passed as --remove_taxids. Default: none.
  --max-memory <max-memory>
                          Maximum memory (Nextflow format, default: 16.GB)
                          (default: 16.GB)
  --max-cpus <max-cpus>   Maximum CPUs (default: auto)
  --nf-profile <nf-profile>
                          Nextflow execution profile (default: docker)
                          (default: docker)
  --revision <revision>   TaxTriage pipeline revision/branch (defaults to
                          Lungfish's pinned TaxTriage revision) (default:
                          e10bfebda32a62711f38a4e23ab03b61725a9675)
  --extra-args <extra-args>
                          Additional TaxTriage/Nextflow pipeline arguments
                          passed verbatim
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
