OVERVIEW: Execute TaxTriage classification on FASTQ files

USAGE: lungfish-cli taxtriage run <options>

OPTIONS:
  --input <input>         Input FASTQ file (R1 or single-end) or .lungfishfastq
                          bundle
        A bundle is planned whole. A bundle of pairs runs as pairs, and a
        bundle that mixes pairs with merged or single reads, or holds several
        files of single reads, gives one single-end file of every read. A file
        inside a bundle is read as named, except the preview of a virtual
        bundle, which reads its bundle. --input and --input2 that name every
        file of one bundle are read as that bundle. A folder gives one sample
        of each FASTQ file or bundle in it. A folder that holds paired reads is
        refused, since the folder route pairs no R1 and R2 files. Use
        --samplesheet to pair them.
  --input2 <input2>       Second FASTQ file (R2 for paired-end)
  --recursive             When --input is a directory, include eligible FASTQ
                          files in subfolders
  --sample <sample>       Sample name, required with an --input file or bundle
                          and with --input2. With an --input folder, each
                          sample is named after its file, behind this name when
                          given
  --samplesheet <samplesheet>
                          Path to a TaxTriage samplesheet CSV (alternative to
                          --input)
  --platform <platform>   Sequencing platform: illumina, oxford, pacbio
                          (default: illumina) (values: illumina, oxford,
                          pacbio; default: illumina)
  -o, --output <output>   Output directory for results
        Without --project or --batch, one Nextflow run processes every sample
        and writes their results to this folder, and the folder keeps every
        file TaxTriage wrote. With --batch, each sample runs alone in its own
        folder inside it. Not with --project.
  --project <project>     The .lungfish project the run belongs to. The result
                          lands in its Analyses/taxtriage-batch-<timestamp>/
                          folder, where the app's TaxTriage runs put it
        One sample runs in that folder itself. Several samples each run alone,
        in a folder named after the sample and made safe for a folder name. The
        run then builds taxtriage.sqlite for the viewer and removes the
        intermediate files the viewer does not read, keeping top/. Not with
        --output.
  --batch                 Run each sample alone, in its own Nextflow run and
                          folder of one batch result
        Without --batch, a plain --output runs every sample in one Nextflow
        run. --batch pairs no R1 and R2 files by name, so give pairs in a
        --samplesheet. The batch result gets taxtriage.sqlite and loses its
        intermediate files as a --project result does. Give --output or
        --project.
  --db <db>               Path to existing Kraken2 database
  --confidence <confidence>
                          Kraken2 confidence threshold (default: 0.2) (default:
                          0.2)
  --top-hits <top-hits>   Number of top hits to report (default: 10) (default:
                          10)
  --rank <rank>           Taxonomic rank: D,P,C,O,F,G,S (default: S) (default:
                          S)
  --skip-assembly         Skip genome assembly steps (default: true)
  --no-skip-assembly      Enable genome assembly steps
  --skip-krona            Skip Krona visualization generation
  --remove-taxids <ids>   NCBI taxids to exclude as host before TaxTriage picks
                          references, separated by spaces or commas (e.g. 9606
                          for human). Passed as --remove_taxids. Default: none.
  --max-memory <max-memory>
                          Maximum memory (Nextflow format, default: 16.GB)
                          (default: 16.GB)
  --max-cpus <max-cpus>   Maximum CPUs (default: auto)
  --nf-profile <nf-profile>
                          Nextflow execution profile (default: docker)
                          (default: docker)
  --revision <revision>   The TaxTriage commit or tag to run. Without it, LGE
                          runs the commit its tool lock pins
  --extra-args <extra-args>
                          Additional TaxTriage/Nextflow pipeline arguments
                          passed verbatim
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
