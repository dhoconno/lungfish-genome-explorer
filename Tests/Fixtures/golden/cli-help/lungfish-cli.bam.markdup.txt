OVERVIEW: Mark PCR duplicates in BAM files using samtools markdup

The input BAM is left untouched. The duplicate-marked copy is written beside it
as <name>.markdup.bam with a .bai index, or to --output for a single BAM. This
matches the app's Mark Duplicates, which keeps the original track as
"[unmarked]".

Pass --in-place to overwrite the input BAM instead. WARNING: --in-place
destroys the unmarked original and cannot be undone.

USAGE: lungfish-cli bam markdup [<options>] <path>

ARGUMENTS:
  <path>                  Path to a BAM file or a directory containing BAMs

OPTIONS:
  --force                 Re-run markdup even if already marked
  --sort-threads <sort-threads>
                          Threads for samtools sort (default 4) (default: 4)
  --output <output>       Write the marked BAM here instead of
                          <name>.markdup.bam (single BAM input only)
  --in-place              Overwrite the input BAM with the marked copy.
                          WARNING: destroys the unmarked original
  --format <format>       Output format: text, json (default: text) (values:
                          text, json; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
