OVERVIEW: Call viral variants from a bundle-owned alignment track

USAGE: lungfish-cli variants call [<options>] --bundle <bundle> --alignment-track <alignment-track> --caller <caller>

OPTIONS:
  --bundle <bundle>       Path to the reference bundle directory
  --alignment-track <alignment-track>
                          Bundle alignment track identifier, or its display
                          name when only one track has that name
  --caller <caller>       Variant caller: lofreq, ivar, medaka, bcftools,
                          clair3, gatk (GATK HaplotypeCaller, attached under
                          variants/gatk)
  --name, --output-track-name <name>
                          Display name for the created variant track
  --min-af <min-af>       Minimum allele frequency threshold
  --min-depth <min-depth> Minimum depth threshold
  --ivar-primer-trimmed   Confirm the BAM was primer-trimmed before iVar
                          calling. Not needed for a track Lungfish
                          primer-trimmed itself: its primer-trim record is read
                          automatically, as the Call Variants dialog does.
  --medaka-model <medaka-model>
                          Medaka: the variant model name, required (for example
                          r941_prom_sup_variant_g507). Clair3: a model shipped
                          with Clair3 by name (for example r941_prom_sup_g5014)
                          or a model folder path; omit it to use the model
                          matched to the platform.
  --platform <platform>   Sequencing platform for Medaka and Clair3: ont, hifi
                          or ilmn. Defaults to the platform recorded in the
                          alignment's read groups (@RG PL).
  --ivar-consensus-af <ivar-consensus-af>
                          Allele frequency threshold above which an iVar
                          haplotype counts as consensus (default: 0.75)
  --ivar-merge-af-threshold <ivar-merge-af-threshold>
                          Maximum allele frequency distance for merging
                          adjacent iVar SNPs (default: 0.25)
  --ivar-bad-quality-threshold <ivar-bad-quality-threshold>
                          iVar ALT_QUAL below this fails the bq filter
                          (default: 20)
  --ivar-no-ignore-strand-bias
                          Apply iVar strand-bias filter (off by default for
                          amplicon data)
  --ploidy <ploidy>       bcftools genotype ploidy: 1 (haploid, for viral and
                          bacterial references) or 2 (diploid, for human and
                          other eukaryotic references). Defaults to a value
                          derived from the bundle's organism metadata, falling
                          back to 1. For --caller gatk it is the GATK sample
                          ploidy, a positive number that defaults to 2.
  --extra-args, --advanced-options <extra-args>
                          Additional caller arguments, written exactly as they
                          should be passed to the underlying tool
  --emit-ref-confidence <emit-ref-confidence>
                          GATK: reference confidence mode, NONE or GVCF. NONE
                          writes a plain VCF of the called variants. (default:
                          NONE)
  --intervals <intervals> GATK: optional intervals file, a BED file or an
                          interval list. The value is read as a file path, so a
                          contig name or a region such as chr1:1-100 is not
                          accepted
  --pcr-indel-model <pcr-indel-model>
                          GATK: PCR indel model (default: CONSERVATIVE)
  --stand-call-conf <stand-call-conf>
                          GATK: calling confidence threshold, used when
                          reference confidence is NONE (default: 30.0)
  --max-alternate-alleles <max-alternate-alleles>
                          GATK: maximum alternate alleles (default: 6)
  --pair-hmm-threads <pair-hmm-threads>
                          GATK: native PairHMM threads (default: 4)
  --time-limit <minutes>  Stop the run after this many minutes. Without it the
                          run has no time limit.
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
