OVERVIEW: Construct a Freyja demix command plan from variant and depth tables

USAGE: lungfish-cli freyja demix [--execute] [--dry-run] --variants <variants> --depths <depths> --output-dir <output-dir> [--sample <sample>] [--extra-args <extra-args>]

OPTIONS:
  --execute               Run Freyja through the wastewater-surveillance tool
                          pack.
  --dry-run               Write and print the command plan without running
                          Freyja.
  --variants <variants>   Freyja variants table from freyja variants
  --depths <depths>       Freyja depths table from freyja variants
  --output-dir <output-dir>
                          Output directory for plan, provenance, and demix
                          output
  --sample <sample>       Optional sample identifier
  --extra-args <extra-args>
                          Additional Freyja demix arguments
  --version               Show the version.
  -h, --help              Show help information.
