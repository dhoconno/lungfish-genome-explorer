OVERVIEW: Trim amplicon primers from a bundle BAM and adopt the result as a new
alignment track

USAGE: lungfish-cli bam primer-trim [<options>] --bundle <bundle> --alignment-track <alignment-track> --scheme <scheme> --name <name>

OPTIONS:
  --bundle <bundle>       Path to the reference bundle directory (.lungfishref)
  --alignment-track <alignment-track>
                          Source alignment track identifier
  --scheme <scheme>       Path to the .lungfishprimers bundle directory
  --name <name>           Display name for the new primer-trimmed alignment
                          track
  --target-reference <target-reference>
                          Override the @SQ SN used to resolve the primer scheme
                          (defaults to the primer scheme's canonical accession)
  --ivar-min-quality <ivar-min-quality>
                          Minimum Phred quality for the sliding-window trim
                          (default: 20)
  --ivar-min-length <ivar-min-length>
                          Minimum read length to retain after trimming
                          (default: 30)
  --ivar-sliding-window <ivar-sliding-window>
                          Sliding-window width for ivar trim (default: 4)
  --ivar-primer-offset <ivar-primer-offset>
                          Primer coordinate offset (bp) (default: 0)
  --format <format>       Output format: text, json (default: text) (values:
                          text, json; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
