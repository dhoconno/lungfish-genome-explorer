OVERVIEW: Export RNA-seq counts for DESeq2, edgeR and limma

Writes counts.tsv, genes.tsv, samples.tsv, deseq2.R, edger-limma-dream.R
(edgeR, limma voom and dream) and a record into the new folder --output names.
The results must come from one route and one reference set. A route is the
tool, its version and every setting that changes counts.

USAGE: lungfish-cli rnaseq export [<options>] <result-paths> ... --output <output>

ARGUMENTS:
  <result-paths>          One or more .lungfishrnaseq result folders

OPTIONS:
  --output <output>       The new folder to write. It must not exist
  --sample-sheet <sample-sheet>
                          A tab-separated sheet with a sample column. Its other
                          columns join samples.tsv
  --design <design>       A column of samples.tsv that enters the model. Repeat
                          it, and the last one is the tested factor
  --contrast <contrast>   FACTOR:NUMERATOR:DENOMINATOR, such as group:TB:HIV.
                          Repeat it for more contrasts
  --padj-cutoff <padj-cutoff>
                          The adjusted p-value cutoff, which is also alpha in
                          DESeq2's results() (default: 0.05)
  --lfc-bar <lfc-bar>     A bar on the absolute log2 fold change. None by
                          default
  --batch <batch>         The column of samples.tsv that names each sample's
                          batch, for --batch-correction
  --batch-correction <batch-correction>
                          none, combat-seq or sva (default: none)
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
