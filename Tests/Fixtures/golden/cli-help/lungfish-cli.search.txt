OVERVIEW: Search for patterns in sequences

Search for exact strings, IUPAC motifs, or regex patterns in nucleotide
or protein sequences. Outputs results in BED format (chrom, start, end,
name, score, strand) suitable for downstream processing.

For nucleotide sequences, both forward and reverse complement strands
are searched by default.

Examples:
  lungfish-cli search genome.fasta ATGCGATCG
  lungfish-cli search genome.fasta --iupac "TATAWAWN"
  lungfish-cli search genome.fasta --regex "ATG(.{3}){10,50}T(AA|AG|GA)"
  lungfish-cli search genome.fasta GAATTC --max-mismatches 1
  lungfish-cli search genome.fasta GAATTC -o sites.bed

USAGE: lungfish-cli search [<options>] <input> <pattern>

ARGUMENTS:
  <input>                 Input file (FASTA format)
  <pattern>               Search pattern (exact sequence, IUPAC motif, or regex)

OPTIONS:
  --regex                 Interpret pattern as a regular expression
  --iupac                 Interpret pattern as an IUPAC ambiguity code motif
  --max-mismatches <max-mismatches>
                          Allow up to N mismatches for exact matching (default:
                          0) (default: 0)
  --forward-only          Search forward strand only (skip reverse complement)
  --case-sensitive        Enable case-sensitive matching
  -o, --output <output>   Output file path (default: stdout)
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
