OVERVIEW: Import a CZ-ID taxon report TSV into a Lungfish result directory

USAGE: lungfish-cli cz-id import <input-path> [--output-dir <output-dir>]

ARGUMENTS:
  <input-path>            Path to a CZ-ID taxon report TSV, ZIP archive, or
                          extracted export folder

OPTIONS:
  -o, --output-dir <output-dir>
                          Output directory for the imported result (default:
                          ./cz-id-{sample})
  --version               Show the version.
  -h, --help              Show help information.
