OVERVIEW: List the BLAST searches that have not ended

Reads the lines under the storage root, each naming a search's result folder,
and lists those not ended. A line whose folder has been missing for 72 hours
since its last contact is retired, and the search is taken up again when its
project reopens. --project also adopts the searches in that project's result
folders.

USAGE: lungfish-cli blast in-flight [--project <project>] [--format <format>] [--verbose ...] [--quiet] [--progress] [--no-progress] [--debug] [--log-file <log-file>] [--no-color] [--threads <threads>]

OPTIONS:
  --project <project>     Project folder that has just opened, whose searches
                          this adopts
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
