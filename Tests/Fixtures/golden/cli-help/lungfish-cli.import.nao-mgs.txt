OVERVIEW: Import NAO-MGS metagenomic surveillance results

USAGE: lungfish-cli import nao-mgs <input-path> [--sample-name <sample-name>] [--output-dir <output-dir>] [--fetch-references] [--no-fetch-references]

ARGUMENTS:
  <input-path>            Path to NAO-MGS results directory or
                          virus_hits_final.tsv(.gz)

OPTIONS:
  --sample-name <sample-name>
                          Override sample name
  -o, --output-dir <output-dir>
                          Output project/import directory (default: current
                          directory)
  --fetch-references/--no-fetch-references
                          Fetch NCBI reference FASTA files into references/
                          (default: --fetch-references)
  --version               Show the version.
  -h, --help              Show help information.
