OVERVIEW: Construct a GATK VariantFiltration command

USAGE: lungfish-cli gatk filter [--execute] [--dry-run] --vcf <vcf> [--preset <preset>] --output <output> [--extra-args <extra-args>]

OPTIONS:
  --execute               Run GATK and write final-location provenance.
  --dry-run               Print the GATK command preview without running it.
  --vcf <vcf>             Input VCF path
  --preset <preset>       best-practices-snp, best-practices-indel,
                          best-practices-both (default: best-practices-both)
  --output <output>       Output filtered VCF path
  --extra-args <extra-args>
                          Additional GATK arguments, written exactly as they
                          should be passed
  --version               Show the version.
  -h, --help              Show help information.
