OVERVIEW: Import ONT output directory into per-barcode bundles

Imports Oxford Nanopore sequencing output directories into per-barcode
.lungfishfastq bundles. Concatenates chunked FASTQ files within each
barcode directory and generates a demultiplex manifest.

Accepts either a fastq_pass/ parent directory or a single barcode
directory (e.g., fastq_pass/barcode01/).

Examples:
  lungfish-cli fastq import-ont fastq_pass/ -o imported/
  lungfish-cli fastq import-ont fastq_pass/barcode13/ -o imported/
  lungfish-cli fastq import-ont fastq_pass/ -o imported/ --include-unclassified

USAGE: lungfish-cli fastq import-ont [<options>] <input> --output <output>

ARGUMENTS:
  <input>                 ONT output directory (fastq_pass/ or single barcode
                          directory)

OPTIONS:
  -o, --output <output>   Output directory for .lungfishfastq bundles
  --include-unclassified  Include unclassified reads (default: skip)
  --concurrency <concurrency>
                          Max concurrent barcode imports (default: 4)
  --storage-mode <storage-mode>
                          How to store ONT chunks inside each bundle (values:
                          chunked, flattened; default: chunked)
  --optimize-storage      Run clumpify on flattened per-barcode FASTQ payloads
                          to improve compression
  --quality-binning <quality-binning>
                          Quality binning: fiveStep (8 quality levels, keeps
                          every Q10, Q20 and Q30 count), illumina4 (7 quality
                          levels, to replay older imports), eightLevel (~21
                          quality levels) or none, which keeps every score. A
                          chunked import bins each chunk with reformat.sh and
                          --optimize-storage bins with clumpify. Binning is
                          lossy. (values: fiveStep, illumina4, eightLevel,
                          none; default: none)
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
