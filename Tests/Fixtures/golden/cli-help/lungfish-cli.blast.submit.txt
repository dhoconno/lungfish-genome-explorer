OVERVIEW: BLAST the sequences of a FASTA file against NCBI

Submits every sequence of the query FASTA to NCBI BLAST and saves the result in
the --output folder, beside a copy of the query. The record names the copy's
SHA-256 and the lineage options, which say which result, sample, taxon or
contig and which subsample the sequences came from.

USAGE: lungfish-cli blast submit [<options>] --query <query> --output <output>

OPTIONS:
  --query <query>         FASTA file of the sequences to BLAST
  --output <output>       Result folder to create, which gets query.fasta,
                          blast-result.json and its provenance
  --name <name>           Label of the search in the result (default: the
                          query's file name)
  --taxid <taxid>         Taxon the sequences were assigned to, recorded and
                          used to judge hits
  --contig <contig>       Contig the sequences are, or came from, recorded
  --source-result <source-result>
                          Result folder the sequences came from, recorded
  --sample <sample>       Sample the sequences came from, recorded
  --subsample-count <subsample-count>
                          Number of sequences a subsample drew, recorded
  --subsample-seed <subsample-seed>
                          Seed of that subsample, recorded
  --database <database>   BLAST database to search (default: core_nt)
  --entrez-query <entrez-query>
                          Entrez query that restricts the search, for example
                          txid11320[Organism:exp]
  --accepted-taxid <accepted-taxid>
                          Taxon whose hits support the assignment (repeatable)
  --accepted-name <accepted-name>
                          Organism name whose hits support the assignment
                          (repeatable)
  --related-taxid <related-taxid>
                          Taxon whose hits count as a relative (repeatable)
  --related-name <related-name>
                          Organism name whose hits count as a relative
                          (repeatable)
  --extra-args <extra-args>
                          Additional BLAST URL API parameters as KEY=VALUE
                          tokens (for example WORD_SIZE=11)
  --format <format>       Output format (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
