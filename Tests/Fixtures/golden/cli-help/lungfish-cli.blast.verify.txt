OVERVIEW: Verify a taxon classification via NCBI BLAST

Submit a subsample of reads classified to the target taxon to NCBI
BLAST and report how many are independently verified. Requires the
kreport file (for tree building), the per-read Kraken2 output (for
read ID extraction), and the source FASTQ (for sequence retrieval).

USAGE: lungfish-cli blast verify [<options>] --kreport <kreport> --source <source> --kraken-output <kraken-output> --taxid <taxid>

OPTIONS:
  --kreport <kreport>     Kraken2 report file (.kreport)
  --source <source>       Source FASTQ file
  --kraken-output <kraken-output>
                          Kraken2 per-read output file (.kraken)
  --taxid <taxid>         Taxonomy ID to verify
  --reads <reads>         Number of reads to submit (default: 20) (default: 20)
  --seed <seed>           Random seed for choosing which fragments to submit
                          (default: 0) (default: 0)
  --max-concurrent <max-concurrent>
                          Maximum in-flight BLAST submissions for this process
                          (default: 1) (default: 1)
  --include-children      Include reads classified to descendant taxa
  --extra-args <extra-args>
                          Additional BLAST URL API parameters as KEY=VALUE
                          tokens (for example WORD_SIZE=11)
  --result-dir <result-dir>
                          Classifier result folder to save the verification in,
                          under blast-verifications/ (the app restores it when
                          the taxon is selected)
  --format <format>       Output format: text, json, tsv (default: text)
                          (values: text, json, tsv; default: text)
  -v, --verbose           Increase output verbosity (can be repeated: -v, -vv,
                          -vvv)
  -q, --quiet             Suppress non-essential output (errors only)
  --progress              Show progress bar (default: auto-detect TTY)
  --no-progress           Disable progress bar
  --debug                 Enable debug output with detailed logging
  --log-file <log-file>   Write detailed logs to file
  --no-color              Disable colored output
  -t, --threads <threads> Number of threads to use (default: auto)
  --version               Show the version.
  -h, --help              Show help information.
