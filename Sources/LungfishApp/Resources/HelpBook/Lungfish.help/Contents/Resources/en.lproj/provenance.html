Provenance

Welcome Reads and Workflows Classification Review Alignments and Variants

Provenance is the reproducibility record attached to a scientific output. It explains what ran, which inputs were used, where outputs were written, and whether the run finished.

What to Check

  • Tool or workflow name and version
  • Command, visible options, and resolved defaults
  • Input and output paths, checksums, and file sizes
  • Status, stderr, and runtime

Missing provenance is a blocking defect for data-changing scientific workflows.
